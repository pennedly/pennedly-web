Рутина упоминаний — собери помощника под конкретную цель

Упоминание в Threads — пост постороннего, который тегнул вас. Владелец хочет автоматизировать реакцию не «на все упоминания подряд», а под конкретную цель, описанную своими словами. Рутина упоминаний = цель (интент словами) + условие (какие упоминания) + действие (что сделать) + режим (сам или спросить). Это не новый визуальный язык, а сборка из готовых кирпичей: карточка-рецепт, бейдж режима, «Правила дома» и Layer-3. Живут в хабе «Автопилот»; вход — с экрана очереди упоминаний. Живые фреймы — реальные DS-компоненты, светлая и тёмная.

хаб + конструктор · ~1000px поле цели · до 500 вложение · неважно / фото / текст режим · сам / спроси меня ответить картинкой · Скоро catch-all по умолчанию Layer-3 · наследует Правила дома
Цель · ядроИнтент словамиСвободный текст до 500. Движок сам решает, какие упоминания под неё подходят. Пусто = catch-all.
УсловиеВложениеНеважно · только с фото · только текст. Требование к медиа упоминания — реально уже сегодня.
ДействиеЧто сделатьОтветить в вашем голосе (реально) или сгенерированным фото (Скоро). Плюс подсказка «как отвечать».
РежимСам / спросиТот же бейдж, что у рутин постинга. Авто — только на безопасное.
01

Хаб рутин упоминаний

Живёт в «Автопилоте». Список карточками в стиле рутин постинга: иконка + название + строка-суть человеческим языком + бейдж режима (сам / спроси) + вкл/выкл + «Изменить». Отдельно — рутина по умолчанию (без цели, ловит всё остальное безопасное), помечена как fallback. Сверху — «+ Новая рутина упоминаний».

02

Конструктор · ядро — поле цели

Собери связным «рецептом-предложением». Триггер зафиксирован: «Когда меня упоминают…». Ядро — большое поле «Опиши цель своими словами» (счётчик до 500, микро-подсказка «Pennedly сам поймёт, какие упоминания подходят») и чекбокс «отвечать на любые безопасные упоминания» (= цель пустая, catch-all). Рядом — честная гарантия: на жалобы, лиды и провокации бот сам не отвечает.

Light · слот «цель» раскрыт на месте · поле + счётчик + catch-all + гарантия
Dark · то же
03

Простое сверху, глубина по желанию

Базовый вид — только цель + действие + режим в одной читаемой фразе, слои свёрнуты. Кто хочет глубже — разворачивает «Настроить точнее» (вложение + подсказка «как отвечать») и «Только для этой рутины» — точечно переопределить «Правила дома»: частота, тихие часы, лимит, аудитория (Слой 3).

04

Под интент · и рутина по умолчанию

Слева — рутина под конкретный интент (цель заполнена, «только с фото», авто). Справа — рутина catch-all: цель пустая (чекбокс включён), ловит всё остальное безопасное. В catch-all фраза читается «по любой безопасной причине», без клаузы про цель.

Light · под интент · «только с фото» · отвечает сам
Light · рутина по умолчанию · цель пустая · черновик
05

Действие · «Ответить сгенерированным фото» — Скоро

Выбор действия: «Ответить в моём голосе» (реально, выбрано) и «Ответить сгенерированным фото» — заблокирован, с меткой «Скоро» и честным пояснением. Требование «с фото» и матч по цели работают уже сегодня; само действие ответить картинкой — Фаза 4. Под действием — необязательное поле «как отвечать».

Light · слот «действие» раскрыт · «фото» заблокировано
Dark · то же
Не рисуем рабочим то, чего нет. «Ответить сгенерированным фото» — заблокированный выбор с меткой Скоро, а не рабочий тумблер. Пока действие недоступно, рутина под такую цель отвечает в голосе (тёплый ответ «заберу в работу»), а картинку пришлёт человек. Матч по цели и требование «с фото» — уже реальны.
06

Режим и вложение — на месте

Слот «режим» разворачивает тот же выбор «Спроси меня / Отвечает сразу», что и у рутин постинга (переиспользуем .sc-mode). Слот «вложение» — сегмент «Неважно / Только с фото / Только текст».

Light · слот «режим» раскрыт · «Спроси меня» по умолчанию
Light · слот «вложение» раскрыт
07

Карточка рутины в хабе · три режима

Бейджи ровно как на постинге: авто («Отвечает сразу», янтарь + корешок карточки), спроси («Черновик ответа», нейтраль), выключена (бейдж приглушён, переключателя режима нет — сначала включи).

Light · авто (отвечает сразу)
Dark · спроси (черновик ответа)
Light · выключена
Dark · рутина по умолчанию (fallback)
08

Правда о данных · рисуем строго под неё

Рутина упоминаний — это on_mention-сценарий. Что он реально несёт в бэкенде и какие гарантии движка мы не даём обойти в UI.

ПолеЧто это · как в UI
Что несёт сценарий
trigger_cfg.intentЦель словами владельца (свободный текст, до 500). Движок один раз прогоняет каждое упоминание и сам решает, подходит ли. Пусто = catch-all «ответить на всё остальное безопасное».
requires_mediaТребование к вложению: any (неважно) / image (только с фото) / none (только текст). Сегмент «Вложение».
publish_modeauto (Pennedly публикует сам) или ask (готовит черновик, публикуете вы). Тот же бейдж, что у рутин постинга.
reply_instructionСлоистая подсказка «как отвечать» (свободный текст, опционально). Поле «Как отвечать».
overridesЧастота / тихие часы / дневной лимит / аудитория — по умолчанию наследуются из «Правил дома»; в слое «Только для этой рутины» переопределяются точечно (Слой 3). Уже исполняются бэкендом.
Жёсткие гарантии движка (не дать обойти)
Только безопасноеАвто-ответ возможен только на AUTO-safe (вопрос / похвала / нейтральное). Жалоба / лид / провокация / конкурент и спам-семейство рутина никогда не трогает сама — они ждут владельца в очереди. UI не даёт выбрать авто-ответ на них.
Одно упоминание — одна рутинаКаждое упоминание уходит максимум в одну рутину (движок выбирает по цели). Рутина без цели — fallback «ответить на всё остальное безопасное».
Чего пока нет — метка «Скоро»
Ответ картинкойГенерация изображения в ответ (кейс «фото ребёнка») — Фаза 4. В конструкторе это заблокированный выбор с меткой «Скоро». Требование «с фото» и матч по цели — реальны уже сегодня.
Тон гарантии — успокаивающий, не запрещающий. Блок .mr-guard в поле цели говорит спокойно: «даже с широкой целью Pennedly сам отвечает только на безопасное; жалобы, лиды и провокации ждут вас в очереди». Один акцент, никакого warning — предупреждающий янтарь бережём для реально опасного.

Чек-лист реализации

хаб · 3+fallbackхаб пустоконструктор базовыйразвёрнутыйпод интентcatch-allдействие·Скорорежим·сам/спросикарточка авто/спроси/выклсветлая+тёмная
  • Хаб живёт в «Автопилоте»: карточки в стиле рутин постинга (иконка + название + строка-суть + бейдж режима + вкл/выкл + «Изменить»); рутина по умолчанию помечена как fallback; «+ Новая рутина упоминаний»; пустой хаб = приглашение.
  • Конструктор — карточка-рецепт: триггер зафиксирован «Когда меня упоминают…»; ядро — поле цели (до 500, микро-подсказка, чекбокс catch-all); слоты «вложение / режим / действие» правятся на месте.
  • Вложение: сегмент Неважно / Только с фото / Только текст (requires_media).
  • Действие: «Ответить в моём голосе» (реально) + «Ответить сгенерированным фото» с меткой Скоро (заблокирован, с пояснением); поле «как отвечать» (reply_instruction).
  • Режим — переиспользован бейдж/выбор «Спроси меня / Отвечает сразу» (.sc-mode, .rt-mode), по умолчанию «Спроси меня».
  • Слой 3 «Только для этой рутины» свёрнут по умолчанию (всё наследует «Правила дома»); разворачивается в панель точечных переопределений — частота / тихие часы / дневной лимит / аудитория (наследовать ↔ своё значение).
  • Гарантии движка не обойти в UI: авто только на безопасное; жалобы / лиды / провокации / спам рутина не трогает сама; одно упоминание — одна рутина; без цели = fallback.
  • Обе темы, только токены ds/tokens.css, один акцент; тексты РУ, без длинных тире; сборка из готовых кирпичей, не новый язык.
