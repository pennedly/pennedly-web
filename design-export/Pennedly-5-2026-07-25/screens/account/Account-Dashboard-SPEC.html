Дашборд аккаунта — V3 «Агент» /app/account · портфельный брифинг

Полный, готовый к 1:1 SPEC выбранного концепта V3 «Агент». Экран открывается как утренний брифинг: в центре внимания — AI-вердикт по всему портфелю, а тоталы и каналы стоят ниже как «Доказательства». Продукт — мульти-сетевой портфельный: Аккаунт (логин) → Бренд (единица голоса) → Профиль (соц-аккаунт в одной сети). Дашборд — один компонент, параметризованный числом брендов: 1 бренд → карточки = профили; 2+ → карточки = бренды (с разворотом в профили). Дашборд и есть дом Агента — отдельного пункта меню «Агент» больше нет (см. §18); строка вопроса и кнопка «Открыть Агента» уводят в чат-экран. Все состояния, обе темы, десктоп. Каждая живая рамка ниже — реальный вывод кита account/v3.js, не пересобранная разметка.

V3 · Агент − пункт «Агент» account/v3.js account/shell.js account/vk.js ds/tokens.css import-banner.css
Критерий приёмки — раскладка (правила 1–2).
  • Правило 1. Однострочные элементы — значения тоталов, чипы, @никнеймы, имена брендов, счётчики, метки кнопок — никогда не переносятся ни на какой ширине; перенос сделан невозможным (короткие метки, tabular-nums, white-space:nowrap, запас контейнеров), крайняя страховка — усечение многоточием. Исключение — заголовок-вердикт (text-wrap:balance, он многострочный по смыслу), но он не ломает соседей. Доказано на 390 / 320 в мобильной спецификации, на узком десктопе — §14.
  • Правило 2. Ревью-копия русская, контейнеры держат 8 локалей (немецкий стресс ~1.3–1.5×). Немецкая длина показана и держит правило 1 (§14; переключатель локали в живом дашборде §3).
Честность данных вшита в кит. Нет числа → нет чипа/карточки (тотал рисует «—»). Отключённый профиль вне тоталов, но показан карточкой с «Переподключить». Агент вернул 204 → честное приглашение и вопросы-стартеры, без выдуманного вердикта и цифр. Все строки — через ключи acc.* (карта VK.T), русский не хардкодится; сети — реальные монохромные логотипы (VK.netLogo), аватар с монограммой-фолбэком.

1Идентификация экрана

Верхний home аккаунта. Порядок сверху вниз (по account/v3.js): sidebar(аккаунт) | main(topbar(breadcrumb + переключатель) → личность → герой-вердикт → «Доказательства»(тоталы + каналы)). Read-only, кроме «Повторить» на сбое синка, «Переподключить» и быстрой строки Агента (уводит в чат).

Маршрут/app/account — верхний уровень входа после логина. Всегда «Аккаунт», не один профиль. Профиль ≥ 1 обязателен (иначе онбординг).
ТипApp-shell уровня аккаунта. Сайдбар — глобальная навигация аккаунта: Дашборд · [Бренды — при 2+] · Настройки. Пункта «Агент» нет — его дом теперь этот дашборд (§18). Профильное меню (Студия / Ответы / Статистика) живёт на уровне профиля и не меняется.
НазначениеОткрыть день вердиктом Агента по всему портфелю, дать доказательства (тоталы + каналы) и вход в любой профиль/бренд в один клик.
Ширинаwide. Сайдбар 232 + колонка контента. Контейнерные запросы @container vbody (780 / 560 / 400) переставляют рекомендации и сетки.
Режимы (карточки)one_profile · single_brand → карточки профилей; two_brands (2+) → карточки брендов с разворотом. Один компонент, флаг scope.show_brand_level (§2).
ФазыАгент: verdict / thin (204) / loading (скелет). Профиль: synced / importing / error / disconnected. Пусто (0 профилей за всю жизнь) → /app/onboarding, на экране не рисуется.

2вердикт — звездаКонцепт V3 — три этажа брифинга

V3 читается как утренний брифинг: сначала тихая личность (кто это), потом громкий вердикт Агента по всему портфелю (что происходит и что делать), и только под ним — «Доказательства»: тоталы и каналы, на которые опирается вывод. Иерархия внимания перевёрнута относительно «дашборда цифр»: цифры обслуживают вывод, а не наоборот.

4Личность аккаунта

Тихая, потому что вердикт — звезда. Марка-квадрат + имя пользователя («Alex Rivera», не «X's workspace») + тариф-бейдж (PRO; биллинг не подключён — это только бейдж) + строка масштаба «N профилей · M брендов · сети». Бренды в строке — только при 2+.

5без «Агента»Сайдбар + навигация аккаунта

Глобальная навигация уровня аккаунта. Меню: Дашборд · [Бренды — только при 2+] · Настройки. Пункта «Агент» нет (решение C, §18): дашборд и есть его дом. В подвале — кнопка аккаунта (email + тариф → настройки, выход).

Что изменилось. Раньше Агент жил в двух местах — герой на дашборде и отдельный пункт меню «Агент». Теперь пункт убран из сайдбара и мобильного бара; сам чат остаётся «глубоким» экраном, доступным только с дашборда. Полностью — §18.

6Переключатель профилей + breadcrumb

Плоский быстрый переключатель — один клик к любому профилю независимо от бренда (в режиме 2+ профили сгруппированы подписями брендов, но список остаётся плоским). Статус-точка справа = синхронизирован / импорт / сбой / отключён. Breadcrumb на этом экране = «Аккаунт».

7heroГерой-брифинг — вердикт

Звезда экрана (.v3-hero, accent-полоска слева, --radius-xl, --shadow-md). Шапка: марка-Агент + «Агент аккаунта» + «По всему портфелю» + кнопка «Открыть Агента» (→ чат). Тело: вердикт крупно (1.75rem, text-wrap:balance) + пояснение (max 68ch) + data-чипы (реальные цифры, тон up/down/accent) + строка «На основе:» + подпись «Рекомендации» + 3 рекомендации (danger/accent-тон, кликабельны) + ask-строка «Спросите совет по портфелю…» (→ чат с засеянным вопросом).

8204Тонкое состояние — данных мало

Агент вернул 204 (нет вывода): честное приглашение вместо выдуманного вердикта. Заголовок «Пока рано делать вывод…», короткое пояснение, подпись «Например» + 3 вопроса-стартера (каждый уводит в чат с засеянным вопросом), ask-строка. Без чипов и цифр — нечего привязывать.

9«Доказательства» — четыре тотала

Заголовок «Статистика · Профили / Бренды» + пояснение «Цифры и каналы, на которые опирается вывод». Сетка 4×: Подписчики +дельта · Просмотры 7д · Посты нед · Ответы (с акцентом — «требует тебя»). Суммируется только по живым профилям; нет числа → «—».

10Карточки — режим «1 бренд» (профили)

Дефолт почти у всех. Карточка профиля: аватар + значок сети + @никнейм + сеть, метрики (подписчики / просмотры) или состояние синка. Клик → дашборд профиля (Студия). Пометка «Настроить голос» — когда has_voice=false и синк готов.

10.1 — Статусы профиля в карточке: importing · sync-error · disconnected

Импорт → спиннер + % + «≈ пара минут». Сбой синка → приглушённо + «Повторить» (danger). Отключён → «Переподключить». Тот же stateBlock используется и в развёрнутом бренде (§11.1) — статус виден в обоих местах.

11Карточки — режим «2+ брендов» (бренды)

Появляется со вторым брендом. Карточка бренда: контурно-квадратная марка + имя + «N профилей · тип», сводные метрики, стек аватаров и строка состояния («Все синхронизированы» / «N импортируется» / «N сбой синка»). Кнопка «Профили» раскрывает профили внутри карточки.

11.1 — Раскрытие бренда: статусы профиля внутри

Развёрнутый бренд показывает профили строками — importing, sync-error и disconnected видны прямо здесь (тот же статус, что на прямой карточке профиля). Доказывает требование «покажи статус и на карточке, и внутри развёрнутого бренда».

12Добавить бренд · профиль

Плитка-CTA в той же сетке (пунктир, accent). Лейбл зависит от режима: «Добавить профиль» при 1 бренде, «Добавить бренд» при 2+. Ведёт в пикер сети (Threads — живая, LinkedIn — «скоро»).

Доказательство критерия. Два запроса. GET /api/me/account → tenant + totals + scope + brands[] (с profiles[]). GET /api/me/account/advisor → вердикт (или 204). Клиент решает режим по scope.show_brand_level.

  • Пустой аккаунт (0 профилей) не доходит сюда — гейт ведёт в /app/onboarding.

19Чек-лист

  • Правило 1: ни один однострочник (тоталы, чипы, @никнеймы, имена брендов, счётчики, метки кнопок) не переносится — узкий десктоп (§14), мобильный, 320px. Не влезает → усечение, не разрыв. Вердикт — единственное балансируемое исключение.
  • Правило 2: текст русский; контейнеры держат немецкую длину (§14, локаль de в §3) без нарушения правила 1.
  • Порядок V3: Личность → Герой-вердикт → «Доказательства». Вердикт — звезда; тоталы и каналы — опора.
  • Агент (решение C): пункта меню «Агент» нет (§5, §18); ask-строка и «Открыть Агента» уводят в чат, засевая вопрос; чат — отдельный «глубокий» экран с возвратом.
  • Один компонент, два режима: 1 бренд → карточки профилей; 2+ → карточки брендов с разворотом. scope.show_brand_level.
  • Тонкое состояние (204): честное приглашение + 3 стартера, без выдуманного вердикта и цифр.
  • Статусы importing / sync-error / disconnected видны и на карточке профиля, и внутри развёрнутого бренда; «Повторить» / «Переподключить» на месте.
  • Честность: нет числа → нет чипа/карточки; отключённый профиль вне тоталов, но с «Переподключить»; тариф — бейдж (биллинг не подключён).
  • Сети — реальные монохромные логотипы (VK.netLogo), не глифы; аватар с монограммой-фолбэком.
  • Светлая + тёмная на токенах; ?demo=1 Tweaks: режим · Агент · состояние · локаль · тема (§3). Пустой аккаунт → онбординг, здесь не рисуется.
Конец спецификации. Парные документы: мобильный дашборд · все профили отключены · чат-Агент.
