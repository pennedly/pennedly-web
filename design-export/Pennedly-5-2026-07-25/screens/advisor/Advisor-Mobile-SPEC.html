Advisor /app/advisor — phone

The AI growth-advisor chat on a phone: ask about your growth and get concrete, data-grounded answers — what to post, why engagement moved, when to post — drawn from your stats, voice and recent posts. This spec fits the whole thing cleanly at 390px (checked at 360): a scrolling conversation of your messages and the advisor’s replies, replies carrying small data chips and actionable suggestions that hand off to the Studio composer, a docked composer with starter prompts, and the three phases — first-run, thinking, error. Read-only except the “Open in Studio” handoff. Same tokens and copy as the desktop spec; only the layout changes below 600px, on the decided shell (hamburger + drawer, no tab bar, composer docked above the safe area). Frames are the real component layer at 390px, light and dark.

pennedly-mobile.css advisor-app.jsx advisor-parts.jsx shell-parts.jsx #i-advisor
What stays grounded. Every substantive reply ties to real account signals — chips show the same numbers as Stats (views/likes/followers, best-time heatmap, viral-tier spread, top/flop posts), grounded by a “Grounded in: …” line; the voice role-book shapes the wording; recent posts and replies fill in specifics. No invented numbers — if data is thin, the advisor says so instead of guessing. Mobile is a layout pass; the only mutation is the Studio handoff.
Three phases — first-run / thinking / error. Unlike Stats, Advisor has an error state, but it’s an inline reply row with Retry — never a whole-screen banner. First-run shows a hero + starter prompts instead of an empty thread. Thinking is honest about what it’s reading.

4A conversation turn

Your message is a right-aligned accent bubble (no avatar — it’s you). The advisor’s reply is a left mark + prose (not a bubble): paragraphs, then data chips, a source line, and an optional suggestion card. Calm, editorial, specific.

Rules. User bubble ≤ 85% width, asymmetric bottom-right corner. Advisor prose runs full column width; <b> carries emphasis. The mark is the #i-advisor glyph in an accent tile.

5Data chips + grounding

Small pills inside a reply, each a real signal. Tone by meaning: up = success, down = danger, neutral / best-time = accent. The number matches its source screen exactly. A “Grounded in: …” line underneath names what the reply used — so the advice is checkable.

Local + honest. Times render in the viewer’s timezone; chips are live DOM text (localize, never clip). If a metric isn’t available yet, the advisor omits the chip and says so — no plausible-looking fabrications.

6→ StudioSuggestion → Studio handoff

Advice becomes action. A suggestion card carries a title, a one-line “why”, and buttons. “Open in Studio” hands a brief to the Studio Ideas composer (prefilled, with a “From your Advisor” banner); “Show me the data” opens the relevant Stats screen. On a phone the buttons stack full-width. This is the only mutation on the screen.

Advice stays advice. Advisor never posts or schedules itself — it only opens a draft in Studio, where the usual confirm rules apply. Control stays with you; the existing composer is reused, not duplicated.

7Composer + starters

Docked above the safe area, always visible: an auto-growing textarea + Send (primary, disabled while empty). On first-run (and after a cleared thread) a horizontally-scrollable row of starter prompts sits above it: “What should I post today?”, “Why did engagement drop?”, “Best time to post this week?”. Tapping one drops the prompt into the composer.

Rules. Composer dock has a top border + frosted bg over the safe-area inset. Textarea grows to ~96px then scrolls. Starter chips are flex:0 0 auto with a right-edge mask fade; ≥44px hit. Send is 36px (≥44 hit) and disabled until there’s text.

8States

first-runreadythinkingerror

First-run is a hero + starters (no empty thread); thinking is a pulsing-dots row with an honest label about what it’s reading; error is an inline reply row with Retry — the rest of the thread stays put.

10Web ↔ mobile

Desktop ( > 880 )

  • Fixed sidebar; 720px column; “Grounded in your data” pill in the topbar.
  • Thread centered (640 max); composer docked at the column foot.
  • Suggestion buttons sit in a row; starters wrap above the composer.

Phone ( ≤ 600 )

  • No sidebar/tab bar; hamburger → drawer (active = Advisor); composer docked over the safe area.
  • Thread full-width (14px gutters); user bubble ≤ 85%; chips wrap.
  • Suggestion buttons stack full-width; starters scroll horizontally.

11Localization & 360px

Title, pill, hero, starter prompts, reply text, chip labels, “Grounded in”, suggestion titles/CTAs, composer placeholder and the first-run/thinking/error copy all localize into 8 locales (en/ru/uk/de/es/fr/it/pt); DE/RU/UK run ~30–40% longer. The thread reflows; chips and suggestion buttons wrap (buttons already stack on a phone); starters scroll; the thinking label truncates. Numbers are tabular and locale-formatted; times in the viewer’s timezone.

360px behavior. No new breakpoint — gutters stay 14px; user bubble ≤ 85%; chips and the source line wrap; suggestion buttons are already full-width; starters scroll; the thinking label clips to “Reading your stats…”. The composer dock keeps its safe-area inset. The drawer stays min(82%, 312px) → ≈295px at 360.

12Checklist

  • Below 600px there is no sidebar and no tab bar — one top bar (hamburger far-left, “Advisor”, “Grounded in your data” sparkle pill) and a docked composer over the safe area.
  • Hamburger opens the left drawer (active = Advisor, Insight group, tester-gated) + account at its foot.
  • User message = right accent bubble (≤85%); advisor reply = mark + prose (not a bubble) with “PENNEDLY ADVISOR”.
  • Data chips tie to real metrics (up=success / down=danger / accent=info·time / muted=context); numbers match the source screen; glyph per metric; chips wrap.
  • “Grounded in: …” source line under the chips makes advice checkable.
  • Suggestion card: title + why + stacked “Open in Studio” (handoff brief to Studio Ideas) + “Show me the data” (to Stats). Only mutation.
  • Starter prompts on first-run: “What should I post today?” · “Why did engagement drop?” · “Best time to post this week?”; horizontally scrollable; tap fills the composer.
  • Composer docked: auto textarea + Send (primary, disabled while empty); ≥44px hits.
  • States: first-run (hero + starters) · ready (thread) · thinking (pulse dots + honest label) · error (inline row + Retry, not a banner).
  • No invented numbers; thin data → honest “not enough data yet”, no chip.
  • Labels wrap on long locales — never clipped; sanity-checked at 360px.
  • Correct in light and dark; no hardcoded colour.
