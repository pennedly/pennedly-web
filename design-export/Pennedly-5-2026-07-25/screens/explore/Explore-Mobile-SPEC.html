Explore patterns /app/patterns/explore — phone

Companion to Pattern study (which reads your posts). Explore is where you paste the text of posts you admire and Pennedly names the reusable writing move behind them — then rewrites each one in your own voice, with an option to fold the good ones into your role-book. Match to the real Explore.html: it is a paste → analyze → results tool, not a filter/search library — so there’s no filter row or separate detail view to adapt; each technique card is the full detail inline. Same tokens, content and flow as the desktop; only the layout changes below 600px, on the decided shell (hamburger + drawer, no tab bar, free bottom edge). Frames are the real component layer at 390px, light and dark.

pennedly-mobile.css explore-app.jsx explore-parts.jsx shell-parts.jsx ds/tokens.css
What does not change (and what isn’t there). Explore is paste-and-analyze: Pennedly never opens links or reads other accounts — it only reads pasted text, so the link/@handle caution + disabled Analyze are load-bearing. The only real action is Add to my voice (appends the do-rule to the role-book). There is no filter/search/category control and no separate per-pattern detail page in the desktop — so this spec adds none (per “match exactly what Explore.html does; prefer read-only”). Mobile is a layout pass; the only structural change is the shared app shell.

4The flow (not a filter library)

Explore is a tool, not a browse grid. The mobile flow is the desktop flow, stacked: paste admired posts → a short analyzing motion → result cards. There is no filter row to make sticky and no detail screen to push — the work is the paste box and the cards.

5fixInput — paste, not links

The input is the entry point. The phone version keeps every load-bearing affordance: the “paste the text, not links” notice, the textarea, the live sample counter, the link/@handle caution, the Analyze button, and the seed chips.

Before

The desktop foot puts the counter, the caution and the Analyze button on one line; on a phone they collide and Analyze wraps under a half-shown caution.

After

The paste foot stacks: counter line, then the caution (when a link is detected), then a full-width Analyze button. The textarea is 16px so iOS doesn’t zoom. Seed chips scroll horizontally at full size.

Rules. Sample counter turns success-green when ≥1 clean post is present (“N posts ready”). If the text contains a URL or @handle, the box goes warning-bordered, the caution appears, and Analyze is disabled — Pennedly reads words, not links. Seed chips (“Try a sample set”, “A hook that stopped you”…) fill the textarea.

6Technique card + detail

Each result card is the full technique — there’s no separate detail view, so the card holds everything: a kind tag + index, the named move, what it does, a quiet “why it works”, the exact line it was spotted in, the same move rewritten in your voice, and a mono do-rule with “Add to my voice”.

9Web ↔ mobile

Desktop ( > 900 )

  • Fixed sidebar; ~720px reading column.
  • Paste foot: counter + caution + Analyze on one row.
  • Transfer block may sit source / in-your-voice side by side.

Phone ( ≤ 600 )

  • No sidebar/tab bar; hamburger → drawer + account; free bottom edge.
  • Paste foot stacks; Analyze full-width; seeds scroll.
  • Transfer stacks: line-that-did-it above in-your-voice.

10Localization & 360px

The notice, counter, caution, step labels, card fields, do-rule label and button copy all localize into 8 locales; DE/RU/UK run ~30–40% longer. On a phone: “Analyze the craft” and “Add to my voice” wrap rather than clip; the caution wraps to multiple lines; seed chips scroll; the do-rule mono text wraps under its “do:” label if a locale runs long. Pasted post text + extracted patterns are content, not chrome — they wrap naturally.

360px behavior. No new breakpoint — the gutter stays 14px; the paste box and cards get ~30px narrower so the technique text and examples rewrap. The Analyze button is already full-width; “Add to my voice” drops below the do-rule on the narrowest locales rather than shrinking. The drawer stays min(82%, 312px) → 82% (≈295px) at 360.

11Checklist

  • Below 600px there is no sidebar and no tab bar — one 52px top bar with a hamburger far-left; title truncates before the results pill.
  • Hamburger opens the left drawer (active = Explore patterns) + account; bottom edge free.
  • No filter/search/category row and no separate detail view are invented — Explore is paste→analyze→results, matching Explore.html.
  • Input keeps the “paste the text, not links” notice; textarea is 16px; counter + caution + Analyze stack; seeds scroll.
  • A detected link/@handle warns and disables Analyze (Pennedly reads words, not links).
  • Analyzing shows the nib-write motion + 4 progress steps (the loading state).
  • Each technique card holds the full detail: kind + idx, name, technique, why, line-that-did-it → in-your-voice (stacked), do-rule + Add to my voice.
  • Add to my voice flips to “✓ Added to your voice”.
  • Empty result = “no moves to show” → back to paste; error banner has Retry.
  • Labels wrap on long locales — never clipped; sanity-checked at 360px.
  • Correct in light and dark; no hardcoded colour.
