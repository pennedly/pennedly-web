**Контекст.** Дашборд аккаунта (`/app/account`) это портфельная «домашняя»
над отдельными профилями: Аккаунт → Бренды → Профили, тестер-гейтед.
Выбран концепт **V3 «Советник»**: экран открывается как утренний брифинг,
в центре внимания AI-вердикт по всему портфелю, а тоталы и каналы стоят
ниже как «Доказательства». Нужен полный, готовый к 1:1 реализации SPEC:
все состояния, обе темы, десктоп + мобайл.

## Решение по советнику (продуктовое, вшить в дизайн)

Раньше советник жил в ДВУХ местах: герой-вердикт на дашборде И отдельный
экран-чат `/app/account/advisor` (пункт меню «Советник»). Раз теперь
дашборд И ЕСТЬ дом советника, **отдельного ПУНКТА МЕНЮ «Советник» больше
нет**. Но сам разговорный чат остаётся как «глубокий» экран.

Конкретно:
- **Убери пункт «Советник» из навигации** (сайдбар + мобильный drawer).
  В меню остаются: Дашборд · [Бренды — только при 2+] · Настройки.
- **Дашборд = вердикт-брифинг** (герой V3): вывод + разбор + data-чипы +
  «На основе:» + рекомендации.
- **Строка «Спросите совет по портфелю…»** на дашборде это «задать один
  вопрос»: отправка НЕ разворачивает диалог прямо на дашборде, а **уводит
  в чат-экран, засеяв первый вопрос**. Кнопка **«Открыть советника»** в
  шапке героя ведёт туда же (в чат).
- **Чат-экран остаётся** (тот же разговорный `/app/account/advisor`:
  многоходовой диалог, карточки-подсказки с «Открыть в Студии»), но
  попадаешь в него ТОЛЬКО из дашборда (строка/кнопка), не из меню. Дай
  этому экрану чёткий возврат на дашборд (крошка/кнопка «← к дашборду»),
  консистентный с V3. Полный редизайн чата НЕ нужен, только шапка-возврат
  и что он открывается с засеянным первым вопросом.

Итог: в навигации нет избыточного раздела, но сложный разговор получает
своё сфокусированное место. Смешивать многоходовой чат в один экран с
вердиктом + тоталами + каналами не надо.

## Что нарисовать (полный V3)

Порядок сверху вниз (по `variants/v3.js`):
1. **Личность аккаунта** (тихо, вердикт это звезда): марка-квадрат + имя
   пользователя (не «X's workspace») + тариф-бейдж + строка масштаба
   «N профилей · M брендов · сети» (бренды только при 2+).
2. **Герой-брифинг** (`.v3-hero`, accent-полоска слева, `--radius-xl`,
   `--shadow-md`):
   - шапка: марка-советник + «Советник» + «по всему портфелю» +
     кнопка **«Открыть советника»** (→ чат);
   - **вердикт** крупно (`1.75rem`, `text-wrap:balance`) + пояснение
     (`max 68ch`) + **data-чипы** (реальные цифры, тон up/down/accent) +
     строка **«На основе:»** + подпись «Рекомендации» + **3 рекомендации**
     (`.v3-reco`, danger/accent-тон иконки, кликабельны) + **ask-строка**
     «Спросите совет по портфелю…» + отправка (→ чат с засеянным вопросом).
   - **тонкое состояние** (советник отдал 204, данных мало): честное
     приглашение + 3 вопроса-стартера + ask-строка. **Без выдуманного
     вердикта и цифр.**
3. **«Доказательства»** (`.v3-evidence`): заголовок «Статистика · Профили/
   Бренды» + пояснение «Цифры и каналы, на которые опирается вывод» +
   **4 тотала** (сетка 4×, подписчики +дельта / просмотры 7д / посты нед /
   ответы-ждут с акцентом) + **решётка карточек каналов** (3 колонки) +
   плитка «Добавить бренд/профиль».

**Адаптивная иерархия** (обязательна): `scope.show_brand_level` →
1 бренд = карточки профилей; 2+ = карточки брендов (агрегат + стек
аватаров + счётчик «N профилей»), разворот в профили. Профиль-карточка
несёт: аватар + значок сети + @handle + метрики (подписчики/просмотры)
ИЛИ состояние синка. Пометка «нет голоса» когда `has_voice=false` и синк
готов (подтолкнуть «Настроить голос»).

## Состояния (все; свет + тьма; десктоп + мобайл)

- советник: **вердикт** / **тонкий-приглашение (204)** / **загрузка** (скелет);
- 1 бренд · 1 профиль (минимальный портфель);
- 1 бренд · несколько профилей;
- 2+ брендов (один развёрнут);
- профиль **импортируется** (состояние в карточке: спиннер + % + «пара минут»);
- профиль **ошибка синка** (приглушённо + «Повторить»); и в карточке, и внутри развёрнутого бренда;
- **смешанное** (живые + отключённый профиль с «Переподключить» в решётке);
- **все профили отключены** (портфель жив, полный хром, каждый бывший
  профиль карточкой с «Переподключить» + «Подключить ещё аккаунт»; это
  анти-«меня разлогинило», НЕ выброс в мастер) → это `Account-Dashboard-Empty-SPEC`;
- **немецкая длина** (одно состояние, ПРАВИЛО 2).

Состояние «совсем пустой аккаунт» (0 профилей за всю жизнь) на этом экране
НЕ рисуется, уводит в онбординг. Упомяни.

## Правила макета (критерии приёмки)

- **ПРАВИЛО 1**: однострочники (значения тоталов, чипы, @handle, имена
  брендов, лейблы кнопок, счётчики) не переносятся ни на какой ширине;
  дизайнить так, чтобы перенос был невозможен; многоточие крайняя
  страховка. Вердикт-заголовок это исключение (`text-wrap:balance`, он
  многострочный по смыслу), но НЕ должен ломать соседей. Доказать 390 / 320.
- **ПРАВИЛО 2**: ревью-копия русская, контейнеры держат 8 локалей (немецкий
  стресс ~1.3–1.5×); одно состояние с немецкими строками.
- Все строки через i18n-ключи (`acc.*`), русский не хардкодить.
- Обе темы; реальные логотипы сетей (`networks.tsx`), не глифы; аватар с
  монограммой-фолбэком. Контейнерные запросы (`@container`), как в V3.

## Чего НЕ делать

- Не смешивать с другими концептами (V1/V2/V4/V5).
- Не встраивать многоходовой чат в дашборд (см. решение C: ask-строка
  уводит в чат-экран).
- Не оставлять пункт меню «Советник».
- Не выдумывать функций (биллинг не подключён, тариф это бейдж); не рисовать
  фейковые метрики / пустые карточки «под данные».
