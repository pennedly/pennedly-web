«Кому отвечать» — мультивыбор · с защитой от конфликтов

Новая версия секции «Кому отвечать»: вместо одиночного выбора — мультивыбор, но с жёсткими правилами под бэкенд. Две группы плиток: точные фильтры (детерминированный enum — выбор одной) и по смыслу комментария (LLM-промпт — любая комбинация). Группы взаимоисключающи; переключение мягкое, с inline-подсказкой. Текстовые пресеты склеиваются в одно OR-описание, которое можно поправить руками. FE-only: новых полей в бэкенде нет.

enum reply_audience · текст audience_prompt A — точные фильтры · выбор один B — по смыслу · комбинируются (OR) A и B взаимоисключающи web + mobile · light + dark копия — через i18n
Группа A · точные фильтры
Выбор одной — как радио
3 детерминированных enum-фильтра (fans · all_except_trolls · questions). Не комбинируются ни между собой, ни с текстом — enum игнорирует audience_prompt. Круглая отметка = «один из».
Группа B · по смыслу
Любая комбинация — как чекбоксы
7 смысловых пресетов. Выбранные склеиваются в один OR-промпт → reply_audience=custom + audience_prompt. Квадратная отметка = «несколько». «Свой вариант» — тоже пункт группы B.
01

Дефолт · как стартует сейчас

На старте выбран один точный фильтр — «Всем, кроме троллей» (как в текущей одиночной версии). Видны обе группы с заголовками и правилами «выбор один / можно несколько»; круглая и квадратная отметки сразу объясняют разницу. Под сеткой — read-only заметка про точный фильтр.

Light · web · группа A = «Всем, кроме троллей»
02

Группа A · точный фильтр + read-only заметка

Выбран фильтр «Фанатам и подписчикам». Поля описания нет — вместо него read-only заметка: точный встроенный фильтр применяется напрямую, текст-промпт не используется. Любая другая плитка A заменяет выбор (радио).

Light · web · группа A = «Фанатам и подписчикам»
03

Группа B · 2 пресета → склеенное OR-описание

Выбраны «Хвалит и благодарит» + «Спрашивает про цену/продукт». Под сеткой появляется одно поле «Описание аудитории», куда авто-склеиваются описания выбранных плиток через выделенное «или». Поле редактируемое, есть «Открыть в отдельном окне». Уйдёт как reply_audience=custom + промпт.

Light · web · группа B = хвалит + цена
04

Группа B · 3 пресета + «Свой вариант»

Три смысловых пресета плюс «Свой вариант» с дописанным куском. Свободный текст становится ещё одним OR-пунктом и приклеивается к склейке. Тоггл любой плитки добавляет/убирает свой фрагмент в описании.

Light · web · по делу + цена + история + свой вариант
05

Только «Свой вариант» · пустое поле

Выбрана единственная плитка «Свой вариант», текст ещё не введён — поле описания пустое, с плейсхолдером. Как только пользователь напишет, текст станет OR-пунктом (единственным).

Light · web · только «Свой вариант», поле пустое
06

Момент конфликта · A снимает B

Был мультивыбор в группе B — пользователь тапнул плитку группы A. Без модалки: весь выбор в B авто-снят, выбран точный фильтр, под сеткой — мягкий неблокирующий нотис «Точный фильтр работает один — описания отключились» (с крестиком, исчезает сам). Зеркальный случай — выбор B снимает A — даёт нотис «Описания комбинируются — точный фильтр снят».

Light · web · тапнули «Всем, кроме троллей» поверх мультивыбора B
07

Описание изменено вручную

Пользователь поправил склейку руками. Появляется бейдж «изменено вручную», а в подвале поля — мягкий «Собрать заново из выбранного». Тоггл плиток не затирает ручную правку: пока бейдж активен, описание остаётся пользовательским, пока он сам не пересоберёт.

Light · web · ручная правка поверх склейки
＊

«Открыть в отдельном окне»

Кнопка из подвала поля открывает полноразмерное окно ввода со склеенным текстом — как в остальном редакторе. Можно дописать или переписать; «или» = любой из пунктов.

Light · web · окно ввода описания открыто

Строки под перевод

Вся видимая копия — через i18n (EN — фолбэк). Ниже — нейтральные ключи-плейсхолдеры, которые ведёт переводчик; в этом макете показаны русские значения как пример.

replyAudience.groupA.title → «Точные фильтры»
replyAudience.groupA.rule → «выбор один»
replyAudience.groupB.title → «По смыслу комментария»
replyAudience.groupB.rule → «можно несколько»
replyAudience.or → «или» · OR-разделитель в склейке
replyAudience.conflict.aClearsB → «Точный фильтр работает один — описания отключились»
replyAudience.conflict.bClearsA → «Описания комбинируются — точный фильтр снят»
replyAudience.desc.manualBadge → «изменено вручную»
replyAudience.desc.regen → «Собрать заново из выбранного»
replyAudience.desc.placeholder → «опиши своими словами, кому отвечаем…»
