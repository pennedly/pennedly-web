Карточка-действие советника · слой «в один клик» над платформой

Советник Pennedly отвечает прозой И прикладывает карточку-действие с превью того, что изменится, и одной кнопкой «Применить». Клик применяет изменение через уже существующую операцию платформы. Это ОДИН переиспользуемый паттерн (единый корпус + типизированное содержимое), а не N разных карточек: действий много и они растут, но все выглядят как один компонент с разным наполнением. Карточка весомее обычных подсказок «Открыть в Студии» (акцентная кромка и иконка), потому что применяет реальное изменение — но живёт в потоке чата, это не модалка.

+ .adv-act (единый корпус) 5 типов · растёт все состояния свет + тьма 390 · 320 ru · de (8 локалей) account/action-card.css
Один корпус, типы = наполнение. Шапка (иконка типа + тип-чип + заголовок) → тело-превью (что изменится: строки-факты, черновик или пара «было → станет») → «На основе:» (опц.) → плашка режима → строка профиля (только портфельный) → действия. Несколько карточек в одной реплике складываются в чистую вертикальную стопку.
Честность полей. Рисуем только пришедшие поля: нет target_account → строки профиля нет; нет grounded → строки «На основе» нет; есть change → рисуем «было → станет». Разрушительное (удалить / дисконнект / биллинг) карточками не применяется — таких типов в каталоге нет. Дефолт для постинга — «на ревью», не авто-постинг.

1Что это — слой «в один клик»

Автор пишет естественной фразой совет-или-задание. Советник отвечает прозой и прикладывает карточку: короткое превью + один клик. Не визард, не форма настроек — короткий предпросмотр реального изменения прямо в разговоре.

Что этоПереиспользуемый элемент внутри существующего экрана чат-советника — не новый экран. Корпус .adv-act, наполнение по типу.
Где живётВ потоке чата, сразу под прозой ответа. Портфельный /app/account/advisor и профильный /app/advisor. Не модалка, не визард.
ВесВесомее подсказки .adv-suggest «Открыть в Студии»: акцентная левая кромка 3px + акцентная иконка-плитка — сигнал, что клик применяет реальное изменение.
КликПрименяет изменение через уже существующую операцию платформы (рутина → Автопилот, правило → Голос, пост → Календарь, ответы → настройки ответов).
Ориентир по тонуПримитив «предложил → применил в один клик» уже есть в недельном аудите (ChangeCard) — спокойный, честный, обратимый.

3anatomyЕдиный корпус

Один корпус для всех типов. Сверху вниз: шапка → тело-превью → «На основе» (опц.) → предупреждение (опц.) → плашка режима → строка профиля (портфельный) → действия. Пример — routine со всеми частями (включая мягкое предупреждение).

Шапка.adv-act-ico (акцентная плитка, иконка типа) + .adv-act-kind (тип-чип «Рутина / Автоответы / Правило голоса / Пост / Расписание») + .adv-act-title (заголовок действия, не переносится).
Тело-превью1–4 строки «что изменится» (иконка + короткий факт). Для черновика (schedule_post) — .adv-act-draft (текст поста, 3 строки max). Для до/после (cadence, voice_rule) — компактная пара .adv-act-change «было → станет».
На основе (опц.).adv-act-grounded — тихая подпись с искрой, только если действие обосновано данными («на основе: просмотры за 7д»).
Предупреждение (опц.).adv-act-warn (--color-warning) — честная подпись о побочном эффекте (напр. «поднимет лимит постов»). Не ошибка.
Плашка режимаЗаметная, но спокойная. review (routine, schedule_post): «На ревью: пост идёт черновиком». config (auto_replies, voice_rule, cadence): «Применится сразу · откат в <разделе>».
Строка профиля.adv-act-profile — только портфельный советник: аватар сети + @handle + затрагиваемый профиль. В профильном профиль очевиден — строку не показываем.
ДействияОсновная кнопка с глаголом по типу (Создать / Включить / Применить / Запланировать) + вторичная «Настроить» (в редактор, предзаполненный) + тихая «Отмена».

5Все состояния

предложеноприменяетсяпримененоошибкамягкое предупреждение

Предложено — кнопки активны. Применяется — основная в загрузку (спиннер + «Применяю…»), карточка disabled, лэйаут не дёргается. Применено — карточка сворачивается в тихую строку: галочка + «Готово» + ссылка в нужный раздел. Ошибка — inline-строка на --color-danger + «Повторить», карточка возвращается в «Предложено». Мягкое предупреждение — тихая подпись под превью.

6Несколько карточек в одной реплике

Одна реплика советника может нести несколько действий. Задание «настрой автопостинг и автоответы» → две карточки подряд, каждая самодостаточна. Паттерн чисто складывается в вертикальную стопку (.adv-act-stack).

7не модалкаВ потоке чата

Полный ход: реплика автора (accent-пузырь) → проза советника → карточка-действие. Карточка живёт в ленте, не всплывает поверх. Вокабуляр 1:1 с чатом (.adv-row, .adv-ai, .adv-userbubble).

8Профильный ↔ портфельный

Единственная разница — строка профиля. В портфельном советнике (много профилей) карточка показывает, какой профиль затронет; в профильном профиль очевиден — строку не рисуем. Марка сети — нейтральная (буквенная), без сторонних логотипов; при добавлении сети меняется только глиф.

Марка сети меняется, корпус — нет

9390 · 320Мобайл

Карточка во всю ширину. Кнопки ≥44px, основная приоритетна (первая, тянется на всю ширину). Однострочники не переносятся ни на 390, ни на 320 — усечение многоточием как крайняя мера. Свет + тьма.

10deЛокализация

Ревью-копия русская; контейнеры держат 8 локалей. Немецкий (~1.3–1.5× ru) — эталон длины: заголовок, строки превью, плашка режима и лейблы кнопок держат Правило 1 (не переносятся). Все строки через ключи adv.*.

11Контракт данных · правила · чек-лист

Советник возвращает опциональный actions[] рядом с обычным ответом. Рисуем строго по этим полям.

Правила макета

  • ОДИН корпус, типы = наполнение; несколько карточек складываются вертикально, каждая самодостаточна.
  • Однострочники (заголовок, строки summary, @handle, лейблы кнопок) не переносятся ни на какой ширине; усечение многоточием — крайняя мера. Доказано 390 / 320.
  • Обе темы на токенах; нейтральные марки сетей; аватар с монограммой fallback.
  • Мобайл: карточка во всю ширину, кнопки ≥44px, основная приоритетна.

Чего НЕ делать

  • Не модалка / не визард — инлайн-карточка в потоке чата.
  • Не показывать весь конфиг (триггеры / пороги) — это делает «Настроить», уводя в редактор.
  • Не выдумывать типы/поля вне контракта. Разрушительное картами не применяется.
  • Дефолт постинга — «на ревью» (ask), не авто-постинг.
  • Единый корпус .adv-act на 5 типах; наполнение по контракту actions[].
  • Весомее .adv-suggest (акцентная кромка + иконка), но в потоке чата, не модалка.
  • Состояния: предложено · применяется · применено (свёрнута) · ошибка + Повторить · мягкое предупреждение.
  • Режим: review (черновик на ревью) для routine/schedule_post; config (сразу · откат) для остальных.
  • Строка профиля только в портфельном; честность полей (нет поля → нет строки).
  • Свет + тьма; 390 / 320 без переносов; ru + de (эталон длины).
  • Несколько карточек в одной реплике складываются в чистую стопку.
Конец спецификации. Парные документы: портфельный чат · профильный чат.
