Сценарии /app/scenarios — телефон

Телефонный проход переработки навигации. Те же четыре явные поверхности, что и на десктопе, но как полноэкранный drill-down: каждый уровень — свой экран с шевроном-назад в топбаре, дом всегда «Мои сценарии». В редакторе и конструкторе — sticky-панель действий снизу. Реальный продуктовый слой при 390px, светлая и тёмная, проверено на 360. Демо — нейтральный креатор. OFF по умолчанию.

scenarios-mobile-redesign.js scenarios-mobile.css scenarios-mobile-redesign.css + scenarios-mobile-ia.css
Что переработано. Один экран с тремя видами без явного «где я» → drill-down по четырём поверхностям с шевроном-назад. Дом «Мои сценарии» делит сценарии на Активные и На паузе с количеством. Каталог — отдельный экран с примером генерации на каждой карточке и заметным «с нуля». Создание «с нуля» — конструктор (пост и/или ответ) со sticky-панелью. Включение — через подтверждение (bottom-sheet), выключение — мгновенно. Часы — в таймзоне аккаунта.

1Экран и карта навигации

Дом = «Мои сценарии». Каждая поверхность глубже — отдельный полноэкранный шаг с шевроном-назад в топбаре. Первый вход (нет сценариев) → A; возвращающийся → B.

Маршрут/app/scenarios (дом B; пусто → A) · …/catalog (C) · …/new (D) · …/:id (редактор) · …/:id/activity. tester-gated · OFF by default.
НавигацияDrill-down. Топбар уровня: шеврон-назад + заголовок поверхности. Дом — гамбургер + «Сценарии» + статус-pill + ＋.
ДесктопДве колонки + крошки. См. Scenarios-WEB-SPEC.html.
Сверху вниз (дом)Статус-бар → top bar (гамбургер · «Сценарии» · «N активны» · ＋) → лимит/день → секция «Активные» (N) → секция «На паузе» (N) → свободный край.
Сверху вниз (редактор/конструктор)Статус-бар → top bar (← · имя) → форма (скролл) → sticky-панель действий снизу (Сохранить и включить · Сохранить выключенным · Удалить).
Два действияТолько пост и ответ. «Опрос» — текстовый пост.

2Каркас: top bar + drawer

Shell общий. Дом: гамбургер → drawer (активная = Scenarios, repeat, Voice & automation, перед Autopilot); «Сценарии»; ≥1 включён → status-pill--success «N активны»; ＋ — каталог; таб-бара нет. Глубже — шеврон-назад вместо гамбургера.

3AСтарт / обучение

Первый вход и пустое состояние. Объясняет, что такое сценарий и зачем; «Как это выглядит» (карточки-примеры с реальным сэмплом); «Как это работает» в 3 шага; две кнопки «Посмотреть шаблоны» (→ C) и «Создать свой» (→ D). «Как это работает» доступно из дома всегда.

4BМои сценарии — дом

Дом и центр управления. Все сценарии с разделением: секция «Активные» (N) и секция «На паузе» (N) отдельными подзаголовками с количеством. Карта = живое предложение + большой статус «Активен»/«На паузе» + «сработал N× · Активность» + действия (Применить к… · Редактировать) + тумблер. Сверху лимит постов/день (дефолт 1).

4.1 — Пусто → ведёт в A (старт)

Нет сценариев → стартовый-обучающий экран A, а не пустая таблица.

4.2 — Карта: активна / на паузе

Выключенная карта прямым текстом: «Создан, но выключен — включи, когда готов». Reply — честно «проверяет каждые 15 минут».

4.3 — Центр управления: лимит + стэкинг

Лимит постов/день + предупреждение называет конкретные сценарии.

4.4 — Загрузка / ошибка / «скопировать»

Пусто = старт A (§4.1). Здесь — загрузка, ошибка и «Применить к…» (копия на другой аккаунт) — bottom sheet.

5CКаталог готовых шаблонов

Отдельный экран с «← Сценарии» в топбаре и заголовком «Готовые шаблоны». Сгруппированы по цели (ритм · вовлечение · повод · кампании). Каждая карта несёт имя, «что это и зачем» и конкретный пример того, что сгенерит (пост или ответ). Клик → редактор, предзаполненный шаблоном. Заметный вход «Создать свой с нуля» → D.

5.1 — Карта шаблона с примером

Бенефит + «Этот сценарий будет…» + обязательный блок-пример (пост / опрос / авто-ответ) + плашка «Отвечает людям». Акция — gated (замок).

6DКонструктор своих сценариев

Гибкий билдер с нуля. Название · КОГДА (5 режимов) · ЧТО ДЕЛАТЬ — постить и/или отвечать (свободные инструкции + подсказка «как написать хорошую инструкцию» с примером) · (опц.) условие · «что добавит» · превью + «Прогнать». Внизу — sticky-панель: «Сохранить и включить» / «Сохранить выключенным».

6.1 — Пост и/или ответ

Две карты-переключателя «Публиковать посты» / «Отвечать на комментарии». Можно собрать постовый, ответный или оба. Внизу «Соберётся в: …» — итоговый вид (инвариант).

7Редактор существующего та же форма

Открытие шаблона или «Редактировать» в доме → та же форма, предзаполненная. Шеврон-назад + имя в топбаре; sticky-панель действий снизу с «Удалить».

7.1 — Состояния правки

Раз в N дней + сохранение (спиннеры в sticky-панели); ошибка валидации (поле + баннер, превью-скелетон); удаление — bottom sheet с danger сверху.

8Момент включения через подтверждение

Включение — через подтверждение (bottom-sheet с выбором режима «Спроси меня» / «Автоматически»); выключение — мгновенно. Для ответов живым людям при «Автоматически» — мягкое согласие. Гейт «Автопостинг» показан здесь же inline.

9Превью в твоём голосе + «Прогнать»

Реальный пример + честная строка «В твоём голосе · на основе N постов» + «когда сработает». «Прогнать сейчас» создаёт только черновик, никогда не публикует.

10Активность

Человеческий журнал: «Опубликовал твой утренний вопрос в 9:02 — открыть», «Ответил Анне — открыть». В режиме «Спроси меня» — черновики, ждущие подтверждения. Достижимо со ссылки «сработал N× · Активность» на карте.

11Web ↔ mobile · 360px

Десктоп ( > 880 )

  • Сайдбар; внутренний топбар + крошки; редактор 2 колонки + липкое превью.
  • Включение — модалка; «применить к…» — поповер.

Телефон ( ≤ 600 )

  • Drill-down; шеврон-назад в топбаре; всё стопкой.
  • Редактор/конструктор — sticky-панель действий снизу.
  • Включение / удаление / копирование — bottom-sheet.

360px: гаттеры 14px; каталог и карты в 1 колонку; живое предложение и статус не клипаются; поля 16px / ≥44px; сегмент переносится; sticky-панель остаётся.

12Чек-лист

  • Drill-down по 4 поверхностям: A старт · B дом · C каталог · D конструктор; каждый уровень — экран с шевроном-назад; дом = «Мои сценарии».
  • A · старт: что такое сценарий и зачем; «как это выглядит» (примеры); «как это работает» в 3 шага; кнопки «Посмотреть шаблоны» (→C) и «Создать свой» (→D); это же — пустое состояние.
  • B · дом: секции «Активные» и «На паузе» с количеством; большой статус; «создан, но выключен» прямым текстом; лимит/день; стэкинг-предупреждение называет сценарии; «сработал N× → Активность».
  • C · каталог: отдельный экран, «← Сценарии», заголовок «Готовые шаблоны»; группировка по цели; пример генерации на каждой карте; клик → редактор предзаполнен; заметный «с нуля» → D.
  • D · конструктор: Название · КОГДА (5 режимов) · ЧТО ДЕЛАТЬ (пост и/или ответ — инструкции + подсказка с примером) · (опц.) условие · «что добавит» · превью + «Прогнать»; sticky-панель Сохранить/Сохранить и включить.
  • Инварианты: сценарий = одно из трёх; конструктор собирает любой («Соберётся в: …»); tester-gated, OFF по умолчанию; включение через подтверждение, выключение мгновенно; «Прогнать» → только черновик.
  • Бэкенд: только Пост/Ответ; опрос = текст; кап 1–10/день дефолт 1; 15-мин опрос для ответов; реактив = просмотры/подписчики.
  • Светлая и тёмная; только семантические токены; копи через i18n; 360px; sticky-панель + safe-area.
