7Чек-лист

  • Портфель жив: полный мобильный хром (верхний + нижний бар без «Советника»); не мастер, не «разлогинило».
  • Честный герой: «Все профили отключены» + «Переподключить» + ask-строка (в чат); без выдуманного вердикта.
  • Тоталы «—»: нет живого числа → прочерк; «Ответы» может быть 0.
  • Каждый профиль — карточка с «Отключён» + «Переподключить»; плитка «Подключить ещё аккаунт».
  • Правила 1–2: метки не переносятся на 390 / 360 / 320 (§5); немецкая длина держит (§6).
  • Светлая + тёмная; реальные логотипы сетей; аватар с монограммой. ?demo=1 Tweaks (§2).
