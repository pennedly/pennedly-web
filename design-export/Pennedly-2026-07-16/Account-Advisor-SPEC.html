Советник по портфелю — чат /app/account/advisor · вход только с дашборда

Разговорный чат-советник уровня аккаунта: многоходовой диалог, привязанные data-чипы, строка «На основе:» и карточки-подсказки с «Открыть в Студии». По решению C дашборд стал домом советника, поэтому отдельного пункта меню «Советник» больше нет — в этот чат попадают только с дашборда: со строки «Спросите совет по портфелю…», с вопроса-стартера или с кнопки «Открыть советника». Экран открывается с засеянным первым вопросом и даёт чёткий возврат «← Дашборд аккаунта». Сам чат не переделан — тот же компонент и вокабуляр (account-screens.js, .adv-*); новое здесь — только шапка-возврат и засев вопроса.

+ шапка «← Дашборд» + засев вопроса − пункт меню «Советник» чат без редизайна account-screens.css
Тот же чат — только вход и возврат другие. Тело диалога (закреплённый вердикт, реплики, проза, .adv-chip--up/down/accent, «На основе:», карточки-подсказки, композер) — без изменений, бэкенд-контракт совпадает с профильным советником. Изменились две вещи: (1) убрана «Советник»-сайдбар-навигация — экран открывается как «глубокий» с шапкой-возвратом; (2) он открывается засеянным первым вопросом, пришедшим с дашборда.
Никакого пустого first-run «из меню». Раньше в чат можно было зайти пунктом меню и увидеть пустой hero. Теперь входа из меню нет: попасть сюда можно только с дашборда, а значит первый вопрос всегда засеян — экран открывается уже в диалоге (вопрос + генерация/ответ), а не с чистого листа.

1Идентификация экрана

«Глубокий» чат уровня аккаунта. Сверху вниз: шапка-возврат («← Дашборд аккаунта» + pill «На основе всего портфеля») → закреплённый вердикт → лента диалога → композер. Без сайдбара аккаунта — это сфокусированный экран, не пункт навигации.

Маршрут/app/account/advisor. Вход только с дашборда: строка «Спросите совет…», вопрос-стартер (в тонком состоянии) или кнопка «Открыть советника» в шапке героя. Tester-gated.
Тип«Глубокий» экран. Тот же компонент чата, что профильный /app/advisor, scope = весь портфель. Не в сайдбаре — пункта меню «Советник» нет (решение C).
Возврат«← Дашборд аккаунта» — явная шапка-возврат, консистентная с V3. Дашборд = взгляд, этот чат = разговор.
ОткрытиеС засеянным первым вопросом. Отправка со строки дашборда / клик по стартеру / кнопка героя приводят сюда, подставив вопрос — экран открывается уже в диалоге.
Ширинаreading — лента центрирована (620 max), композер прилеплен снизу, вердикт закреплён сверху.
Фазыready (засеяно → ответ) · thinking (генерация первого ответа) · thin (тонкие данные — честно) · error (inline + Retry).

2liveПолный экран в контексте

Весь экран: шапка-возврат «← Дашборд аккаунта», закреплённый вердикт, диалог, открытый засеянным вопросом (помечен «Засеяно с дашборда»), и композер. Свет + тьма.

3newШапка-возврат «← Дашборд аккаунта»

Единственный новый элемент хрома. Слева — кнопка возврата с маркой аккаунта и подписью «Дашборд аккаунта»; справа — pill «На основе всего портфеля» и переключатель темы. Консистентно с V3 (те же токены, форма марки, скругления).

4seedОткрывается засеянным вопросом

Три входа с дашборда засевают первый вопрос — экран открывается уже в диалоге (вопрос + генерация ответа), а не с пустого листа.

Дашборд · ask
«Спросите совет…»

Отправка строки уводит сюда, подставив текст пользователя как первый вопрос.

Дашборд · стартер
Вопрос-стартер

В тонком состоянии (204) клик по стартеру засевает его текст.

Дашборд · кнопка
«Открыть советника»

Кнопка в шапке героя открывает чат (с последним вердиктом закреплённым сверху).

Чат
Открыт засеянным

Первый вопрос уже в ленте, советник генерирует ответ. Возврат «← Дашборд аккаунта».

5heroЗакреплённый вердикт

Портфельная сводка, что не скроллится: тот же компонент и источник вердикта, что герой дашборда — в проде обе точки читают один ответ /api/me/account/advisor, поэтому вывод согласован. Caption «Сводка портфеля» + scope, вердикт и привязанные чипы. (В этом SPEC чат показан на своём портфельном сценарии, поэтому пример-вердикт может отличаться от примера на дашборде — в бою источник один.)

6Анатомия ответа

Реплика пользователя (accent-пузырь справа) → ответ ассистента: марка + проза, data-чипы, строка «На основе:» и карточка-подсказка с «Открыть в Студии». Вокабуляр 1:1 с профильным чатом — не переделан.

Где ответ применяет изменение (рутина, автоответы, правило голоса, пост, расписание) — советник прикладывает карточку-действие .adv-act: единый корпус, превью «что изменится», одна кнопка «Применить», плюс строка профиля (какой профиль затронет). Полная спецификация: Advisor-Action-Card-SPEC.html.

7Все состояния

засеяно → ответгенерациятонкие данныеerror

Вердикт закреплён во всех состояниях; первый вопрос всегда засеян. ready — засеянный вопрос + ответ; генерация — «Читаю статистику портфеля…»; тонкие данные — честное «пока мало данных», без выдуманных чипов; error — inline-строка + Retry. Пустого «first-run из меню» больше нет.

8решение CМаршрутизация

Продуктовое решение, вшитое в дизайн. Дашборд — дом советника; отдельного пункта меню нет; сложный разговор получает своё сфокусированное место.

Пункт меню «Советник»Убран из сайдбара и мобильного бара (см. дашборд §5, §18). Меню: Дашборд · [Бренды при 2+] · Настройки.
Вход в чатТолько с дашборда: ask-строка · вопрос-стартер · кнопка «Открыть советника». Каждый засевает первый вопрос.
ВозвратШапка «← Дашборд аккаунта» — явный выход обратно на дашборд.
РазделениеДашборд = взгляд (вердикт + тоталы + каналы); чат = разговор (многоходовой). Не смешиваются в один экран.
Итог. В навигации нет избыточного раздела, но глубокий разговор получает сфокусированный экран с ясным возвратом. Многоходовой чат не встраивается в дашборд.

9Локализация · Web ↔ Mobile

Вся копи в 8 локалях (en·ru·uk·de·es·fr·it·pt); ru — ревью, de — эталон длины. Числа в чипах tabular; @никнеймы LTR. Немецкая длина держит шапку-возврат и композер.

Десктоп

  • Сфокусированный экран, колонка 720; шапка-возврат сверху; вердикт закреплён; лента центрирована (620), композер снизу.

Телефон

  • Шапка-возврат компактно; вердикт закреплён; чипы скроллятся вбок; композер-док. Полный проход — Account-Advisor-Mobile-SPEC.html.

10Чек-лист

  • Вход только с дашборда: ask-строка · стартер · «Открыть советника». Пункта меню «Советник» нет (решение C).
  • Открывается засеянным первым вопросом — экран уже в диалоге, без пустого «first-run из меню».
  • Возврат «← Дашборд аккаунта» — явная шапка, консистентная с V3.
  • Чат не переделан: закреплённый вердикт + реплики + проза + .adv-chip--* + «На основе:» + карточки-подсказки «Открыть в Студии»; бэкенд-контракт совпадает.
  • Data-чипы привязаны к реальным сигналам портфеля; никаких выдуманных чисел; тонкие данные — честно.
  • Состояния: засеяно→ответ · генерация · тонкие-данные · error (inline + Retry). Вердикт закреплён везде.
  • Светлая + тёмная на токенах; 8 локалей без клиппинга (эталон de).
