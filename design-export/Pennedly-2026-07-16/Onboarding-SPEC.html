Онбординг /app/onboarding — пиксель-в-пиксель

Дотошная спецификация full-screen мастера без app-shell (как Login): топбар, степпер Connect·Voice·Done и карточка текущей стадии по центру. Это многосостоятельный флоу — задокументированы АБСОЛЮТНО все стадии, под-состояния, варианты входа, темы и анимации, отдельно для веб- и мобильной версий. Все значения взяты из реального дизайна.

onboarding-app.jsx onboarding-parts.jsx onboarding-data.jsx onboarding-icons.jsx onboarding.css ds/tokens.css ds/components.css
Стейт-машина одним взглядом. Стадии: connect → choose → {analyze | scratch} → done. Степпер-индексы: connect=0, {choose,analyze,scratch}=1 (всё это шаг «Voice»), done=2. Вход first-run начинается с connect (показ «Skip for now»); вход revisit начинается с choose (Connect уже «done», показ «Back to Settings»). Режим preview (?preview=1 или твик) превращает done в read-only «каким был бы голос».

1Идентификация экрана

Маршрут, назначение, условия показа (first-run vs revisit vs preview), раскладка сверху вниз.

Маршрут/app/onboarding · тестер-превью /app/onboarding?preview=1
ТипFull-screen мастер, без app-shell (как Login): свой сфокусированный layout, <Sidebar> НЕ рендерится.
НазначениеПодключить аккаунт Threads и задать Pennedly стартовый голос, чтобы будущие черновики звучали как пользователь.
First run (forced)entry≠"Revisit" → firstRun=true. Старт со стадии connect, connectStatus=idle, connected=false. В топбаре «Skip for now».
Revisit (из Settings)entry="Revisit" → firstRun=false. Старт со стадии choose; Connect помечен как уже пройденный (степпер шаг 1 = done, текущий = Voice). В топбаре «Back to Settings» → Settings.html.
Preview (тестер)?preview=1 ИЛИ твик preview=true. Флоу выполняется «по-настоящему», но НИЧЕГО не сохраняется. Стадия done рендерит read-only голос. В топбаре пилюля «Preview · nothing is saved» + «Back to Settings».
Корневой контейнер.ob → min-height:100%; display:flex; flex-direction:column. Фон: радиальный блик radial-gradient(120% 80% at 50% -10%, mix(surface 60%, transparent) 0%, transparent 60%) поверх --color-bg.

Раскладка сверху вниз

  1. Топбар .ob-top — бренд (логотип 30 + «Pennedly») · [revisit/preview: «Back to Settings»] · [preview: пилюля] · спейсер · действия (Skip[first-run] + кнопка темы).
  2. Сцена .ob-stage — центрирует по вертикали и горизонтали: степпер .stepper + карточка .ob-card (текущей стадии).

3Раскладка и адаптив — ВЕБ vs МОБАЙЛ

Ширина карточки (обычная vs --wide), паддинги, breakpoints, сетки/флексы и что меняется на мобилке.

3.1 — Ширины и breakpoints

ПараметрЗначение
Карточка обычная .ob-cardmax-width 540px · padding 36px 36px 30px · radius-2xl 28px
Карточка широкая .ob-card--widemax-width 600px (стадии scratch и done-preview)
Сцена .ob-stage padding8px 24px 56px (центрирование по обеим осям)
Топбар padding20px 24px
Breakpoint ≤ 560pxединственный. См. ниже что меняется.

3.2 — Что меняется на ≤ 560px

ВЕБ (> 560px)

  • Карточка: padding 36px 36px 30px, radius 28px (--radius-2xl).
  • Заголовок стадии: --text-h1 = 32px.
  • Степпер: подписи .step-label видны; линии .step-line = 28px.
  • Ряд действий: в одну линию, кнопка .btn--lg по своему контенту.

МОБАЙЛ (≤ 560px)

  • Карточка: padding → 26px 20px 22px, radius → 20px (--radius-xl).
  • Заголовок стадии: --text-h2 = 24px (было 32px).
  • Степпер: подписи скрыты (.step-label{display:none}); линии .step-line → 16px. Остаются только кружки + линии.
  • Ряд действий: flex-wrap:wrap; .btn--lg → width:100% (на всю ширину).
  • Сцена/топбар padding не переопределяются media-query (остаются 24px) — карточка сама сужается до 100% минус padding сцены.
Адаптив контента стадий — флюидный, без своих breakpoint'ов: все внутренние блоки (trust, choices, analyze-steps, поля, recap, pv) — вертикальные flex-column и тянутся по ширине карточки. Чипы/стартеры/подсказки переносятся через flex-wrap:wrap. Отдельных media-query у них нет — перенос происходит естественно при сужении карточки.

7Чек-лист проверки

По каждому состоянию «убедись, что X = ровно Y» + сквозные проверки.

7.1 — Оболочка (топбар + степпер + сцена)

  • Нет app-shell / сайдбара — только .ob с топбаром и центрированной сценой.
  • Топбар padding = 20px 24px, gap 12; логотип 30×30 radius 10/shadow-sm; «Pennedly» 19px/w600.
  • Степпер: 3 узла, .step-dot 26×26, .step-line 28×1, margin-bottom 26.
  • current-узел: dot bg+border #171717, текст #efedea; done-узел: dot success + <IcCheck 14>.
  • Сцена центрирует карточку по обеим осям; padding 8px 24px 56px.
  • Карточка 540px (обычная) / 600px (scratch, done-preview); padding 36/36/30; radius 28px; shadow-lg.

7.2 — First run vs Revisit

  • First run стартует на connect (idle); виден «Skip for now»; на choose есть кнопка «Back» → connect.
  • Revisit стартует на choose; Connect-узел = is-done ✓, текущий = Voice; виден «Back to Settings» → Settings.html; на choose НЕТ «Back».
  • Revisit: connected=true, connectStatus=connected; при too-few chosen сразу = scratch.
  • Правило: showSkip = firstRun && !preview && stage∉{done,analyze}; showBack = (!firstRun||preview) && stage≠analyze.

7.3 — Connect (idle / connecting / connected)

  • idle: .step-mark.brand = логотип 56 (r16); 3 trust-строки (eye/check/lock), иконки 15 в плитке 26×26 radius-sm.
  • idle-кнопка = «Connect Threads account» + <IcAt 17>, height 46, radius 10.
  • connecting: кнопка disabled (opacity .5), <spinner 16> + «Connecting…»; через 1500ms → connected.
  • connected: инсет .connected (bg surface-2, radius-lg 14, padding 13/14), Avatar 42, имя 13/w600, handle·followers 12/subtle.
  • connected: success-пилюля = .status-pill--success «Connected», color #2c7350, dot 7×7; кнопка → «Continue» + <IcArrowRight 17>.

7.4 — Choose (enough / too-few)

  • 2 карточки .choice (analyze, scratch), gap 12, padding 18, radius-lg 14; иконки 42×42 (IcScan/IcPen 20).
  • enough: Analyze активируема, бейдж «Recommended» (accent), виден meta «Takes about a minute».
  • too-few: Analyze = .choice--disabled (opacity .72, bg surface-2, cursor default); вместо бейджа — «Needs 15 posts» + <IcLock 12>.
  • too-few: причина в desc содержит «at least 15», «{handle}», «has 6»; meta и check скрыты; выбор форсится на scratch.
  • active-карточка: border #171717 + box-shadow 0 0 0 1px #171717; иконка инвертирована; .choice-check opacity 1.
  • hover (не disabled): border mix(text 18%), bg surface-2.
  • «Continue» disabled пока selected пуст.

7.5 — Analyze (todo / active / done → auto)

  • Перо .nib 40×40, анимация nib-write 1.5s infinite (каноническая из components.css).
  • 3 шага, .analyze-steps max-width 340, .an-step padding 11/4 + border-top (кроме первого).
  • active-шаг: .sp спиннер 11×11 (border 2px), tick accent-рамка/цвет; label text/w500.
  • done-шаг: <IcCheck 13>, tick bg+border success, label text.
  • todo-шаг: точка 5×5 currentColor opacity .5; tick border border/bg surface/color subtle.
  • Тайминг: шаги по 1100ms, после последнего пауза 800ms → авто-переход на done (mode=analyze).
  • На analyze не показаны ни Skip, ни Back.

7.6 — Scratch

  • Карточка --wide (600px). 3 field-group (margin-top 20, первый 24).
  • textarea .ta: min-height 92, padding 11/12, radius 10; focus = border accent + shadow 0 0 0 3px mix(accent 18%).
  • 2 стартера с dashed-рамкой; клик вставляет пример и фокусирует textarea; подпись = 42 символа в «…».
  • chip-инпут: focus-within = border accent + shadow 3px; Enter добавляет, Backspace на пустом удаляет последний; дубликаты игнор (регистронезависимо).
  • avoid-чипы danger-вариант: bg mix(danger 9%), border mix(danger 26%), color mix(danger 75%,text).
  • подсказки .suggest исчезают после добавления; disabled = opacity .4.
  • «Create my voice» disabled пока desc пуст ИЛИ нет write-topics (avoid опционально).

7.7 — Done (обычный)

  • .done-mark 64×64 success, <IcCheck 30>, анимация pop-in (scale .82→1).
  • connected → заголовок «You're all set, {Имя}.»; skipped → «You're good to go for now.».
  • recap: 2 строки, ико-плитки 30×30 (radius-sm), .recap-ok галочка success там, где есть значение.
  • voiceLabel = scratch:«Built from your description» / analyze:«Analysed from your posts» / —:«Set up later».
  • Действия: «Refine your voice» → Voice.html; «Go to Studio» → Studio.html.

7.8 — Done (PREVIEW тестер)

  • Карточка --wide; пилюля accent «Preview · nothing was saved».
  • Заголовок «The voice Pennedly would build»; источник по mode (scratch→«your description», иначе→«{handle}'s recent posts»).
  • 3 блока .pv: summary (вставка surface-2), themes (read-only .pv-chip), traits (.pv-list с success-галочками 14).
  • Действия: «Back to Settings» → Settings.html; «Run setup for real» → Onboarding.html.
  • Топбар: пилюля accent + «Back to Settings»; «Skip» скрыт.

7.9 — Тёмная тема

  • Класс .dark: фон #0a0a0a, карточка #171717, surface-2 #201f1d, border #2b2a27.
  • Primary-кнопки и активная choice-иконка инвертированы (bg #ededed / color #171717).
  • success → #5fbf8d (connected/done/analyze-done); accent → #9aacff (eyebrow, рекоменд., preview-пилюля, focus); danger → #ef8a80 (avoid-чипы).
  • Тени глубже (--shadow-lg = 0 20px 48px −16 /0.7).

7.10 — Адаптив ≤ 560px

  • Карточка padding → 26px 20px 22px, radius → 20px (--radius-xl).
  • Заголовок стадии → --text-h2 24px.
  • Степпер: .step-label скрыты; .step-line → 16px.
  • step-actions: flex-wrap; .btn--lg → width 100%.
  • Чипы/стартеры/подсказки переносятся (flex-wrap); контент не обрезается.

7.11 — Сквозные проверки

  • Токены вместо хардкода: в onboarding.css нет ни одного hex — всё через var(--color-*) / color-mix. Исключения только числовые литералы 11px (choice-rec/locked шрифт) и геометрия точек.
  • Центрирование: степпер и карточка центрированы .ob-stage (align+justify center); по горизонтали оба по центру колонки.
  • Причина у locked-Analyze: текст содержит точные числа need=15 и postCount=6 и handle — не общий «недоступно».
  • Skip vs Back взаимоисключающи и зависят от стадии по формулам §4.0 (на analyze — ни того, ни другого).
  • nib-write берётся из канонических keyframes ds/components.css §3.5 (не локальный nibwrite-алиас).
  • success-пилюля на connected = общий компонент .status-pill--success, не кастом.
  • Степпер-индекс верный: connect=0, choose/analyze/scratch=1, done=2; галочка на пройденных.
  • Радиусы из шкалы: 6/10/14/20/28 = sm/md/lg/xl/2xl; пилюли/точки/аватары = full.
  • Переходы/easing: только --duration-fast/base/slow (120/180/240) и --ease-standard/entrance.
  • Preview ничего не сохраняет — «Run setup for real» ведёт на чистый Onboarding.html.
