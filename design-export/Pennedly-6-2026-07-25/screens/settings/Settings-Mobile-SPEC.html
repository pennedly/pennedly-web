Pennedly · Mobile spec · per-screen

Settings /app/settings — phone

Account management: the signed-in identity, the connected Threads account(s), the UI language, appearance, and a danger zone. A settings-width screen, so the work on a phone is making each section fit and feel native — single column, clear headers, full-width rows, 44px controls, labels above fields. Danger actions are clearly separated and confirmed. Same tokens, content and backend rules as the desktop spec; only the layout changes below 600px, on the decided shell (hamburger + drawer, no tab bar, free bottom edge). Frames are the real component layer at 390px, light and dark.

pennedly-mobile.css settings-app.jsx settings-parts.jsx shell-parts.jsx ds/tokens.css
What does not change. Connected accounts come from the backend; disconnecting deauthorizes the Threads account and starts the data-deletion cascade (confirmed). Deleting the Pennedly account cascades everything (confirmed). Language sets the UI locale and mirrors to the server. Plan tier is shown but billing isn’t built yet — no upgrade/payment UI. No invented notification settings or profile editing. Account-switch and Log out live in the drawer foot (the shared shell), not on this screen. Mobile is a layout pass; the only structural change is the shell.

4fixSection pattern — the fix

Every settings group is a card: a header (title + optional description) over a body of full-width rows. On a phone each control gets the whole width; nothing sits in a cramped right column.

Before

Desktop label-on-left / control-on-right rows split the width; selects and account rows shrink and long locale labels collide with their control.

After

One column of section cards. Controls are full-width 44px; toggles right-aligned on their row; the language picker is a 2-up flag grid; account rows give the handle room and keep Disconnect reachable. Danger actions get their own danger-tinted card.

5Identity + language

Identity = avatar + email + plan badge (read-only; a note says billing isn’t available yet). Language = the 8 UI locales as flag + native + English buttons, in a 2-up grid; the active one is accent-ringed with a check.

6Connected accounts

Each connected Threads account is a row: avatar + display name (+ a “Primary” tag) + @handle, with a Disconnect (danger) button. “Connect another account” is a full-width button at the foot. A zero-state shows the connect call-to-action.

7Appearance + danger zone

Appearance is a light/dark toggle row. The danger zone is a separate danger-tinted card: deleting the Pennedly account is a full-width danger button (confirmed in a sheet). Disconnecting an account is also a danger action, surfaced per-row above.

8Confirmations

Both destructive actions confirm in a bottom sheet (the desktop’s inline/modal confirm folded to a phone). Disconnect explains the deauthorize + data-deletion; delete-account requires typing DELETE before the danger button.

9States

loadingreadyzero accountserror

Loading is a skeleton of section cards; ready is all sections; the zero-accounts state shows the connect CTA; error is the shared banner with Retry.

11Localization & 360px

Section titles/descriptions, the plan/billing note, language English-names, account labels, appearance and danger copy all localize into 8 locales; DE/RU/UK run ~30–40% longer. On a phone: section descriptions wrap; the language grid’s native + English names truncate with ellipsis inside their cell (the flag + check stay put); account display names truncate while the handle keeps a line; the Disconnect/Delete buttons wrap rather than clip; the type-to-confirm keyword (DELETE) is locale-stable.

360px behavior. No new breakpoint — the gutter stays 14px; the language grid stays 2-up (cells get ~15px narrower, names ellipsis sooner); account rows and full-width controls just get narrower. The drawer stays min(82%, 312px) → 82% (≈295px) at 360.

12Checklist

  • Below 600px there is no sidebar and no tab bar — one 52px top bar with a hamburger far-left.
  • Hamburger opens the left drawer (active = Settings) + account; account-switch + Log out are in the drawer foot, not on this screen; bottom edge free.
  • Identity shows email + plan badge, read-only; a note says billing isn’t available yet (no upgrade UI).
  • Language = 8 UI locales as flag + native + English; active is accent-ringed with a check.
  • Connected accounts list rows (avatar + name + handle) + Disconnect (danger) + “Connect another account”.
  • Appearance = light/dark toggle row.
  • Danger zone is a separate danger-tinted card; Delete account is a full-width danger button.
  • Disconnect + Delete confirm in a bottom sheet; delete requires typing DELETE.
  • Loading = skeleton cards; zero-accounts shows the connect CTA; error banner has Retry.
  • Labels wrap on long locales — never pushing controls off-screen; sanity-checked at 360px.
  • Correct in light and dark; no hardcoded colour.
