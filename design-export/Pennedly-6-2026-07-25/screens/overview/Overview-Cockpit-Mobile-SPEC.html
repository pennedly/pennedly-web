Главная /app/overview · кокпит — телефон

Мульти-сетевой кокпит на телефоне, под большой палец. Сверху — очередь «Требует тебя»: приоритизированный список черновиков, ответов, сбоев синка и аудитов по всем профилям, каждая строка показывает свой профиль (аватар + значок сети + @никнейм) и ведёт внутрь. Ниже: итоги портфеля (2×2) и карточки профилей в столбик. Единственный контрол аккаунта на мобильном — кнопка внизу экрана, открывающая нижний лист (сменить профиль · Все аккаунты · подключить · Настройки · выйти), всё под большой палец. Текст русский; раскладка держит все 8 локалей (эталон — немецкий) по правилам 1–2; проверено до 320px.

pennedly-mobile.css + TriageQueue + MobileAccountButton import-banner.css
Критерий приёмки (правила 1–2). Однострочные элементы (значения метрик/итогов, счётчики очереди, бейджи, @никнейм, метки кнопок, вердикт) не переносятся и не толкают соседа вниз — усекаются многоточием. Текст русский; контейнеры держат немецкую длину. Доказано в §9 на 390, 360 и 320px и на немецкой длине.
Достраивает Overview-Mobile. Итоги, карточки профилей, состояния importing/sync-error/empty/error — 1:1 из Overview-Mobile-SPEC.html. Новое: очередь (герой), значки сети на аватарах и кнопка аккаунта внизу + лист — единственный контрол аккаунта на телефоне.

1Идентификация

Маршрут/app/overview — Главная-кокпит; ведёт сюда при профилей ≥ 2 (1 → Студия).
Сверху внизСтатус-бар → топ-бар (гамбургер · «Главная» · пилюля «N профилей» · тема) → очередь → итоги (2×2) → карточки → свободный нижний край. Доку — кнопка аккаунта над нижним краем.
Контрол аккаунтаКнопка внизу → нижний лист. Единственный контрол аккаунта на телефоне (нет подвала drawer, нет таб-бара).
Read-onlyКарточки и строки очереди открывают экраны профиля; мутирует только Retry на сбое синка.

2Телефонный кокпит

Весь кокпит в контексте, светлая и тёмная: очередь-герой → итоги 2×2 → карточки в столбик (один профиль импортируется, у одного Threads-сбой), с докнутой кнопкой аккаунта над нижним краем.

3shellШелл · Главная · кнопка аккаунта

Шелл общий. На Главной гамбургер открывает drawer (с Главной первой/активной); нижняя кнопка аккаунта здесь читает «Все аккаунты · N профилей» и открывает лист.

СлотЗначение на Главной
ГамбургерСлева, открывает drawer; Главная — первая строка, активна.
Заголовок / пилюля«Главная» + пилюля «N профилей · обновлено ежедневно» (rollup-глиф). На длинных локалях падает ниже.
Кнопка аккаунтаДокнута над нижним краем: аватар / «Все аккаунты» + имя + @никнейм + шеврон вверх → лист. Единственный контрол.
Таб-барНет — свободный нижний край (safe-area); контент освобождает место под кнопку.

4Очередь «Требует тебя»

Герой: приоритизированный список по всему портфелю — ответы и сбои синка, затем черновики, аудиты последними. Каждая строка ведёт аватаром профиля (+ значок сети), затем заголовок + @никнейм/мета, затем шеврон (или Retry при сбое). Пусто → спокойное «всё разобрано».

Правило 1. Строка на профиль-сигнал; тап = deep-link в экран профиля (Ответы / Студия / Аудиты). Retry на строке сбоя — единственное действие на месте. Заголовок усекается многоточием; @никнейм и мета — на своей строке под ним, тоже с усечением; аватар и действие фиксированы.

5Итоги + карточки перенесено

Без изменений из Overview-Mobile: итоги 2×2, затем карточка на профиль (теперь со значком сети и названием сети в подписи). «Ответы» — accent-метрика. Метки — одно слово, деталь в подписи (правило 1).

6newЛист аккаунта

Десктопный переключатель в сайдбаре на телефоне становится докнутой кнопкой аккаунта внизу → нижним листом с теми же действиями: email + тариф в шапке, пин Все аккаунты, Сменить профиль (со значками сети), Подключить ещё аккаунт, Настройки и Выйти — всё под большой палец.

Контекст кнопки. На кокпите кнопка читает «Все аккаунты · N профилей» (rollup-плитка); на экране одного профиля — аватар + имя + @никнейм этого профиля. Лист одинаков; активный контекст отмечен галочкой.

7Состояния

заполненовсё разобраноодин → Студиязагрузкапустоошибка

Один профиль = заметка «Студия — главная» + одна карточка + nudge (без героя-очереди). Загрузка повторяет раскладку; пусто = «Пока нет аккаунтов» + подключить; ошибка = баннер загрузки списка + Retry.

8правила 1–2Проверка раскладки

Доказательство критерия приёмки на телефоне: один кокпит при 390 (реф), 360 и 320px, и на немецкой длине. Ни один однострочный элемент не переносится — длинные подписи усекаются, аватары и действия фиксированы, выравнивание держится.

8.1 — 390 · 360 · 320px

9.2 — Немецкая длина (самая длинная локаль)

«Synchronisierung fehlgeschlagen», «Erneut versuchen», «Wachstums-Audit» — самые длинные. Усекаются, не ломая сетку. То же доступно в Tweaks (локаль = de).

10Чек-лист

  • Правило 1: однострочные элементы не переносятся и не толкают соседа — на 390/360/320px; усечение, не разрыв строки.
  • Правило 2: текст русский; контейнеры держат немецкую длину (§9, локаль de) без нарушения правила 1.
  • Ниже 600px: без сайдбара/таб-бара; топ-бар (гамбургер · «Главная» · пилюля «N профилей»); свободный нижний край.
  • Очередь — герой (сверху): сбои синка и ответы, затем черновики, затем аудиты; строка показывает профиль (аватар + сеть + @никнейм) и ведёт внутрь; сбой → Retry на месте.
  • Нулевой триаж = спокойное «всё разобрано» (не пустота/ошибка); итоги + карточки остаются.
  • Итоги 2×2 + карточки в столбик 1:1; значок сети на каждом аватаре; «Ответы» accent.
  • Кнопка аккаунта внизу → лист — единственный контрол: email + тариф · Все аккаунты · сменить профиль · подключить · Настройки · выйти.
  • Один профиль → заметка «Студия — главная» + карточка + nudge; загрузка повторяет раскладку; пусто + ошибка из Overview.
  • Корректно в светлой + тёмной; числа tabular, время в TZ зрителя.
