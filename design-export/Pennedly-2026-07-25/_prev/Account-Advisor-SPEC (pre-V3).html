Советник по портфелю /app/account/advisor

Полноценный чат-советник уровня аккаунта — как профильный /app/advisor, но scope = весь портфель: советник читает данные всех профилей (и брендов) и отвечает конкретикой. Вердикт закреплён сверху (та же сводка, что на карточке советника дашборда) и виден всегда; ниже — лента диалога с привязанными data-чипами, строкой «На основе:» и карточками-подсказками, и композер снизу. Кнопка «Открыть чат» на дашборде ведёт сюда. Вокабуляр 1:1 с профильным чатом (те же тон/иконки чипов и подсказок), чтобы бэкенд-контракт совпал. Состояния: empty (first-run) · thinking · тонкие-данные · error. Экран tester-gated. Хром — дашборда аккаунта; текст русский, 8 локалей (эталон — немецкий).

+ PortfolioAdvisorChat + PinnedVerdict .adv-* (advisor.css) account-screens.css account.css ds/tokens.css
Тот же чат, что у профиля — но по всему портфелю. Компонент переиспользует вокабуляр профильного советника (.adv-*: реплики, проза, .adv-chip--up/down/accent, строка источников, .adv-suggest), поэтому бэкенд-контракт совпадает. Отличие — scope: грунт = данные всех профилей портфеля, а сверху закреплён вердикт по аккаунту (сводка с карточки советника на дашборде).
Что особенного на этом экране.
  • Вердикт закреплён сверху. Портфельная сводка (вердикт + привязанные чипы) не скроллится — всегда виден, пока идёт диалог. Это тот же вердикт, что на карточке советника дашборда.
  • Привязка ко всему портфелю. Чипы и строка «На основе:» ссылаются на реальные сигналы across profiles: «@mara.co · сбой синка», «7 ответов · @mara.notes», «портфель 10 ← 14». Никаких выдуманных цифр.
  • Подсказки ведут в нужный профиль/бренд/Студию. «Open in Studio», «Открыть @mara.co» — та же handoff-механика, что у профильного чата.
  • Тонкие данные — честно. Если по портфелю мало истории — прямое «пока мало данных», без правдоподобных чисел.

1Идентификация экрана

Чат уровня аккаунта в хроме дашборда. Сверху вниз: sidebar(аккаунт · Советник активен) | main(topbar(крошка «Аккаунт › Советник» + pill «На основе всего портфеля») → pinned вердикт → лента → композер).

Маршрут/app/account/advisor. Вход: сайдбар аккаунта (пункт «Советник») или кнопка «Открыть чат / Открыть советника» с карточки советника на дашборде. Tester-gated.
ТипApp-shell уровня аккаунта + чат. Активный пункт сайдбара — Советник. Тот же компонент чата, что /app/advisor, scope = портфель.
НазначениеСпросить совета по всему портфелю и получить конкретный, привязанный к данным ответ: что чинить, где просел темп, какой профиль растёт — со ссылками на реальные сигналы и действиями в один клик.
Ширинаreading = --content-reading 720; лента центрирована (620 max), композер прилеплен снизу.
ЗакрепленоВердикт по портфелю (acc-chat-pinned) — не скроллится, всегда виден: сводка + привязанные чипы.
Фазыempty (first-run: вердикт + hero + стартеры) · ready (лента) · thinking (генерация — честная подпись об источнике) · thin (тонкие данные) · error (inline-строка + Retry).
ИсточникиСтатистика всех профилей портфеля, их голоса (role-book) и недавние посты/ответы. Ответ всегда называет, на что опирался.

2liveПолный экран в контексте

Весь экран — сайдбар аккаунта (Советник активен), крошка + pill, закреплённый вердикт, двухходовой диалог по портфелю и композер. Светлая и тёмная.

3heroЗакреплённый вердикт сверху

Портфельная сводка, что не скроллится: caption «Сводка портфеля» + scope, вердикт (одна фраза-вывод по аккаунту) и привязанные чипы. Это тот же вердикт, что на карточке советника дашборда — единая правда. Слева — 1 бренд, справа (тёмная) — 2+ брендов (scope тот же, данные брендовые).

4Анатомия ответа

Реплика пользователя (правый accent-пузырь) → ответ ассистента: mark + проза (не пузырь), затем data-чипы, строка «На основе:» и карточка-подсказка. Тот же строй, что профильный чат.

5Data-чипы + строка источников

Мелкие pill'ы внутри ответа, каждый — реальный сигнал портфеля. Тон: up=success, down=danger, справка/акцент=accent. Строка «На основе:» называет источники по всему портфелю — делает совет проверяемым.

КлассТонПример (портфель)
.adv-chip--downdanger«@mara.co · сбой синка» · «портфель 10 ← 14»
.adv-chip--upsuccess«+596 за 30 дней» · «Mara Lin · 7 постов»
.adv-chip--accentaccent«7 ответов · @mara.notes» · «3 бренда · 6 профилей»

6handoffКарточка-подсказка

Совет → действие. Заголовок + «почему» + кнопки. Главная ведёт в нужный профиль / бренд / Студию (та же handoff-механика, что у профильного чата), вторичная — на данные. Danger-иконка для срочного (сбой синка), accent — для роста.

7Композер + стартеры

Прилеплен снизу, всегда виден. Авто-textarea «Спросите о портфеле…» + Send. На first-run — чипы-стартеры про портфель («Что чинить в первую очередь?», «Где просел темп постинга?», «Какой профиль растёт быстрее?»). Тихая подпись про чтение данных портфеля.

8Все состояния

empty · first-runready ●thinkingтонкие данныеerror

Вердикт закреплён во всех состояниях. empty — вердикт + hero + стартеры; thinking — честная подпись «Читаю статистику портфеля…»; тонкие данные — прямое «пока мало данных», без выдуманных чипов; error — inline-строка + Retry (не баннер экрана).

9Навигация + вход с дашборда

Крошка «Аккаунт › Советник» (сегмент «Аккаунт» → дашборд). Кнопка «Открыть советника» на карточке советника дашборда ведёт сюда — карточка = взгляд, полный чат = разговор. Полная навигация Аккаунт↔Профиль — в Navigation-SPEC.html.

10Привязка к данным · что читает советник

Каждый содержательный ответ собирается из реальных сигналов всех профилей портфеля. Чип = метрика 1:1 с её экраном; строка источников называет, что использовалось. Вокабуляр — тот же, что профильный чат.

ИсточникЧто берётся (по портфелю)Где всплывает
Статистика профилейподписчики/просмотры/посты по каждому профилю, тренды, сбои синкачипы («+596», «10 ← 14»), цифры в прозе
Профили / статусыsynced / importing / error, время последнего обновления«@mara.co · сбой синка», приоритет действий
Ответы / вовлечённостьочередь ответов по профилям, всплески«7 ответов · @mara.notes»
Голоса (role-book)голос каждого профиля, что заходитпочему подсказки в нужном голосе
Никаких выдуманных чисел. Если по портфелю мало данных — честное «пока мало данных», без чипа. Чипы всегда совпадают с тем, что показывают дашборд и экраны профилей.

12Чек-лист

  • Хром дашборда аккаунта; активный пункт — Советник; крошка «Аккаунт › Советник» + pill «На основе всего портфеля»; tester-gated.
  • Вердикт закреплён сверху (не скроллится) — сводка + чипы, та же, что на карточке советника дашборда.
  • Полный чат: реплика пользователя (accent-пузырь) + ответ-проза с mark; вокабуляр .adv-* 1:1 с профильным чатом (бэкенд-контракт совпадает).
  • Data-чипы привязаны к реальным сигналам портфеля (up/down/accent); строка «На основе:»; никаких выдуманных чисел.
  • Карточка-подсказка → профиль / бренд / Студия (handoff); danger для срочного, accent для роста.
  • Стартеры про портфель на first-run; композер «Спросите о портфеле…» + Send.
  • Состояния: empty · ready · thinking (честная подпись) · тонкие-данные · error (inline + Retry).
  • «Открыть чат» с дашборда ведёт сюда; грунт = данные всех профилей портфеля.
  • Светлая + тёмная на токенах; 8 локалей без клиппинга (эталон de).
