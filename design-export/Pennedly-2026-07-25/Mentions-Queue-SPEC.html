Упоминания /app/mentions — очередь с интентами, медиа и рутинами

Редизайн экрана Упоминания. Раньше это была плоская лента текста плюс «Открыть в Threads». Теперь бэкенд классифицирует каждое упоминание по цели (интенту), отдаёт причину скипа и медиа-поля, и экран становится командным центром по входящим, а не списком. Три зоны различимы с первого взгляда: «Требуют вас» (то, на что бот сознательно не отвечает сам), лента (авто-безопасное и уже обработанное) и свёрнутое «Отфильтровано» (мусор, отсеянный автоматически). Ориентир по карточкам и очередям — экраны Ответы и Автопилот. Обе темы, только токены ds/tokens.css, один акцент: интенты различаются иконкой и словом, а не светофором. Живые фреймы ниже — реальные компоненты на mentions-queue.css, светлая и тёмная.

mentions-queue.css интент (12 · 3 группы) медиа-превью рутины упоминаний mentions-queue-build.js ds/tokens.css ds/components.css
Что осталось честным. Threads-API отдаёт только @автора без имени, аватар — заглушка-монограмма. Единственные действия, реально доступные вне продукта, — «Открыть в Threads» (жаловаться на аккаунт API не даёт). Продукт не «смотрит» видео: при генерации ответа честно помечаем «видео я не вижу». Тексты по умолчанию русские, без длинных тире.

1Идентификация экрана

Маршрут, назначение, раскладка сверху вниз: sidebar | main(topbar + scroll(content--wide: интро + вход в рутины + зона «Требуют вас» + лента + «Отфильтровано»)).

Маршрут/app/mentions. Пункт Упоминания (@) в группе Workspace, tester-gated.
НазначениеКомандный центр по входящим упоминаниям. Каждое упоминание — пост постороннего, который тегнул аккаунт; классифицирован по цели и разложен по зонам.
Ширина контентаwide = --content-wide 960. Топбар выровнен через .topbar-inner.topbar--wide.
Топбар«Упоминания» + .status-pill «Обновляется раз в час» (clock). Действия — тема + Настройки.
Зоны (сверху вниз)1. «Требуют вас» (QUEUE-only) → 2. лента (AUTO-safe + обработанные) → 3. «Отфильтровано» (SKIP-silent, свёрнуто).
Backend-правдаТолько @автор (без имени/аватара), интент, причина скипа, статус, медиа-поля, текст, пермалинк, время (в локальной TZ).
Только read + generateНикаких действий вне бэкенда. Пожаловаться на аккаунт нельзя (API не даёт) — только «Открыть в Threads».

2Модель данных · интент

Каждое упоминание несёт интент (12 значений, три группы), статус, медиа и — для отфильтрованных — причину скипа. Группа интента определяет зону и набор действий.

A · AUTO-safeМожно на автоЛента. Разрешено доверить авто-ответу.
B · QUEUE-onlyЖдёт владельца«Требуют вас». Бот сознательно не отвечает сам.
C · SKIP-silentМусор«Отфильтровано». Отсеяно автоматически.
ПолеЗначения
ИнтентAUTO-safe: вопрос · похвала · нейтральное. QUEUE-only: лид · жалоба · провокация · конкурент. SKIP-silent: спам · скам · фишинг · инъекция · не вам.
Статусновое · черновик (готов) · отвечено · пропущено.
Медиатип (фото / видео / текст), картинка, постер. Подозрительное медиа — размытое превью с «Показать».
Причина скипатолько у отфильтрованных: ссылка · масстег · обфускация · класс · не вам.
Автор и пост@автор (без имени), текст, пермалинк, время.
Один акцент, не светофор. Интенты различаются иконкой и словом, а не цветом. Единственная уместная сдержанная предупреждающая окраска (--color-warning) — у опасных: скам · фишинг · инъекция. Всё остальное — нейтральные чипы.

3Три зоны экрана полная очередь

Экран целиком, светлая и тёмная: вход в рутины, зона «Требуют вас» (2-3 QUEUE-only), лента (разные интенты и статусы) и свёрнутое «Отфильтровано (N)» внизу.

4Анатомия карточки

Шапка: аватар-заглушка + @автор + время, справа чип интента (иконка + короткое слово) и статус-бейдж. Дальше текст упоминания (с «Перевести»), опциональная подсказка «почему», медиа-превью, тред черновика и футер действий.

chips4.1 — Интент-чипы (12) и статус-бейджи

Спокойный тон. Опасные три (скам/фишинг/инъекция) — единственные с warning-окраской.

5Медиа-превью фото · видео · скрытое

Картинка или постер видео с бейджем «Видео». Для подозрительного медиа — размытое превью с «Показать» по клику. Видео продукт не смотрит: в черновике честно помечаем «видео я не вижу».

КлассОписание
.mq-mediaФото: превью 4:3, заглушка (реальная картинка приходит из API).
.mq-media--videoПостер 16:9 + кнопка play + бейдж .mq-media-badge «Видео».
.mq-media--hiddenРазмытый постер + .mq-media-veil с «Показать». Для скама/фишинга.
.mq-media-note«Видео я не вижу» — в треде черновика, когда медиа = видео.

6Карточка по статусам

Действия зависят от статуса и группы интента. Статус-строка честно называет текущее состояние.

СтатусДействия
Новое · AUTO«Сгенерировать ответ» (primary) · «Открыть в Threads» · «Пропустить».
Новое · QUEUE«Сгенерировать черновик» (осознанно) · «Открыть». Подсказка «ждёт вас».
ЧерновикПоказать текст + «Отправить» / «Изменить» / «Отклонить».
Отвечено«Открыть в Threads». Мета «Отправлено {время}».
Пропущено«Открыть в Threads» · «Вернуть в работу». Карточка приглушена.

7Опасная карточка скам / фишинг

Опасные интенты (скам/фишинг/инъекция) несут сдержанную warning-окраску чипа, подсказку «Это развод, отвечать не нужно» и размытое медиа. Обычно они живут в «Отфильтровано»; здесь — как пример.

8«Отфильтровано» развёрнуто

Свёрнуто по умолчанию (не в глаза, но доступно): «Отфильтровано N». Разворот — список с интент-чипом, @автором, сниппетом, причиной скипа и (для скам/фишинг) пометкой «это развод». Единственное действие — «Открыть в Threads».

9Рутины упоминаний заложить место

Скоро появятся авто-сценарии под интент («на все вопросы — авто-ответ», «на упоминания с фото — обработать и ответить картинкой»). Здесь заложен вход (рядом с «Автопилотом») и карточки-рутины в стиле рутин постинга. Полный конструктор — отдельный бриф позже; сейчас только место.

Только место, не конструктор. Карточки-рутины показаны как заглушка в стиле рутин постинга. Логика, редактор и запуск — отдельный бриф. Вход ведёт в объединённый Автопилот.

10Панель лимита

Отдельный дневной лимит ответов на упоминания рядом с общим лимитом, в «Правилах дома» · Ответы (см. Автопилот). Контрол «Не больше N ответов на упоминания в день» с пояснением «отдельно от ответов под постами».

11Пусто · reconnect · ошибка

emptyreconnect (сохранён)error

Пустое состояние, сохранённое reconnect-состояние (доступ к Threads истёк) и общий баннер ошибки с «Повторить».

12Чек-лист реализации

  • Полный app-shell; активный пункт = Упоминания (@, Workspace, tester-gated); топбар «Упоминания» + status-pill «Обновляется раз в час»; ширина --content-wide 960, одна колонка.
  • Три зоны: «Требуют вас» (QUEUE-only, приоритет сверху) → лента (AUTO-safe + обработанные) → «Отфильтровано» (SKIP-silent, свёрнуто по умолчанию).
  • Карточка: аватар-монограмма + @автор + время; чип интента (иконка + слово) + статус-бейдж; текст с @-хэндлами; «Перевести» для не-русских.
  • Один акцент, не светофор: warning-окраска только у скам/фишинг/инъекция; остальные интенты нейтральны.
  • Медиа: фото-превью, видео (постер + бейдж «Видео»), скрытое размытое медиа с «Показать»; в черновике к видео — «видео я не вижу».
  • Действия по статусу/интенту: AUTO новое (Сгенерировать ответ / Открыть / Пропустить), QUEUE (Сгенерировать черновик / Открыть), черновик (Отправить / Изменить / Отклонить), пропущено (Открыть / Вернуть).
  • «Отфильтровано»: свёрнуто «Отсеяли N», разворот со списком, причинами и пометкой «это развод» у скам/фишинг.
  • Вход в рутины упоминаний + карточки-рутины (только место); отдельный дневной лимит ответов на упоминания в «Правилах дома».
  • Состояния: полная очередь, пусто, reconnect (сохранён), ошибка.
  • Никаких действий вне бэкенда (жаловаться нельзя — только «Открыть в Threads»); только @автор без имени/аватара.
  • Обе темы на семантических токенах; тексты РУ, без длинных тире; тон помощника-фильтра.
