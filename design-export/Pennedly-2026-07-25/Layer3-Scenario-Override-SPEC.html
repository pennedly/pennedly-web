Слой 3 — «Только для этого сценария» · переопределение «Правил дома»

Аккордеон «Слой 3 · для продвинутых» в модели карточка-рецепт. Для reply-сценария (например, «Дежурство в комментах») можно точечно переопределить общие «Правила дома» — кому отвечать, лимит ответов в день, частоту проверки, тихие часы. По умолчанию всё наследуется; пользователь переопределяет отдельные пункты только для этого сценария, видит, что наследуется, а что переопределено, и может вернуть к наследованию.

01

Дефолт · всё наследуется из «Правил дома»

Ключевой экран в контексте редактора: рецепт-фраза + свёрнутый Слой 2 + раскрытый Слой 3. Четыре пункта, у каждого бейдж «наследуется из Правил дома», текущее значение словами и кнопка «Переопределить». Ничего ещё не тронуто — счётчик говорит «всё наследуется».

Light · сценарий-ОТВЕТ · Слой 3 раскрыт · 0 переопределений
02

Часть переопределена · «Лимит ответов»

Пользователь нажал «Переопределить» у лимита: строка подсветилась, бейдж сменился на «переопределено здесь», раскрылся контрол со слайдером, а внизу честно сказано «В Правилах дома: до 25 в день» со ссылкой и кнопкой «Вернуть к наследованию». Остальные три пункта по-прежнему наследуются.

Light · переопределён лимит (до 40/день) · остальное наследуется
03

Контрол раскрыт · «Кому отвечать»

Переопределение аудитории переиспользует галерею «Кому отвечать» из редактора: те же плитки (фанатам · все кроме троллей · только вопросы · свой вариант) плюс поле свободного описания. Внизу — честная подпись, что тролли отсекаются всегда и это переопределить нельзя.

Light · аудитория переопределена · «свой вариант» раскрыт
04

Несколько пунктов переопределено

Три из четырёх пунктов переопределены — счётчик показывает «переопределено: 3 из 4», появляется «Сбросить все переопределения». Видно сразу: что осталось общим (частота проверки), а что стало своим для этого сценария. Каждый контрол открыт со своим типом ввода.

Light · переопределены аудитория · лимит · тихие часы
05

Раскадровка · наследуется → переопределить → переопределено

Петля на одном пункте — «Частота проверки». Свёрнуто пункт наследует значение из «Правил дома»; тап «Переопределить» раскрывает контрол прямо в строке; выбор значения превращает бейдж в «переопределено здесь», а «Вернуть к наследованию» откатывает всё обратно.

1Наследуется— пункт показывает значение из «Правил дома».
2«Переопределить» → контрол раскрыт— редактор появился прямо в строке.
3Переопределено здесь— значение своё; «Вернуть к наследованию» откатит.
