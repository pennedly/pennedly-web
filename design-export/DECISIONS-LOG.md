## 🎯 Позиционирование / автопилот-кластер — ✅ ЗАКРЫТ (Q1–Q7)

- **Q2 = A** — честная рамка про автоматизацию (фраза из Terms — каноничная). Абсолюты («ничего не постится само») оставляем только там, где это правда (экран подключения + режим «только чтение»). На landing/onboarding — уточнить («по умолчанию», «пока не включишь»).
- **Подача автоматизации = «тихая опция»** — лицо бренда «твой голос, ты главный»; автоматизация честно показана как опция, без отрицания и без выпячивания. (Совпадает с исходной фразой Закхара: «как автопилот позиционировать нельзя, но отрицать глупо».)
- **Q1 = A** _(следствие Q2)_ — переписать глобальное meta-описание (`layout.tsx:19`, убрать «Threads on autopilot») + дать landing собственные `metadata`/OG.
- **Q3 = A** _(следствие честной рамки)_ — показать `auto_replied` в Replies (поле в SELECT `comments.py` + тип `CommentSummary` + бейдж «Auto-replied by Pennedly»); смягчить вступление «only when you approve». ⚙️ нужна правка бэкенда.
- **Q4 = оставить имя «Autopilot»** внутри приложения (по желанию Закхара — функцию не прячем). На landing убрать громкое отрицание «not an autopilot» → «ты главный / сначала одобрение». Противоречие уходит за счёт тихой подачи.
- **Q5 = A** — добавить на экран Autopilot спокойный текст про доверие: «отвечает AI, по твоим правилам, с лимитом, с логом». Прозрачность как сигнал доверия. ⚠️ Перед публичным запуском всерьёз взвесить вариант B (одобрение по умолчанию) — ресёрч предупреждает про shadowban аккаунтов клиентов.
- **Q6 = A** — заменить иконку-молнию ⚡ на спокойные часы/расписание (+ чат для авто-ответов), в один проход с переименованием иконографики.
- **Q7 = C** — смягчить вступление Audits («ничего не меняется без твоего одобрения») + подтвердить, что карточка авто-часов появляется только при включённом мастер-переключателе (SPEC §5.4).
