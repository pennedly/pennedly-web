«Отвечать на комментарии» — встроенная карточка-рутина ответов аккаунта

Поведение авто-ответов аккаунта (отвечать или нет, и кому) раньше жило отдельной настройкой и в списке рутин не показывалось. Эта дельта делает ответы полноценной рутиной: всегда присутствующая карточка «Отвечать на комментарии» на самом верху списка «Автопилота». Это не пользовательский сценарий — её нельзя удалить, она отражает реальный режим ответов аккаунта. Переиспользуем .sc-card, .sc-plaque, .inherit, .sc-createdoff из контроль-центра. Ниже — состояния и решения. Живые DS-фреймы, светлая И тёмная.

+ карточка «Отвечать на комментарии» + .sc-builtin (встроенная) + .sc-whoedit (кому, инлайн) + .sc-replaced (сосуществование) .sc-card .sc-plaque .inherit − «режим ответов» как скрытая настройка

1Что это за карточка

Карточка — это видимое лицо режима ответов аккаунта. Бэкенд не меняем: рисуем существующую реальность как рутину.

режим
Переключатель карточки = режим ответов. Вкл → «на все посты», выкл → «выкл». «Только на выбранные посты» здесь не появляется — это режим, который включается в Ленте у конкретного поста.
кому
Своё у карточки — только «кому отвечать»: только фанатам / все кроме троллей / только вопросы.
из ПД
Частота, тихие часы и потолок — глобальные. Живут в «Правилах дома», карточка их наследует и честно помечает чипом из Правил дома.
сама
Свип отвечает сам, без подтверждения — это не «Спроси меня»-черновик. Опрос раз в ~15 минут, не мгновенно. На карточке это строка «отвечает сама».

2Решения по брифу 7 вопросов → ответы

3 · кому отвечатьИнлайн-сегмент на карточкеДля не-технического юзера чище всего: сегмент «фанатам / все кроме троллей / вопросы / свой вариант» прямо на карточке. «Свой вариант» раскрывает поле — опиши аудиторию своими словами. «Открыть» ведёт глубже — в reply-редактор.
4 · отличиеБейдж «встроенная» + нет «Удалить»Маленький якорь-бейдж .sc-builtin и отсутствие действия «Удалить». Карточка всегда в списке.
5 · действияАктивность → «Ответы», Открыть → редактор«Активность» ведёт на экран «Ответы» аккаунта (журнал отправленных ответов). «Открыть» — в редактор «кому/как отвечать».
6 · сосуществованиеДефолт «заменена сценарием»Если есть кастомный reply-сценарий — он перебивает свип. Встроенная карточка приглушается и пишет «Заменена сценарием …», сценарий — обычной активной карточкой ниже.
7 · местоПервой, в группе «Встроенная»Карточка закреплена первой в списке рутин, в отдельной мини-группе «Встроенная», визуально отделена от «Твои рутины».
1–2 · состоянияВключена · ВыключенаВкл (режим ≠ выкл): живое предложение, «Активна», плашка, чип, «отвечает сама». Выкл: off-карточка «включи, когда готов».

3Состояние · ВКЛЮЧЕНА режим ≠ выкл

Режим ответов ≠ «выкл». Живое предложение «Отвечает на комментарии <кому> в твоём голосе. Частоту и тихие часы берёт из Правил дома», статус «Активна», плашка отвечает людям, чип из Правил дома, строка «отвечает сама» (свип авто), инлайн-сегмент «кому», действия «Активность» / «Открыть» — и нет «Удалить». 4Состояние · ВЫКЛЮЧЕНА режим = выкл

Режим = «выкл». Карточка остаётся в списке (её нельзя убрать), но читается как off-карточка через .sc-createdoff: «Ответы выключены — включи, когда будешь готов» + «Включить». Никаких чипов наследования и «отвечает сама» — отвечать-то нечем. «Удалить» по-прежнему нет. Светлая и тёмная:

Переключатель = режим аккаунта. Тумблер на карточке пишет напрямую в режим ответов: вкл → «на все», выкл → «выкл». Отдельной «настройки ответов» больше нет — карточка и есть настройка.

5«Кому отвечать» — как редактируется решение: инлайн

Два пути было на выбор. Выбран инлайн-сегмент прямо на карточке — для соло-креатора это один тап, без захода в редактор: видно, кому ты отвечаешь, и тут же меняешь. Три значения = reply_audience: только фанатам / все кроме троллей / только вопросы. Сегмент — это .sc-whoedit + .seg (переиспользован из редактора).

ЗначениеЧто делает свип
только фанатамОтвечает тем, кто уже подписан / тепло настроен. Самый узкий, самый безопасный режим.
все кроме троллей дефолтОтвечает всем, кроме явного негатива/провокаций. Баланс охвата и безопасности.
только вопросыОтвечает только там, где задан вопрос. Полезно, когда поток комментариев большой.
свой вариант текстомРаскрывает поле, где креатор своими словами описывает аудиторию (напр. «только тем, кто спрашивает про цены»). Сохраняется как reply_audience=custom + audience_prompt.

5.1 — «Свой вариант» — кому отвечать своими словами

Четвёртая опция сегмента — текстом «Свой вариант». При её выборе под сегментом раскрывается текстовое поле (.sc-whocustom) с плейсхолдером-примером и подсказкой «Опиши своими словами, кому Pennedly отвечает — остальных пропустит». Покрывает случаи, которые не ложатся в три готовых пресета. Есть и на дефолтной карточке, и в reply-редакторе (§5.2). Светлая и тёмная:

5.2 — «Открыть» → reply-вариант гибрид-редактора

Сегмент покрывает 90% случаев. Для тона и короткой инструкции «Открыть» ведёт в гибрид-редактор, reply-вариант: шаг «Когда» — read-only «раз в ~15 мин» (.sced-when-reply), шаг «Что ты задаёшь» = кому отвечать (тот же сегмент с 4 опциями, ниже — «Свой вариант» раскрыт) + короткая инструкция, справа — крупное превью ветки авто-ответа. 6Встроенная карточка vs пользовательский reply-сценарий

Обе сущности могут отвечать на комментарии — поэтому различие должно читаться мгновенно.

7Сосуществование с кастомным reply-сценарием важный кусок

Решение: не объединять, а показать приоритет честно. Кастомный reply-сценарий перебивает дефолтный свип аккаунта — значит две карточки одновременно «отвечать на все» вводили бы в заблуждение. Поэтому пока кастомный сценарий активен, встроенная карточка переходит в состояние «заменена сценарием …»: приглушается (.sc-card--paused), переключатель/сегмент гасятся, и появляется строка .sc-replaced со ссылкой на сценарий, который сейчас рулит. Сам кастомный сценарий стоит ниже обычной активной карточкой с бейджем перебивает дефолт. Так в любой момент видно ровно одну сущность, которая реально отвечает. Светлая и тёмная:

Почему не слияние. Слить их в одну карточку = спрятать тот факт, что свипом теперь управляет отдельный сценарий со своей логикой. Приглушённая встроенная + явная ссылка «Открыть сценарий» оставляют путь назад: выключи/удали сценарий — встроенная карточка тут же оживёт в своём «на все».

8Где карточка стоит в списке первой, отделена

Карточка закреплена первой в списке рутин «Автопилота», в собственной мини-группе «Встроенная» (.rl-group-k), визуально отделённой от группы «Твои рутины». Так встроенная сущность аккаунта не теряется среди пользовательских сценариев и читается как «всегда здесь». Сверху — свёрнутые «Правила дома» (контекст). Светлая:

9«Активность» и «Открыть» — куда ведут

ДействиеВедётЧто там
АктивностьЭкран «Ответы» аккаунтаЧеловеческий журнал отправленных авто-ответов: цитата комментария + ответ свипа + ссылка на пост. Это account-уровень (не per-routine), потому что свип — это аккаунт.
ОткрытьРедактор «кому / как отвечать»Reply-вариант гибрид-редактора (§5.1): сегмент «кому» + тон/инструкция + превью ветки. Без «Удалить».

10Раскладка · Web ↔ Mobile

Десктоп ( > 640 )

  • Карточка .sc-card в строку: иконка + имя+бейджи слева, статус+тумблер справа.
  • Инлайн-сегмент «кому» — в одну строку под шапкой карточки.
  • Подвал: «отвечает сама» + чип «из Правил дома» слева, «Активность» / «Открыть» справа.

Телефон ( ≤ 640 )

  • Карточка стопкой: шапка, затем сегмент «кому» full-width (3 опции в ряд, ≥44px).
  • Подвал переносится: чипы наследования сверху, действия «Активность» / «Открыть» во всю ширину.
  • Группы «Встроенная» / «Твои рутины» — те же лейблы, карточки full-width.
Сегмент «кому» держит ≥ 44px высоту тапа на телефоне; длинные RU/DE-лейблы («все кроме троллей») оборачиваются внутри опции, не обрезаются.

11Чек-лист реализации

  • Карточка «Отвечать на комментарии» — встроенная (.sc-builtin), всегда первой в списке, в группе «Встроенная»; нет «Удалить».
  • Переключатель карточки = режим ответов аккаунта: вкл → «на все», выкл → «выкл». «Выбранные» — в Ленте, не здесь.
  • ВКЛ: живое предложение + «Активна» + плашка «отвечает людям» + чип «из Правил дома» + строка «отвечает сама» (свип авто, ~15 мин).
  • ВЫКЛ: off-карточка .sc-createdoff «включи, когда готов» + «Включить»; без чипов наследования.
  • «Кому отвечать» — инлайн-сегмент .sc-whoedit (фанатам / все кроме троллей / вопросы); дефолт «все кроме троллей».
  • «Открыть» → reply-вариант редактора (шаг «Что ты задаёшь» = кому + инструкция); «Активность» → экран «Ответы».
  • Частота / тихие часы / потолок — наследуются из «Правил дома», помечены .inherit; на карточке не редактируются.
  • Сосуществование: при активном кастомном reply-сценарии встроенная карточка → .sc-card--paused + .sc-replaced «Заменена сценарием …»; сценарий — обычной картой с бейджем «перебивает дефолт».
  • Мобайл стопкой; сегмент ≥44px; светлая И тёмная; только семантические токены; Geist.
