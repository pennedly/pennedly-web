Pattern study /app/patterns — пиксель-в-пиксель

Дотошная спецификация экрана Pattern study — детерминированного само-анализа (БЕЗ LLM) — и общего app-shell, который экран переиспользует 1:1 из Studio (<window.Sidebar active="patterns"/> + топбар + переключатель аккаунтов). Pennedly читает ТВОЮ собственную историю постов и их метрики и находит закономерности, которые реально двигают вовлечённость (длина, хук-вопрос, тема, тайминг и т.п.), показывая каждую с доказательствами из твоих же постов. Это инсайты для самоанализа, не действие с контентом. Ниже задокументированы АБСОЛЮТНО все состояния: shell (аккаунт-меню откр/закр) и четыре фазы экрана — empty (мало постов), idle (приглашение запустить), running (ступенчатый прогресс с nib-write) и results (карточки найденных паттернов с доказательствами lead vs base и примерами), тема и адаптив web↔mobile. Все значения взяты из реального дизайна, без «примерно». Сосед «Explore patterns» (/app/patterns/explore) здесь НЕ описывается.

patterns-app.jsx patterns-parts.jsx patterns-data.jsx patterns.css shell-parts.jsx shell-data.jsx shell.css studio.css ds/tokens.css ds/components.css
App-shell — общий, 1:1 как в Studio. Pattern study НЕ собирает каркас заново: рендерится <window.Sidebar active="patterns"/> из shell-parts.jsx, а классы .app/.sidebar/.main/.topbar/.account приходят из studio.css + shell.css. Отличия shell от Studio — активный пункт навигации = Pattern study в группе Insight (nav-item--active, aria-current="page", без badge) и заголовок топбара «Pattern study». §2.1–2.4 документируют shell так же дотошно, как в Studio-SPEC.
Расхождения с брифом — здесь задокументирован РЕАЛЬНЫЙ дизайн. В коде (а не в брифе):
  • Ширина — reading 720, не wide 960. Топбар использует .topbar-inner без --wide, .content — без --wide. Обе колонки выровнены по --content-reading 720.
  • Скелетонов/shimmer на этом экране НЕТ. Фаза running — это каноничный nib-write (анимация пера) + ступенчатый прогресс с тикером-спиннером (run-spin), а не shimmer-скелетоны. Skeleton-компонента в Pattern study не существует. card-in у карточек паттернов используется.
  • Idle-чипы — 6 конкретных лейблов (LOOKS_FOR): «Hooks & openings», «Post length», «Topics», «Timing», «Format & structure», «Questions vs statements» — а не 5 коротких «hooks/length/timing/format/questions».
  • Брейкпоинт экрана — 600px (ev-row схлопывается, pc-stat уменьшается до h1), плюс общий 880 (rail) и 560 (паддинг из studio.css). Своего правила на 560 у patterns нет.
  • Error-фазы НЕТ. Твик state = Idle / Running / Results / Empty. По умолчанию — Results.
  • Тостов/диалогов на экране нет. Экран read-only, кроме кнопок запуска.
  • kind-теги паттернов в сидах — Hook · Length · Topic · Timing (а не length/question/emoji/structure из брифа); strength — strong / emerging («Strong signal» / «Worth testing»).
Состояния одним взглядом. Экран управляется двумя твиками (patterns-app.jsx → PT_TWEAK_DEFAULTS): dark (false) и state («Results»). Твик state жёстко задаёт фазу для превью: Idle / Running / Results / Empty. Кнопка «Run a study» (idle) и «Re-run study» (results) запускают runStudy → фаза running → анимация 4 шагов по 700ms → через +500ms фаза results (lastRun="just now"). Данные — из PATTERNS (4 паттерна) + STUDY_META (postsAnalyzed 47, lastRun «3 days ago»). Анализ детерминированный, без генерации текста.
