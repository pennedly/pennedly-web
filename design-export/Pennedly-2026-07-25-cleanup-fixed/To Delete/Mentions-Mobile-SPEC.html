Mentions /app/mentions — phone

A read-only queue of posts where you were @-mentioned, so you can hop to Threads and respond yourself. Unlike Replies, there’s no AI drafting here — Mentions just collects and shows them. The simplest screen in the app: a single column of mention cards. Same tokens, content and states as the desktop spec — only the layout changes below 600px, on the decided shell (hamburger + left drawer, freshness pill, no tab bar, free bottom edge). Frames are the real component layer at 390px, light and dark.

pennedly-mobile.css mentions-app.jsx mentions-parts.jsx shell-parts.jsx ds/tokens.css
What does not change. This is a read-only ingestion queue refreshed hourly — no reply composer, no approve/publish, no editing. The @-handle highlighting, the on-demand translation, and the loading/empty/error states are identical to desktop. Threads exposes only the mentioner’s @username — no avatar, no display name — so the card never invents one. Mobile is a layout pass; the only structural change is the shared app shell (tab bar → hamburger drawer).

2The phone layout

The whole screen in context, light and dark: a column of mention cards, each showing who mentioned you (@username + time), the mention text with @handles highlighted, and an “Open in Threads” action. The list runs to the free bottom edge.

4fixMention card — @username

Threads gives us only the mentioner’s @username — no reliable avatar, no display name. The card head is therefore @username + time only; we never draw a mentioner avatar or invent a name. The desktop card’s avatar + name simply drop.

Before

The desktop foot puts a translate toggle and “Open in Threads” on one line beside the text; squeezed onto a phone the button wraps awkwardly and the head avatar steals width that isn’t really ours to spend (no real avatar exists).

After

Head = @username + time only. The mention text wraps freely with @handles in accent ink. Any translate toggle sits on its own meta line; “Open in Threads” is a full-width-grow secondary button (44px) below — the one reachable action.

Rules. Text wraps with text-wrap:pretty; @handles render as .at-mention (accent, 500). A long mention just grows the card — no clamp, no “see more” (this is the whole point of the screen). For a foreign-language mention, an inline “Translate from {lang}” swaps to the translation + “Show original”. The only action is “Open in Threads”; there is no overflow ⋯ because there’s nothing else to collapse.

5States

loading ×3readyemptyerror

Loading is 3 skeleton cards; ready is the populated list; empty is the friendly “no mentions yet”; error is the shared banner with Retry. No per-state chrome differs from the desktop beyond width.

7Web ↔ mobile

Desktop ( > 900 )

  • Fixed sidebar; 960px column; freshness pill in the topbar.
  • Card head shows avatar + name + handle + time.
  • Foot: translate toggle + “Open in Threads” on one line.

Phone ( ≤ 600 )

  • No sidebar/tab bar; hamburger → drawer + account; free bottom edge.
  • Card head = @username + time only (no avatar/name).
  • Foot: translate on its own line; “Open in Threads” full-width-grow.

8Localization & 360px

The freshness pill, the translate toggles and “Open in Threads” all localize into 8 locales; DE/RU/UK run ~30–40% longer. On a phone: “Open in Threads” wraps rather than clips; the translate toggle wraps; the @username truncates with ellipsis; the mention body wraps naturally. Mention text itself arrives in any language — translation is on-demand. Never bake a label into an image.

360px behavior. No new breakpoint — the gutter stays 14px and cards just get ~30px narrower. Nothing here is width-fragile: the head is one short line, the body wraps, the single action grows to fit. The only visible change at 360 is the occasional second line on a long “Open in Threads” locale (still ≥44px). The drawer stays min(82%, 312px) → 82% (≈295px) at 360.

9Checklist

  • Below 600px there is no sidebar and no tab bar — one 52px top bar with a hamburger far-left and the “Updated hourly” clock pill.
  • Hamburger opens the left drawer (active = Mentions, tester-gated) + account at its foot; bottom edge free.
  • Card head = @username + time only — no mentioner avatar, no invented name.
  • Mention text wraps freely with @handles in accent; long mentions grow the card (no clamp).
  • Read-only: no composer, no status flow; the only action is “Open in Threads” (full-width-grow, 44px).
  • Foreign-language mentions show an inline translate toggle + “Show original”; both wrap.
  • Loading = 3 skeletons; empty = “No mentions yet”; error banner has Retry.
  • Labels wrap on long locales — never clipped; sanity-checked at 360px.
  • Correct in light and dark; no hardcoded colour.
