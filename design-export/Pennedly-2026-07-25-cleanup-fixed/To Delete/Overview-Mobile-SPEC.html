Pennedly · Mobile spec · per-screen

Overview /app/overview · All accounts — phone

The multi-account rollup on a phone: every connected account at a glance, so someone running 3–4 accounts sees the whole picture without switching one by one. A combined top strip (portfolio totals) sits over a column of account cards — each with avatar, @handle, key metrics (followers + Δ, 7-day views, posts this week, replies to answer) and a sync status that reuses the Phase-0 “Importing your history” state. Any card opens that account’s full screens. Reached from the account switcher’s All accounts pin. This fits cleanly at 390px (checked at 360): a 2×2 totals grid, stacked cards with 2×2 metrics, and the same loading / empty / error / importing states. Same tokens and numbers as the desktop spec; only the layout changes below 600px. Frames are the real component layer at 390px, light and dark.

What stays the same. The portfolio totals, per-account metrics and “× / Δ” numbers are the same computed values as the per-account screens — read-only, no new metrics. The importing state is the shared Phase-0 banner. Mobile is a layout pass; the only navigation is into each account’s screens.
Portfolio, not single-account. This is the one screen with no active account — the context is “all of them”. It’s reached from the switcher’s All accounts pin, not the nav. With one account it degrades to a single card + a “connect another” nudge.

4Combined top strip

Portfolio totals as a 2×2 grid: Followers (+Δ) · 7-day views · Posts this week · Replies to answer (accent). A caption reads “Across N accounts”, with “+1 still importing” when someone’s syncing.

Rules. Totals sum only synced accounts; importing accounts are counted separately and excluded until they resolve. “Replies to answer” is the accent total — the number of conversations waiting across the whole portfolio. Numbers tabular.

5Account card

One card per account: header (avatar + name + @handle + a go chevron), a 2×2 metric block, and a status row. The whole card opens that account (switches context → its Stats); quick-links deep-link to Stats and Replies (with the waiting count).

Rules. Metrics are Followers (+Δ) · 7-day views · Posts this week · Replies to answer (accent when > 0). Name/handle ellipsis-truncate; the status row wraps the quick-links under the sync line at 360. Whole-card tap target.

6Sync statuses

Each card carries its account’s sync state: synced (“● Updated 2h ago”), importing (the Phase-0 banner replaces the metrics), sync-error (“● Sync failed” + Retry).

Reuses Phase-0. The importing card mounts the shared import-banner--syncing (spinner, live “N posts · M comments so far”, progress bar) instead of the metric block; metrics fill in as data lands. A failed sync is card-local — other cards are unaffected.

7States

single + nudgemanyloadingemptyerror

Single account = one card + a “connect another” nudge (no empty portfolio). Loading mirrors the layout; empty = “No accounts connected yet” + Connect; error = an inline banner + Retry for the list load (a single account’s sync failure lives in its card).

9Web ↔ mobile

Desktop ( > 880 )

  • Fixed sidebar; 960px column; account-control = “All accounts”.
  • Top strip 4-up; card grid 2-up; metrics in a row.
  • Status row: sync left, quick-links right.

Phone ( ≤ 600 )

  • No sidebar/tab bar; drawer + switcher sheet; “All accounts” pin on top.
  • Top strip 2×2; cards stack; metrics 2×2.
  • Status row wraps quick-links under the sync line at 360.

10Localization & 360px

Title, pill, total/metric labels, sync text, nudge, empty/error copy and quick-links localize into 8 locales (en/ru/uk/de/es/fr/it/pt); DE/RU/UK run ~30–40% longer. Totals stay 2×2; metric labels wrap inside their cell; names/handles ellipsis-truncate; quick-links wrap under the sync line. Numbers tabular; “updated Nh ago” relative in the viewer’s timezone.

360px behavior. No new breakpoint — gutters stay 14px; the totals stay 2×2 (numbers are short); the card’s 2×2 metrics hold; name/handle truncate; the status row wraps quick-links under the sync line; the importing banner stacks its ETA under the bar (as in Phase-0).

11Checklist

  • Below 600px: no sidebar/tab bar; top bar (hamburger · “Overview” · “N accounts” pill); free bottom edge.
  • Entry: switcher “All accounts” pin (rollup icon · “N connected · Overview”) → Overview.
  • Top strip: 2×2 totals (Followers +Δ · 7-day views · Posts this week · Replies to answer [accent]); “Across N accounts” + “+M still importing”.
  • Account card: avatar + name + @handle + go chevron; 2×2 metrics; whole card opens the account.
  • Sync status: synced (“● Updated Nh ago”) / importing (Phase-0 banner instead of metrics) / sync-error (“Sync failed” + Retry).
  • Quick-links: Stats + Replies N (accent when > 0).
  • Totals sum only synced accounts; importing counted separately.
  • Single account → one card + “connect another” nudge; no empty portfolio.
  • Loading mirrors the layout; empty = “No accounts connected yet” + Connect; error = inline banner + Retry (list load).
  • Labels wrap on long locales — never clipped; checked at 360px.
  • Correct in light and dark; no hardcoded colour; numbers tabular, time in the viewer’s timezone.
