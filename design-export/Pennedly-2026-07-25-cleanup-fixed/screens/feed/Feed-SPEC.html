My Feed /app/feed — пиксель-в-пиксель

Дотошная спецификация аналитического экрана My Feed («что зашло») — и общего app-shell, который Feed переиспользует 1:1 из Studio (<window.Sidebar active="feed"/> + топбар + переключатель аккаунтов). Здесь пользователь видит свои опубликованные в Threads посты с метриками вовлечённости и понимает, насколько каждый пост выстрелил относительно собственного среднего по аккаунту. Это surface для самоанализа, не для действий с черновиками. Ниже задокументированы АБСОЛЮТНО все состояния: shell (аккаунт-меню откр/закр), сортировка (Recent / Top performing), лента (loading / live / empty / error), карточка поста со всеми элементами (virality-verdict, героическая метрика views + ряд метрик, раскрывающийся график роста, per-post auto-reply тогл, ⋯-меню с переводом и удалением), confirm-диалог удаления, тосты, тема и адаптив web↔mobile. Все значения взяты из реального дизайна, без «примерно».

App-shell — общий, 1:1 как в Studio. Feed НЕ собирает каркас заново: рендерится <window.Sidebar active="feed"/> из shell-parts.jsx, а классы .app/.sidebar/.main/.topbar/.account приходят из studio.css + shell.css. Единственное отличие shell от Studio — активный пункт навигации = My Feed (nav-item--active, aria-current="page", без badge) и заголовок топбара «My Feed». §2.1–2.4 документируют shell так же дотошно, как в Studio-SPEC.
Сводный блок «Baseline» удалён (коммит fb3e0b2, 30 июня) — синхронизация образца. Лента больше НЕ начинается с карточки-сводки (4 средних + sparkline + дельта). Сразу под заголовком «My Feed» идёт сортировка, затем карточки постов — ничего не переносилось и не пряталось взамен. При этом показатель на каждой карточке («N× average», см. ViralityBadge ниже) сохранён и вычисляется как прежде — просто больше не отображается отдельным блоком.
Расхождения с брифом — здесь задокументирован РЕАЛЬНЫЙ дизайн. В коде (а не в брифе):
  • Virality-verdict — не 4 тира «viral/good/mid/flop» и не «N× your usual». Реальный ViralityBadge отдаёт: «Still settling» (пока пост свежий, settling) · «{r}× average» со стилем --over (success) при ratio ≥ 1.5 · «On par» при 0.85 ≤ ratio < 1.5 (нейтральный) · «{r}× average» нейтральный при ratio < 0.85. ratio = post.views ÷ baseline.views (среднее по аккаунту — внутреннее значение, больше не рисуется отдельным блоком). Стилизованы только два: --over (success) и --settling (accent); «On par» и низкий — базовый нейтральный .vbadge.
  • График роста (Growth) — это раскрывающийся .trend-panel с полноразмерным SVG-графиком накопленных просмотров против пунктирной линии «your average», а не sparkline.
  • Перевод есть и здесь (как в Studio): через ⋯-меню → Translate → одна из 8 локалей, тело меняется инлайн + .translate-bar «Translated to {native} · Show original».
  • Действия карточки: футер несёт auto-reply-пилюлю + «Growth» + «Open on Threads» (primary) + ⋯-меню; «Delete post» живёт В ⋯-меню (tester-gated) и идёт через confirm-диалог. «Open on Threads» продублировано и в footer, и в меню.
  • Твиков три: dark, state (Live/Loading/Empty/Error) и sort (Recent/Top). Density-режима нет.
Состояния одним взглядом. Экран управляется тремя твиками (feed-app.jsx → FEED_TWEAK_DEFAULTS): dark (false), state («Live»), sort («Recent»). При монтировании фаза всегда loading ~850ms → ready; state="Loading" держит loading, "Empty" рисует EmptyState, "Error" — ErrorBanner. Сортировка client-side: top → по views убыв., recent → как есть. Метрики и тренды — из сид-данных (FEED_POSTS, 6 постов); среднее по аккаунту — из BASELINE (30-дневное среднее), используется только для расчёта ratio на карточках.

1Идентификация экрана

Маршрут, назначение, ширина wide-колонки, раскладка сверху вниз: sidebar | main(topbar + scroll(content: feed-intro + feed-bar + feed)).

Маршрут/app/feed (Feed.html). Пункт навигации My Feed в группе Workspace (без badge, не tester-gated).
ТипПолный app-shell: рендерится <window.Sidebar active="feed"/>. Каркас 1:1 переиспользован из Studio.
НазначениеАналитика опубликованных постов: насколько каждый пост выстрелил относительно собственного среднего пользователя. Только просмотр/самоанализ — никаких действий с черновиками. Доступные действия: раскрыть график, переключить auto-reply, перевести тело, открыть в Threads, удалить пост (tester).
Корневой контейнер.app → display:flex; height:100%; overflow:hidden; bg --color-bg; color --color-text. Без data-density (density-режима у Feed нет).
Ширина контентаwide = --content-wide 960px. Колонка .content.content--wide центрируется; топбар выровнен по той же ширине через .topbar-inner.topbar--wide.
ТопбарЗаголовок «My Feed» + .status-pill.status-pill--success «Updated just now» (всегда) + действия: тема + Settings.
Секции (top→bottom).feed-intro (h1 «My Feed» + подзаголовок) → <FeedBar> (.feed-bar: счётчик + сегмент сортировки) → .feed (карточки постов). Сводного блока перед сортировкой больше нет (см. предупреждение выше). В loading/empty/error эта пара частично/полностью замещается.
Фазы (state)loading (5 скелетон-карточек) · ready (live) · empty (EmptyState) · error (ErrorBanner). Управляется твиком state; в реальном приложении — loading на fetch, error на сбое.
СортировкаТвик sort + сегмент в .feed-bar: Recent (по умолчанию, как есть) ↔ Top performing (по views убыв., client-side). Клик по сегменту синхронизирует твик sort («Recent»/«Top»).
First-run / densityОтсутствуют в этом экране.
ЛокализацияEnd-user копи локализуется (8 UI-локалей, UI_LANGS). Перевод тела поста — через ⋯-меню → Translate → локаль; тело меняется инлайн + .translate-bar. Тексты постов и их переводы (post.tr) — сэмплы; реальные приходят из сервиса перевода.
Backend-правдаМетрики и тренд — из Threads insights; среднее по аккаунту (baseline) — собственное скользящее среднее аккаунта, используется только как делитель для «N× average» на карточках. Лайков/метрик на уровне ответов нет — только на самом посте. Delete tester-gated, убирает из Threads и из ленты. Время — в локальной TZ зрителя (fmtDateTime).

Раскладка сверху вниз

  1. .app — горизонтальный flex во всю высоту. Два прямых ребёнка: <Sidebar active="feed"> и .main.
  2. .sidebar (shell) — flex:0 0 248px: бренд → nav-группы (active = My Feed) → .sidebar-foot (AccountMenu, margin-top:auto).
  3. .main — flex:1 1 auto; min-width:0; flex-direction:column: <Topbar> (sticky 60px) + .scroll.
  4. .scroll > .content.content--wide — max-width:960; margin:0 auto; padding:28px 24px 96px; flex-column; gap:20px. Здесь: feed-intro, FeedBar, .feed.
  5. Оверлеи поверх .app — <ConfirmDelete> (по требованию), <Toasts> (фикс. снизу-центр), <TweaksPanel>.

2.7.1 — Virality-verdict .vbadge ViralityBadge

Бейдж top-right в шапке — единственное место, где показатель «относительно среднего» теперь виден (взамен удалённого сводного блока). ratio = post.metrics.views ÷ baseline.views (baseline 14800, внутреннее значение). Логика и копи — ровно как в коде:

УсловиеКласс / стильКопи + иконка
settling=true.vbadge--settling — bg mix(accent 12%, surface), color accent, border mix(accent 28%)«Still settling» + IcClock 12 (иконка пульсирует settle-pulse 1.8s)
ratio ≥ 1.5.vbadge--over — bg mix(success 13%, surface), color success, border mix(success 30%)«{ratio.toFixed(1)}× average» + IcArrowUp 12
0.85 ≤ ratio < 1.5базовый .vbadge (нейтральный)«On par»
ratio < 0.85базовый .vbadge (нейтральный)«{ratio.toFixed(1)}× average»

База .vbadge: inline-flex; gap:6px; --text-caption / w600 / lh1; padding:5px 10px; radius-full; border; bg surface-2; color text-muted. По сидам: f1 = 3.3× (over) · f2 = Still settling · f3(reply) = 2.1× (over) · f4 = 1.5× (over) · f5 = On par · f6 = 0.6× (нейтральный). «Ещё набирает» = копия «Still settling» для свежих постов, у которых цифры не устоялись; «На уровне среднего» = «On par»; тон нейтральный (не danger/warning) для значений ниже 0.85 — это осознанно, не ошибка и не тревога.

Каждое состояние — что видно, чем отличается, как в него попасть. Сверху вниз: shell → сортировка → лента → карточка (verdict / growth / auto-reply / translate / delete) → ⋯-меню → диалог → тосты → интерактив каждого кликабельного элемента → анимации.

shell4.1 — Аккаунт-меню: закрыто / открыто

Закрыто (по умолчанию)

  • .account aria-expanded="false"; chev без поворота.
  • Нет scrim, нет .acct-menu. Hover триггера → bg surface-2.

Открыто

  • Клик → aria-expanded="true"; chev rotate 180°.
  • scrim (z35) + .acct-menu ВВЕРХ (z40, dialog-in).

4.2 — Сортировка: Recent / Top performing

  • .fb-count = «{count} published posts» (в live count = 6). Это теперь первая видимая строка контента под заголовком.

4.4 — Карточка: verdict + growth + auto-reply + translate

Virality-verdict (vs среднего по аккаунту)

  • Still settling — пока пост свежий (settling): accent-бейдж, IcClock пульсирует. Копия для «ещё набирает».
  • {r}× average (success) — ratio ≥ 1.5, IcArrowUp.
  • On par — 0.85 ≤ ratio < 1.5, нейтральный тон. Копия для «на уровне среднего».
  • {r}× average (нейтральный, не danger) — ratio < 0.85. Тон осознанно нейтральный, не тревожный.
  • Стилизованы только --over и --settling; «On par»/низкий — базовый .vbadge.

Growth (график роста)

  • Свёрнут (default): только кнопка «Growth», chevron вниз; панели нет.
  • Развёрнут: клик → expanded === post.id → появляется .trend-panel (card-in), chevron rotate 180°.
  • В каждый момент развёрнута максимум одна карточка (single expanded id; повторный клик сворачивает).
  • Внутри: «Views over {span}» + «{peak}» + SVG-кривая против пунктира «your average» + ось «Posted»/«Now».

Auto-reply тогл (per-post)

  • off: .ar-pill нейтральный + .ar-dot (полый кружок), «Auto-replies off».
  • on: .ar-pill--on (accent fill/border) + IcReply (accent), «Auto-replies on».
  • Клик → оптимистичный тогл + тост (on/off, см. §2.11). aria-pressed отражает состояние.
  • Сиды: on у f1/f2/f4; off у f3/f5/f6.

translated / reply / leaving

  • translated: выбор локали в ⋯-меню → .draft-body = post.tr[lang] + .translate-bar «Translated to {native} · Show original».

7Чек-лист

«Убедись, что X = ровно Y». Пройди в светлой и тёмной теме, на вебе и мобайле.

Shell (1:1 как в Studio)

  • Сайдбар = flex 0 0 248px; активен пункт My Feed (nav-item--active, aria-current="page"), без badge.
  • AccountMenu открывается ВВЕРХ, chev 180°, scrim z35 / меню z40, активный Mara Lin с success-галочкой.
  • Топбар = height 60, заголовок «My Feed», status-pill success «Updated just now», действия = тема + Settings.
  • Топбар и контент выровнены по 960 (.topbar-inner.topbar--wide = .content--wide).
  • На ≤880 сайдбар → icon-rail; acct-menu width 248.

Лента начинается с сортировки — без сводки

  • Под заголовком «My Feed» сразу идёт .feed-bar (счётчик + Recent/Top performing) — никакого блока-сводки перед ней.
  • Сегмент сортировки: Recent (default) / Top performing; active = surface + shadow-sm + w600; счётчик «6 published posts».
  • Top performing сортирует по views убыв., client-side.
