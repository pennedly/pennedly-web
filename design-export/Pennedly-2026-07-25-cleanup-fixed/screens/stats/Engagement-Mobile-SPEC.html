Pennedly · Mobile spec · Stats panel

Engagement · /app/stats panel — phone

The Engagement panel on a phone: a per-day time series of the selected metric (Views · Likes · Replies · Reposts · Quotes), a range control (30d / 90d / 1y), the account-wide lifetime tiles, and a per-point tooltip. It is the sibling of the Follower-growth chart and uses the same line treatment — only the axis differs (0-based, because this is a per-day metric, not a cumulative count). Same tokens and computed numbers as the desktop spec; only the layout changes below 600px. Every state is shown, light and dark, on the real component layer at 390px.

engagement.css pennedly-mobile.css stats-followers.css ds/tokens.css
What does not change. The five metrics, the gap-filled / continuous series, the 0-based axis with its faint floor rule, the «vs previous window» trend, the lifetime totals (the reliable account-wide figures), and the data honesty — Views real + backfilled, per-day Likes/Replies/Reposts/Quotes recent-only — are all identical to desktop. Mobile is a layout pass.
States are loading / thin-data / populated / error. Loading is a skeleton that mirrors the populated layout so nothing reflows. Thin-data is an honest «building daily» treatment — never a fake flat line. Error offers a Retry.

2The panel on a phone

The whole panel in context, light and dark — Views · 90d, populated. The metric selector scrolls horizontally; the lifetime tiles drop to a 2-up grid.

3fixMetric selector + range

Five metric tabs don't fit a phone row, so the selector becomes a horizontally scrollable segmented row — each tab keeps its icon so it stays compact, ≥44px hit. The range control (30d / 90d / 1y) sits at the top-right of the header and wraps below the caption if the locale is long.

Rules. .emetric is overflow-x:auto; tabs are flex:1; min-width:max-content so short labels fill and long ones scroll. Active tab = surface + shadow, icon tinted accent. The active tab drives the series, the headline value, and the headline trend.

4newTime series + tooltip

Same line as Follower growth — accent 2.2px stroke, soft accent area, a dot on the latest point — but 0-based with a faint floor rule. On a phone the plot is 132px; tap or drag across it to reveal the per-point tooltip (weekday + date and the value). Labels stay sparse (~5) so dates never wall up.

0-based, on purpose. A per-day metric belongs on a 0 floor. When older days of a Likes/Replies series are genuinely 0 the line rests on the floor and then climbs out of it — empty reads as empty, not as a plateau. (The Follower line is min–max because it is a count that should never touch 0.)

5newLifetime tiles

Below the chart, four small stat tiles for the account-wide lifetime totals — Likes · Replies · Reposts · Quotes. These are the reliable figures from the latest snapshot, independent of the metric or range above. On a phone they drop from 4-up to 2-up; a null total renders «—».

6States

loadingthin-datapopulatederror

Loading mirrors the populated layout (skeleton selector + headline + chart + tiles) so nothing reflows. Thin-data plots the few real points honestly with a hatched «still building» stretch and a footnote — never a fake flat line. Error replaces the chart + tiles with a compact tile and a Retry.

7The five metrics

Each metric over 90d. Views is a full, real, backfilled series. Likes / Replies / Reposts / Quotes are recent-only — the older two-thirds of the window are genuinely 0, so the line rests on the floor and then climbs. When the previous window has no data the trend reads «no prior window».

8360px

No new breakpoint. The metric selector already scrolls, so longer labels stay reachable; the lifetime tiles stay 2-up (numbers are short); the headline number and chart get ~30px narrower; the chart's date labels are live DOM text and localize. The tooltip clamps to the plot edges so it never clips.

Localization. Metric labels, the range labels, the «Lifetime totals» caption, the «vs previous …» sub, the «no prior window» / «building daily» copy, and the bucket/tooltip dates all localize (8 locales); DE/RU/UK run ~30–40% longer. Numbers are tabular and locale-formatted.

9Checklist

  • Panel sits in the Stats stack after Follower growth; outer card = .m-spanel; single column.
  • Metric selector scrolls horizontally; all 5 reachable (icon + label); ≥44px hit; active drives series + headline value + trend.
  • Range control 30d / 90d / 1y (default 90d), top-right, wraps under the caption on long locales.
  • Time series styled like the Follower line (accent 2.2 + soft area + latest dot) but 0-based with a faint floor rule; 132px on a phone.
  • Per-point tooltip on tap/drag: weekday + date and the value; clamps to the plot edges; never clips.
  • Lifetime tiles: account-wide Likes / Replies / Reposts / Quotes; 2-up on a phone; null → «—».
  • Honesty: Views real + backfilled; per-day Likes/Replies/Reposts/Quotes recent-only; mostly-zero-then-real reads as empty-then-real.
  • States: loading (skeleton, no reflow) · thin-data (honest «building daily») · populated · error (couldn't load + Retry).
  • Correct in light and dark; no hardcoded colour; sanity-checked at 360px.
