Редактор сценария — модель «Карточка-рецепт» · спека и история изменений

Один экран: сценарий = читаемая фраза с редактируемыми слотами; тап по слоту разворачивает редактор блока на месте (inline-drawer); справа — живой предпросмотр, «следующие 3 запуска» и «Прогнать сейчас». Ниже — все изменения с момента первого дизайна и точные размеры, отступы, цвета и токены для разработчика.

экран: Scenario-Editor-Recipe-SPEC.html стили: recipe-editor.css рендер: recipe-editor.js данные: scenarios-redesign-data.js (window.SR) база: ds/tokens.css · ds/components.css · scenarios.css · scenarios-redesign.css
iСлой строится только на семантических токенах дизайн-системы (никаких хардкод-hex). Светлая и тёмная темы — автоматически. Все значения ниже даны как токен + пиксельный эквивалент.

1 · Что менялось — история по твоим правкам

По порядку, от первоначального дизайна до текущего состояния.

0
Первоначальный дизайн — модель «Карточка-рецепт»
Уход от пошагового редактора (6 шагов) к одной фразе-рецепту. Двухколоночник (рецепт слева, живое превью справа), inline-drawer на каждый слот, 3 слоя глубины (Суть / Настроить точнее / Только для этого сценария). Поддержка пост и ответ, состояния (новый / правка / из шаблона), тёмная тема.
1
Фраза стала обычным предложением
Убраны мета-метки «КОГДА / ЕСЛИ» внутри текста и принудительный перенос строки. Фраза читается слитно. Условие «только если…» вынесено отдельной тихой строкой под фразой (.recipe-cond). Причина: деление текста метками выглядело рвано.
2
Убраны голубые фоны-выделения слотов
Слоты больше не залиты цветным блоком — просто текст. Причина: блоки-подсветки выглядели тяжело.
3
Длинный текст → отдельное окно ввода
Все свободные поля (инструкция, тон ответа, своя аудитория) — не тесная textarea, а триггер (.bigtext) с кнопкой «Открыть в отдельном окне». Тап открывает полноразмерное модальное окно (.bt-dialog) с большим полем, подсказкой и «Сохранить». Причина: в маленьких полях неудобно вводить много текста.
4
Оформление слотов: без подсветок и подчёркиваний-блоков
Перебрали стили (5 → ещё 3 → ещё 3 варианта). Финал: вариант v9 — тёмный полужирный текст + серый пунктир-точки снизу; активный (раскрытый) слот синеет. Сверху — строка-подсказка «Нажми на подчёркнутые слова…». Все 11 вариантов сохранены в CSS как .recipe--v1…v11 для будущего выбора.
5
Имя аккаунта — свой цвет
@handle теперь фиолетовый (--mention), отдельной палитрой, чтобы не путался с редактируемым синим. Не кликабелен — это контекст, а не слот.
6
Слоты переносятся по строкам
Слот сменил тег <button> (inline-block) на <span role="button"> (display:inline). Длинный слот теперь разрывается по словам на 2–3 строки, а не прыгает блоком на следующую строку. Причина: рваное выравнивание фразы.
7
Гибкий планировщик «Когда»
Слот «Когда» раскрывает полный планировщик с 7 режимами частоты: каждый день · раз в N дней · по дням недели (с опцией разное время в разные дни) · раз в месяц (числа месяца + «последний день») · раз в год (даты-годовщины) · период дат (разовая акция с окном) · по событию (реактивный). Везде — точное время (любой час), несколько слотов в день, разброс минут и честные подписи про лимиты площадки.
