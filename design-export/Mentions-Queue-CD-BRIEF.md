# CD-бриф — Экран «Упоминания»: очередь с интентами, медиа и рутинами

> Готов к вставке в Claude Design. Вставь всё, что ниже линии. Это РЕДИЗАЙН
> существующего экрана `/app/mentions` (сейчас — плоская лента текста + «Открыть
> в Threads»). Бэкенд Фазы 1 уже в проде: каждое упоминание получает интент,
> причину скипа, медиа-поля. Живой код: `src/app/app/mentions/page.tsx`.
> Дизайн-система: `ds/tokens.css` (ink-on-paper, один акцент, обе темы).
> Ориентир по карточкам-действиям и очередям: экраны «Ответы» + «Автопилот».

---

## Идея (что строим)

Упоминание в Threads — это пост ПОСТОРОННЕГО человека, который тегнул аккаунт.
Раньше все упоминания сваливались в одну плоскую ленту. Теперь каждое
классифицировано по ЦЕЛИ (интенту), и экран должен это показывать: что можно
доверить авто-ответу, что требует внимания владельца, а что — мусор. Плюс
упоминания несут вложения (фото/видео), которые надо показать. И скоро появятся
РУТИНЫ упоминаний (автоматические сценарии под конкретную цель). Экран — это
командный центр по входящим упоминаниям, а не просто список.

## Правда о данных (рисовать под неё)

Каждое упоминание несёт:
- **интент** (одно из 12 значений, три группы):
  - AUTO-safe (можно на авто): `question` (вопрос), `praise` (похвала/шаут-аут),
    `general` (нейтральное);
  - QUEUE-only (никогда авто, ждёт владельца): `lead` (деловой запрос),
    `complaint` (жалоба), `provocation` (провокация), `competitor` (наживка
    конкурента);
  - SKIP-silent (мусор, уже отфильтровано): `spam`, `scam` (скам-розыгрыш),
    `phishing` (фишинг), `injection` (попытка манипуляции ботом), `irrelevant`
    (не нам);
- **skip_reason** (для отфильтрованных: `url` / `mass_tag` / `obfuscated` или
  имя спам-класса);
- **status**: `new` / `replied` / `drafted` / `skipped`;
- **медиа**: `media_type` (IMAGE / VIDEO / TEXT_POST / …), `media_url`,
  `thumbnail_url`;
- автор, текст, пермалинк, время.

## Структура экрана

Три смысловых зоны (владелец должен различать их с первого взгляда):

1. **«Требуют вас»** (сверху, приоритет): QUEUE-only интенты — лид, жалоба,
   провокация, конкурент. Это то, на что бот сознательно НЕ отвечает сам.
   Каждая карточка с ярлыком интента и подсказкой почему («деловой запрос —
   решать вам», «жалоба — черновик деэскалации готов»).
2. **Лента упоминаний**: AUTO-safe + уже обработанные (replied/drafted). Карточка
   показывает интент-чип, статус, медиа-превью.
3. **«Отфильтровано»** (свёрнутая секция внизу, по умолчанию collapsed): spam/
   scam/phishing/injection/irrelevant. Не мусор в глаза, но доступно («мы
   отсеяли N упоминаний» + разворот со списком и причинами). Скам/фишинг с
   пометкой-предупреждением «это развод, отвечать не нужно».

## Анатомия карточки упоминания

- **Шапка**: аватар-заглушка + `@автор` + время. Чип интента (иконка + короткое
  слово: «Вопрос» / «Лид» / «Жалоба» / «Спам»…), спокойный тон, НЕ светофор:
  один акцент на весь экран, интенты различаются иконкой + текстом, не буйством
  цветов. Опасные (scam/phishing/injection) — единственные, кому уместна
  сдержанная предупреждающая окраска.
- **Текст** упоминания (с существующей кнопкой «Перевести» / «Показать оригинал»).
- **Медиа-превью** (НОВОЕ): если есть вложение — картинка (или постер видео с
  бейджем «Видео»). Для скам/фишинг/подозрительных медиа — размытое превью с
  «Показать» по клику (модерация Фазы 2). Видео продукт не «смотрит» — если
  владелец генерит ответ, честно помечаем «видео я не вижу».
- **Статус-строка**: «Отвечено» / «Черновик готов» / «Пропущено: причина» /
  «Новое».
- **Действия** (по статусу и интенту):
  - AUTO-safe новое: «Сгенерировать ответ» (→ черновик в голосе, как в «Ответах»),
    «Открыть в Threads», «Пропустить».
  - QUEUE-only: «Сгенерировать черновик» (осознанно, без авто), «Открыть».
  - drafted: показать черновик + «Отправить» / «Изменить» / «Отклонить».
  - skipped: «Открыть в Threads», «Вернуть в работу» (разблокировать).

## Рутины упоминаний (заложить место, детально не рисовать)

Скоро появятся автоматические сценарии под интент («на все вопросы — авто-ответ
в голосе», «на упоминания с фото — обработать и ответить картинкой»). Заложи на
экране вход в «Рутины упоминаний» (ссылка/секция рядом с «Автопилотом» или
кнопкой в шапке) — карточки-рутины в том же стиле, что рутины постинга. Полный
конструктор рутин — отдельный бриф позже; сейчас только предусмотри место.

## Настройка (в шапке или отдельной панели)

- **Отдельный дневной лимит ответов на упоминания** (бэкенд:
  `mention_replies_per_day`) — контрол «Не больше N ответов на упоминания в день»
  рядом с общим лимитом ответов, с пояснением «отдельно от ответов под постами».

## Состояния (нарисовать все)

1. Полная очередь: «Требуют вас» (2-3 карточки) + лента (4-5, разные интенты и
   статусы) + свёрнутая «Отфильтровано (N)».
2. Карточка с фото-вложением; карточка с видео-вложением (постер + бейдж);
   карточка со скрытым/размытым медиа (подозрительное).
3. Карточка каждого статуса: new, drafted (с черновиком), replied, skipped.
4. Опасная карточка (scam/phishing) с предупреждением.
5. Развёрнутая секция «Отфильтровано» со списком и причинами.
6. Пустое состояние (упоминаний нет ещё).
7. Reconnect-состояние (нет scope) — уже есть, сохранить.
8. Панель настройки лимита упоминаний.
9. Мобильная версия ленты + карточки + развёрнутого медиа.

## Ограничения

- Обе темы (light/dark), только токены `ds/tokens.css`, один акцент.
- Тон: помощник-фильтр, не «стена входящих». Опасное подсвечено, ценное на виду,
  мусор убран с глаз.
- Тексты РУ по умолчанию; без длинных тире.
- Не выдумывать действий, которых нет в бэкенде (генерация ответа, отправка,
  пропуск, перевод, открыть — есть; «пожаловаться на аккаунт» Threads API не
  даёт — только «Открыть в Threads»).
- Итог: `Mentions-Queue-SPEC.html` + `Mentions-Queue-Mobile-SPEC.html`.
