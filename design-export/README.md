# design-export — сюда складываем экраны из Claude Design

Это «приёмник» для готовых экранов из проекта Claude Design. Чат-редизайнер
(Phase 7) берёт макеты **отсюда** как эталон и адаптирует их в реальный код
`src/app/...` (с настоящими данными, i18n, токенами тёмной темы).

## Как сложить экран (по одному, в любом темпе)

1. В Claude Design открой нужный экран → возьми **код** (кнопка вида
   «Copy code» / «Get code» — Claude Design отдаёт React/JSX).
2. Создай здесь файл с понятным именем по экрану, например:
   - `01-feed.tsx` · `02-replies.tsx` · `03-mentions.tsx` · `04-stats.tsx`
   - `05-audits.tsx` · `06-patterns.tsx` · `07-autopilot.tsx` · `08-voice.tsx`
   - `09-style-rules.tsx` · `10-settings.tsx` · `11-onboarding.tsx`
   - `12-login.tsx` · `13-landing.tsx` · `14-legal.tsx`
   - плюс каркас: `00-shell.tsx` (сайдбар + верхняя панель) и `00-studio.tsx`
     (одобренный Studio — эталон стиля).
3. Вставь скопированный код в файл, сохрани. Всё.

Если Claude Design даёт **картинку**, а не код — клади скриншот сюда
(`01-feed.png` и т.д.), редизайнер сверстает по ней.

## Что важно

- **Имя файла = номер экрана из `../SCREEN_MAP.md`** — так редизайнер сразу
  поймёт, какой экран это и какая у него структура/данные.
- Это **эталон вида**, не финальный код. Реальные данные, i18n-строки и
  семантические токены редизайнер вкрутит сам — не правь это здесь руками.
- Папку можно (и нужно) коммитить — это входной материал фазы.
