Scenarios /app/scenarios — phone

A scenario is recurring or conditional content in the author’s voice — КОГДА (trigger) → ЕСЛИ (condition) → СГЕНЕРИРОВАТЬ (post/reply) С ИНСТРУКЦИЕЙ on top of the voice. This is the phone pass for all four screens — List, Template picker, the «Акция» editor, and the «Свой» editor — designed for the narrow viewport: no sidebar, a hamburger drawer, a free bottom edge, every control 16px text / ≥44px tap, the desktop two-column editor folded to form → sticky-less preview → full-width save bar, and the delete confirm as a bottom sheet. Frames are the real product layer (pennedly-mobile.css on ds/tokens.css) at 390px, light and dark, sanity-checked at 360. Placeholders are the RU «Соня» case (a daily birth-date mini-reading); the feature itself is generic. Off by default for every scenario.

scenarios-mobile.css pennedly-mobile.css ds/tokens.css ds/components.css mobile/mock.js
What does not change from desktop. The model (КОГДА → ЕСЛИ → СГЕНЕРИРОВАТЬ · С ИНСТРУКЦИЕЙ), the four screens, every state, OFF-by-default, the «Акция» fields and live preview, and the read-only run-times all come from the same backend. Mobile is a layout pass; the only structural change is the shared app shell (hamburger + drawer instead of a sidebar). Hours are UTC server-side, shown in the viewer’s local timezone.
Where the Scenarios tab lives. No bottom tab bar — nav is the hamburger .m-drawer. Scenarios sits in Voice & automation, before Autopilot, tester-gated (Scenarios = intent, Autopilot = the executor). Icon = repeat-loop, never a bolt.

4screen 1Список сценариев

Each scenario is a full-width card: a template icon, the name, the template badge (Акция / Рубрика / Сезонное / Свой), an on/off toggle (top-right), a one-line trigger description, then «след. запуск» / «последний запуск» and a full-width «Открыть». Off → dimmed, “— на паузе”. States: list / empty / loading / error.

Before

The desktop card’s one-row footer (runs left, “Открыть” right) and the title-row badges crush below 360.

After

Badge + toggle wrap under the name; the runs sit in a two-column row above a full-width “Открыть”; the whole card is a comfortable tap target.

4.1 — Пусто / Загрузка / Ошибка

Empty explains the model + offers template chips + “Создать сценарий”. Loading mirrors the card layout with skeletons. Error is an inline banner with “Повторить”.

5screen 2Выбор шаблона

A full screen (route …/new) of full-width, stacked, tappable template cards — Акция and Свой are live; Рубрика and Сезонное are “скоро” (dimmed, not tappable). Each card: icon, name, a short explanation, and a chevron.

6screen 3Редактор «Акция»

The desktop two-column (form + sticky preview) folds to a single column: form sections first (Что за акция · Когда запускать · Как отвечать), then the live preview as its own section (assembled CTA + a mock post + a sample reply), then the save bar. Every field is 16px / ≥44px; the schedule is a full-width two-segment control; delete is a bottom sheet.

Before

A 380px sticky preview beside the form has nowhere to go on a phone; the three save buttons in a row are too small to tap safely.

After

Preview drops below the form as a normal section; the save bar stacks full-width (“Сохранить и включить” primary on top); delete opens a confirm sheet.

6.1 — Состояния

New/empty (preview = empty invite, no “Удалить”) · preview-loading (skeleton in the preview section) · «Раз в N дней» schedule · saving (spinners) · validation error (field + banner) · delete sheet.

Rules. Gift glyph in the «Акция» badge. The assembled CTA recomputes from “что просим” + “что даём” (+ subscribe/like); while it recomputes the preview section shows skeleton lines. Saving leaves the scenario OFF; “Сохранить и включить” flips it on. Delete is irreversible — confirmed in a bottom sheet (danger primary on top).

7screen 4Редактор «Свой»

Simpler than «Акция»: one section of stacked fields straight from the model — Название · КОГДА (trigger) · ЕСЛИ (condition, optional) · СГЕНЕРИРОВАТЬ (action) · С ИНСТРУКЦИЕЙ (on top of the voice) — then the same preview section and save bar. Each label carries its model-key chip.

«Свой» = «Акция» without the wrapper. Same four model parts, set directly through selects rather than friendly “что просим / что даём” fields. The preview depends on the chosen action: “Пост” → a single mock post; “Ответ в комментариях” → the comment→reply mechanic.

10Web ↔ mobile

Desktop ( > 880 )

  • Fixed sidebar; 960px column; status pill in topbar; hover states on cards/buttons.
  • List: card footer in one row (runs left, “Открыть” right).
  • Template picker: 2×2 grid.
  • Editor: two columns — form + sticky preview (380px).
  • Delete = inline confirm in the action bar.

Phone ( ≤ 600 )

  • No sidebar/tab bar; hamburger → drawer + account; free bottom edge.
  • List: badge+toggle wrap under name; runs row; full-width “Открыть”.
  • Template picker: full-width stacked cards.
  • Editor: form → preview section → full-width save bar (no sticky).
  • Delete = bottom sheet (danger primary on top).

11Localization & 360px

All end-user copy — the intro, template names/descriptions, the «Акция» field labels (“Что просим написать в комментах”, “Что даём взамен”), the schedule segments, the model keys, the run-time labels, empty/error — localizes into 8 locales (en/ru/uk/de/es/fr/it/pt); RU/DE run ~30–40% longer. On a phone: template badges wrap under the name; the schedule segment labels wrap inside their ≥44px buttons; field labels wrap above their full-width control; the save buttons hold 16px and wrap to a second line rather than clip.

360px behavior. No new breakpoint — gutters stay 14px; cards, template cards, and editor fields are already one column; the schedule segment stays two equal cells (labels wrap to two lines); the save bar stays full-width stacked; the delete sheet stays full-width with the danger primary on top. Long RU/DE labels (“Что просим написать в комментах”, “Сохранить и включить”) wrap and never clip; selects/inputs hold 16px / ≥44px. The drawer stays min(82%, 312px) → ≈295px at 360.

12Checklist

  • Below 600px: no sidebar, no tab bar — one top bar with a hamburger far-left, the title, (when ≥1 on) a “N активны” success pill with a live dot, and a ＋ action; bottom edge free.
  • Hamburger opens the drawer (active = Scenarios, repeat glyph, Voice & automation, before Autopilot, tester-gated) + account at its foot.
  • Scenario icon = repeat-loop; Акция = gift; Свой = sliders; Рубрика = layers; Сезонное = calendar; auto-reply = chat bubble; no bolt.
  • List card: icon · name · template badge · on/off toggle · trigger desc · «след. запуск» / «последний запуск» · full-width «Открыть»; off → dimmed + “— на паузе”.
  • List states: list · empty (model explainer + template chips + “Создать сценарий”) · loading (skeletons mirroring the card) · error (banner + “Повторить”).
  • Template picker: full-width stacked cards; Акция + Свой live; Рубрика + Сезонное “скоро” (dimmed, non-tappable).
  • «Акция» editor: form sections (Что просим · Что даём · subscribe/like toggles · schedule Ежедневно / Раз в N дней + N · Как отвечать) → live preview section (CTA + mock post + reply) → save bar; all 16px / ≥44px.
  • «Акция» states: new/empty (empty preview, no “Удалить”) · filled · preview-loading (skeleton) · Раз в N дней · saving (spinners) · validation error (field + banner) · delete bottom sheet.
  • «Свой» editor: Название · КОГДА · ЕСЛИ (optional) · СГЕНЕРИРОВАТЬ · С ИНСТРУКЦИЕЙ; simpler than «Акция»; preview depends on the action.
  • OFF by default; “Сохранить” leaves off, “Сохранить и включить” turns on; delete confirmed in a bottom sheet (danger primary on top).
  • Correct in light and dark; only semantic tokens; copy survives the longest of 8 locales — never clipped; sanity-checked at 360px.
