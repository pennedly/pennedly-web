Pennedly · Spec · Studio — Ideas hook-brainstorm panel

Ideas /app — brainstorm hooks in your voice

The composer’s action row already carries AI suggestion chips, a draft-count select and the Generate button. This spec documents the “✨ Ideas” pill that now leads that row — an accent-tinted chip that brainstorms ~8 post ideas in the account’s own voice (from their role-book + top-performing posts) into an inline panel under the action row. Each idea is a bold hook (a ready-to-expand opening line) plus a muted one-line angle. Tapping an idea replaces the editor text with the hook to seed the brief, and closes the panel. Ideas are ephemeral (never saved) and free (they don’t spend the monthly post quota). The feature already shipped without a design — this is its reference spec. Every state is the real composer layer (studio.css + studio-ideas.css) over ds/tokens.css, in light and dark.

Extend, don’t redesign. The composer, its chips, the count select and Generate are unchanged — the Ideas pill is simply the first chip, set apart only by an accent tint and its lead position. The panel reuses the shipped placement (inline, under the action row, above the draft list). On pick, the hook replaces the editor text (it seeds the brief) — never appends. No saved-ideas library, no quota/cost UI — ideas are ephemeral and free.

0Where it lives

One accent pill in the action row; one inline panel below it. The panel opens under the row (its own border-top divider) and above the draft feed — the same region the shipped feature already uses. It respects the composer’s padding and never overpowers the draft below.

＊New icon needed

The panel header’s refresh control needs a reload glyph. IcSparkle (chip + caption), IcX (close), IcArrowUp (the “Use” affordance) and IcCheck are reused from the shipped set — but there is no reload glyph in studio-icons.jsx. Add one to icons.tsx in the same 24-grid / 1.8-stroke family.

Usage. IcReload — the panel’s “more ideas” refresh and the error “Try again”. No new tokens are introduced; the chip’s accent tint is built from the existing --color-accent.

1The Ideas chip

The action-row chips now sit in one horizontally-scrolling row on every width (no flex-wrap, hidden scrollbar, a right edge-fade) — so the count select + Generate stay flush on the same line and no gap opens at the top-right. The accent “✨ Ideas” pill is first and always visible; overflow chips scroll under the fade. When generation is unavailable (no connected account, or no active voice yet) the pill is disabled with a short hint. The pressed/open state lives in §2–§3.

Disabled reasons map to the API’s 422. No connected account → “Connect an account to brainstorm ideas”. No active voice → “Finish setting up your voice to brainstorm ideas”. The hint is plain text-subtle, never a red error — brainstorming is optional and free.

2Loading

Tapping the pill presses it (the sparkle pulses, the chip is disabled so it can’t double-fire) and opens the panel in its loading state: a pulsing sparkle + “Brainstorming ideas in your voice…”, over three shimmer placeholders that hint at the incoming list. The pulse honors prefers-reduced-motion.

3Results — the panel

A header row — the IDEAS IN YOUR VOICE caption on the left, a refresh (more ideas) and a close on the right — above a vertical list of 6–8 idea cards. Each card is a bold hook + a muted angle. The list caps its height and scrolls internally, so even the full ~8 never pushes the draft feed too far down.

4Idea card → pick → seed

On hover or keyboard focus a card takes an accent border + a faint accent tint, and a “Use ↑” affordance fades in — a quiet cue that the hook seeds the brief upward into the editor. Tapping it replaces the editor text with that hook (it doesn’t append) and closes the panel; Generate is now enabled.

Seed, don’t append. The hook becomes the new brief — the user expands it, edits freely, then Generates. A subtle accent micro-note (“Seeded from an idea — edit freely, then Generate.”) confirms what happened without nagging. Ideas are never saved; refreshing or closing discards them.

5Error & empty

Two quiet end-states. Error (503 / model down): “Couldn’t get ideas.” + a calm “Try again”. Empty (rare — the account has no voice or posts to riff from): “No ideas right now.” with a one-line nudge. Neither is a red banner; the panel stays light because brainstorming is free and repeatable.

＊Icon refresh — three primary actions

New line-icons for the three primary Studio actions, in the same calm single-weight family. Each is named for icons.tsx and shown before → after, then on the real button in light and dark. (The composer’s single-scroll chip row from §0–§1 is the only other action-row change.)

Keep the set coherent. IcNib → IcGenerate on Generate (the “Drafting…” busy state keeps the new glyph with the existing nib-write motion). IcCheck → IcApprove (check-in-circle) on a draft’s Approve. IcStudio → IcPublish (paper-plane) on Publish to Threads. The publish dialog’s “Publish now” confirm currently uses IcCheck — switch it to IcPublish so the publish action reads the same on the card and in the dialog. IcCheck then stays the generic save/confirm mark (inline Edit “Save”, alt-text “Save description”) and no longer clashes with Approve; IcSend (arrow) stays the tweak-bar “send” affordance, visually distinct from the paper-plane.

＊Behaviour & guardrails

Ephemeral & free

  • Ideas are never persisted — refresh or close discards them. There is no saved-ideas library.
  • They don’t spend the monthly post quota and never reserve it — no cost/quota UI appears anywhere in the panel.
  • POST /api/generation/ideas {account_id, count 3–12 default 8} → {ideas:[{hook, angle}]}; voice = active role-book + top-5 posts by views. Rides the per-minute burst limit.
  • No count control — ideas default to ~8. Want more? The header refresh re-rolls a fresh ~8 (the existing count select stays bound to post generation, not ideas).

Motion & reduced-motion

  • The sparkle pulse (pressed chip + loading) and the skeleton shimmer are the only motion; both stop under prefers-reduced-motion: reduce — the static state reads fine.
  • The panel’s entrance (fade + 4px rise) is also suppressed under reduced-motion.
  • Every control carries an aria-label; the open chip is aria-expanded; the list is keyboard-navigable and a card’s focus state matches its hover state.

— localization (8 locales)

All copy localizes (studio.ideas, ideas_title, ideas_loading, ideas_error, ideas_retry, ideas_empty, ideas_refresh, ideas_close). DE/RU run ~30–40% longer than EN: the chip label and caption never clip, and hooks + angles wrap to as many lines as they need.
