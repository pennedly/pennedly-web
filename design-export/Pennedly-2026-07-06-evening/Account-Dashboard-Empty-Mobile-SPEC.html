Дашборд аккаунта — пустые состояния /app/account · телефон, 0 живых профилей

Телефонный парный документ к десктопным пустым состояниям. Новые состояния, не новый экран. Сегодня без живого профиля шелл жёстко редиректит в мастер подключения — весь хром исчезает, пользователь ощущает себя разлогиненным. Мы делаем дашборд durable поверх профилей — для всех, кроме брэнд-нью пользователя: брэнд-нью (0 профилей когда-либо) получает полноэкранный первый вход с пикером сетей (см. Connect-Network-Picker-Mobile-SPEC). Всем остальным — полный телефонный шелл (гамбургер → drawer + логин-переключатель; докнутая кнопка профилей) во всех состояниях: «все отключены», «смешанное», плюс скелет и ErrorBanner. «Подключить другой» и «Переподключить» открывают тот же пикер сетей (нижний sheet). Текст русский, 8 локалей (эталон — немецкий), проверено до 320px.

account-empty-mobile.css + networkPicker + disconnectedCard + reassure + errorBanner account-mobile.css pennedly-mobile.css
Критерий приёмки (правила 1–2). Полный шелл во всех in-dashboard состояниях; отключивший последний профиль не редиректит в онбординг (брэнд-нью → полноэкранный пикер). Однострочные элементы (@никнеймы, метки кнопок, пилюли, «N профилей») не переносятся — усечение, не разрыв. Никаких фейковых метрик. Текст русский; контейнеры держат немецкую длину. Доказано на 390/360/320px и на немецкой длине.

1Идентификация + сдвиг поведения

Тот же экран, что Account-Dashboard-Mobile-SPEC — меняется только поведение без живых профилей.

Было

0 профилей → редирект в мастер. Полноэкранный онбординг, хром скрыт. Отключивший последний профиль ощущает себя разлогиненным.

Стало

Отключился последний профиль → дашборд с полным шеллом. Drawer + логин + докнутая кнопка на месте; отключённые профили с «Переподключить». Брэнд-нью → полноэкранный пикер.

Маршрут/app/account. Существует поверх профилей, не требует ни одного живого.
Шелл (всегда)Гамбургер → drawer (Дашборд / Советник / Настройки) + логин-переключатель в подвале; топ-бар; докнутая кнопка профилей.
СостоянияПервый вход (0 когда-либо) → полный экран (пикер). В дашборде: all_disc · mixed · loading · error.
ДействияConnect / Подключить другой / Reconnect открывают общий пикер сетей (Threads live · LinkedIn «скоро»). Threads → OAuth; Reconnect — на известный @handle.

2Состояния одним взглядом

Три состояния подряд, светлая тема: полноэкранный первый вход (пикер сетей), баннер уверенности + карточки «Отключён» (all_disc), обычный дашборд с отключённым профилем inline (mixed).

3pickerПодключение · пикер сетей

Брэнд-нью пользователь (0 профилей когда-либо) сюда не попадает — ему показывается полноэкранный первый вход с пикером сетей; он вынесен в Connect-Network-Picker-Mobile-SPEC. В дашборде тот же пикер открывают «Подключить другой» и «Переподключить» — нижним sheet. Ниже: первый вход (полный экран) и лист «Подключить другой» / «Переподключить @mara.co».

4состояние 2 · heroВсе отключены

Профили были, но все отключены. Главный анти-«я потерял кабинет» момент: баннер уверенности (данные, настройки, голос и история целы), идентичность без фейковых итогов, и каждый профиль — карточкой с status-pill--warning «Отключён» + «Переподключить», плюс «Подключить другой аккаунт». Докнутая кнопка сохраняется (профили отключены).

5состояние 3Смешанное

≥1 живой + ≥1 отключён. Обычный дашборд (шапка + портфель + «Требует тебя» + советник + карточки), но отключённые профили inline с пилюлей «Отключён» + «Переподключить» вместо метрик — видимы и восстановимы. Рядом: synced, отключён, сбой синка (danger, отличается) и importing.

6Карточка «Отключён» — анатомия

Переиспользуемый блок (и в §4, и inline в §5). Приглушённый аватар, чёткие @никнейм + имя, пилюля status-pill--warning «Отключён» + «Данные сохранены», строка disconnected_at и primary «Переподключить». Warning-тон — не danger.

7Загрузка + ошибка

Скелет повторяет раскладку дашборда. Ошибка — общий ErrorBanner (§3.8, класс .m-error) с Retry; «данные в безопасности».

8хромШелл сохраняется

Доказательство: даже без живых профилей гамбургер открывает drawer навигации аккаунта с логин-переключателем в подвале, а докнутая кнопка — плоский переключатель (в all_disc — с отключёнными профилями). Пользователь никогда не «выпадает» из своего аккаунта.

9правила 1–2Раскладка · 390 · 360 · 320 + de

Один дашборд при 390 (реф), 360, 320px и на немецкой длине. Ни один однострочный элемент не переносится: длинные подписи усекаются, кнопки держат ширину, метрики держат сетку.

10Чек-лист

  • Полный шелл во всех in-dashboard состояниях: гамбургер-drawer (навигация аккаунта + логин-переключатель) + докнутая кнопка профилей. Отключивший последний профиль больше не редиректит в онбординг.

  • Отключён ≠ сбой синка: warning + Reconnect против danger + Retry.
  • Скелет повторяет раскладку; ErrorBanner с Retry.
  • Правило 1 (нет переносов) на 390/360/320; правило 2 (немецкая длина). Светлая + тёмная.
