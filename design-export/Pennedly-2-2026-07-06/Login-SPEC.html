Login /app/login — пиксель-в-пиксель

Дотошная спецификация full-screen passwordless-входа без app-shell: одна центрированная карточка на мягком радиальном фоне, переключатель языка справа сверху и выдвижной Developer-drawer снизу. Это вход стейт-машины view: email · code · signing с тремя накладываемыми ошибками. Ниже задокументированы АБСОЛЮТНО все виды, под-состояния, busy-состояния, состояния OTP-ячейки, кулдаун resend, переключатель языка, dev-drawer, тема и анимации — отдельно для веб- и мобильной версий. Все значения взяты из реального дизайна, без «примерно».

login-app.jsx login-parts.jsx login-data.jsx login-icons.jsx login.css ds/tokens.css ds/components.css
Стейт-машина одним взглядом. view: email → code → signing. Из email два пути: «Continue with Google» (→ busy «Opening Google…» → signing) и «Email me a code» (→ code). Из code: ввод/вставка 6 цифр запускает submit (→ busy → signing). signing — короткий спиннер, затем редирект: обычный вход → Onboarding.html, dev-вход → Studio.html. Три ошибки накладываются на email/code и НЕ являются отдельным видом. Все четыре состояния превьюются твиками View и Error state.

1Идентификация экрана

Маршрут, назначение, pre-auth-статус, условия показа Developer-drawer, раскладка сверху вниз.

Маршрут/app/login — первый, pre-auth экран. Первый успешный вход создаёт аккаунт.
ТипFull-screen, без app-shell (<Sidebar> НЕ рендерится). Собственный центрированный layout на радиальном фоне.
НазначениеPasswordless-вход: пароля нет нигде. Два пути — Google или e-mail-код (OTP). Коды живут ~10 минут, resend rate-limited (кулдаун).
Корневой контейнер.login → position:relative; min-height:100%; display:flex; flex-direction:column. Фон: radial-gradient(120% 75% at 50% -8%, mix(surface 55%, transparent) 0%, transparent 58%) поверх --color-bg.
view = emailПо умолчанию. Заголовок «Sign in to Pennedly», Google-кнопка, разделитель «or», поле e-mail + CTA «Email me a code», consent-строка.
view = codeПосле «Email me a code»: «Enter your code», 6-клеточный OTP, resend с кулдауном 30s, «change email», submit.
view = signingКороткий спиннер. Текст «Signing you in…» (после кода/dev) или «Opening Google…» (после Google). Затем редирект.
Developer-drawerРеальный dev-путь: email-only вход, гейтится build-флагом DEV_LOGIN (login-data.jsx → DEV_LOGIN.enabled). Виден ТОЛЬКО когда флаг включён; скрыт в проде. Bypass OTP, редирект в Studio.html.
ЛокализацияВесь end-user текст локализуется (title/sub, лейблы кнопок, ошибки, resend, consent). 8 локалей: EN/ES/DE/FR/IT/PT/RU/UK. OTP — digits-only, locale-agnostic.
Trademark-safeПлитка «G» Google — намеренно монохромная (GoogleMark в login-icons.jsx): не пропавший логотип, а trademark-safe знак. НЕ подменять цветным логотипом.

Раскладка сверху вниз

  1. Top-bar .login-top — justify-content:flex-end; единственный элемент — <LangSwitch> (переключатель языка) в правом углу.
  2. Сцена .login-stage — flex:1 1 auto; центрирует по вертикали и горизонтали единственную карточку .login-card.
  3. Карточка .login-card — <LoginHeader> (марка + title + sub) и далее ОДИН из видов: <EmailForm> / <CodeForm> / <SigningIn>.
  4. Developer-drawer .dev — прижат к низу .login (flex:0 0 auto), под сценой; закрыт по умолчанию.

Поведение OTP (digits-only)

  • Ввод цифры — пишется в ячейку, фокус авто-переходит на следующую (i < 5).
  • Backspace — если в ячейке цифра, очищает её; если пусто — переходит назад и очищает предыдущую.
  • ArrowLeft / ArrowRight — перемещают фокус между ячейками без правки.
  • Вставка (paste по контейнеру ИЛИ многосимвольный ввод в одну ячейку) — берёт только цифры, заполняет до 6, фокус на последней заполненной.
  • Авто-submit — как только набрано 6 цифр, вызывается onComplete → verifyCode().
  • Любой ввод сбрасывает текущую ошибку (if (err) setErr(null)).

Каждый вид, под-состояние, ошибка, busy, состояние OTP-ячейки, кулдаун resend, chrome (lang/dev/тема) и интерактив каждого элемента. Ничего не пропущено.

view · emailВид Email

defaultgoogle: idlegoogle: busyemail: empty (CTA disabled)email: valid (CTA enabled)+ rate-limit+ google-failed
  • default — title «Sign in to Pennedly», sub «No password, ever. Your first sign-in creates your account.» Google-кнопка (idle), «or», поле e-mail (autoFocus, пустое), CTA «Email me a code» disabled, consent.
  • e-mail валиден (/\S+@\S+\.\S+/) — CTA становится активной (opacity 1, кликабельна).
  • Google busy — после клика: кнопка disabled, содержимое = spinner + «Opening Google…». Через 700ms → view signing.
  • + rate-limit — <Alert> над CTA: «Too many requests. Wait a moment, then try again.» Поле НЕ получает .has-error (rate-limit не про конкретное поле), но Alert виден.
  • + google-failed — <Alert>: «We couldn't sign you in with Google. Please try again.»

view · codeВид Code

empty (submit disabled)partial 1–5full 6 (auto-submit)submit: busyresend: cooldownresend: ready+ invalid-code (danger + SHAKE)
  • empty — title «Enter your code», sub «It expires in 10 minutes. You can paste it straight in.», .code-to с e-mail и «Use a different email». 6 пустых OTP-ячеек (первая в фокусе). Submit «Sign in» disabled. Resend в кулдауне 30s сразу при входе в вид.
  • partial (1–5 цифр) — заполненные ячейки получают .filled (bg surface-2). Submit всё ещё disabled.
  • full (6 цифр) — submit активна; авто-вызов verifyCode().
  • submit busy — кнопка disabled, spinner + «Signing you in…». Через 1000ms → view signing.
  • resend cooldown — кнопка resend disabled, «Resend in {n}s», counter тикает 30→0 каждую секунду.
  • resend ready — на 0 кнопка активируется, «Resend code», цвет accent/w600.
  • + invalid-code — .otp получает класс .error: danger-граница + danger-кольцо на ВСЕХ ячейках, плюс канонический SHAKE (0.4s). <Alert> под OTP: «That code didn't match. Double-check it and try again.» (твик подставляет 739104).

7Чек-лист

«Убедись, что X = ровно Y» — по каждому состоянию, плюс сквозные проверки.

Вид Email

  • title = «Sign in to Pennedly», sub про «No password, ever.»
  • Google-кнопка .btn--secondary.btn--google = 100%×46px, плитка монохромная G (НЕ цветной логотип)
  • Google busy → spinner + «Opening Google…», disabled
  • разделитель «or» uppercase, две линии border
  • CTA «Email me a code» disabled при невалидном e-mail (/\S+@\S+\.\S+/)
  • consent-строка со ссылками Terms / Privacy подчёркнута
  • rate-limit / google-failed = Alert над CTA, без shake

  • 6 OTP-ячеек 46×56 (моб 40×50), gap 9px (моб 6px)

  • filled → bg surface-2; focus → accent + ring 18%
  • submit disabled при <6 цифр; 6 цифр → авто-submit
  • submit busy → spinner + «Signing you in…»
  • resend кулдаун = ровно 30s, «Resend in {n}s» → «Resend code»
