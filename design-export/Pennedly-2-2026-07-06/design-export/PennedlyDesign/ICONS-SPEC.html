Icon inventory

The canonical, up-to-date set of every icon used anywhere in Pennedly — nav glyphs, button icons, inline indicators, status marks and empty-state glyphs. Each card shows the rendered glyph, its stable code name, the exact copy-pasteable SVG, and where it's used. This is the reference the live code is checked against; cards flagged in amber call out duplicate definitions, web↔mobile drift, or icons defined but possibly never applied.

Drift & duplication to reconcile. Several names ship more than one glyph or are defined in more than one file — poll (two glyphs), quote (outline / filled / sprite), logout, link, plus IcMail, IcSliders, IcScan, IcArrowRight and IcPen/IcPenLine defined in two files each. users, calendar and the status-bar glyphs exist only as mobile sprites with no web component.
