Overview /app/overview · All accounts

Приложение мультиаккаунтное, но каждый экран сегодня — про один аккаунт. Этот rollup показывает все подключённые аккаунты разом, чтобы человек, ведущий 3–4 аккаунта, видел общую картину без переключения по одному. Сверху — combined top strip с тоталами по портфелю (подписчики, 7-дневные просмотры, посты за неделю, ответы, ждущие реакции). Ниже — сетка карточек, по одной на аккаунт: аватар + @handle + ключевые метрики (подписчики и Δ, 7-day views, посты за неделю, комментарии, ждущие ответа) + статус импорта/синка (переиспользуется Phase-0 importing-state). Любая карточка — вход в полноэкранные экраны этого аккаунта. Точка входа — пункт «All accounts» в переключателе аккаунтов. Ниже — живые фреймы (реальные DS-компоненты, светлая И тёмная), анатомия, все состояния (один аккаунт + nudge / много / импорт / loading / empty / error), контракт данных, маппинг Web↔Mobile, локализация в 8 языков и чек-лист. Копи — на английском (исходная локаль).

overview-app.jsx overview-parts.jsx overview-data.jsx overview.css import-banner.css shell-parts.jsx ds/tokens.css + IcOverview
Живые фреймы — это реальный системный слой. Документ подключает ds/tokens.css + ds/components.css + import-banner.css и рендерит компоненты как в продукте на ширине --content-wide 960. Каждый фрейм пинит свои токены: светлый — из :root, тёмный — через класс dark. App-shell общий из Studio; в Overview контекст аккаунта — «All accounts» (не один аккаунт), поэтому ни один пункт sidebar не активен, а account-control внизу читает «All accounts».
Что особенного в этом экране.
  • Portfolio, не single-account. Это единственный экран без активного аккаунта: контекст — «все сразу». Sidebar-навигация ведёт в per-account экраны активного аккаунта; Overview достаётся из переключателя.
  • Тоталы + карточки. Top strip суммирует портфель (подписчики · 7d views · посты за неделю · ответы к разбору). Сетка — карточка на аккаунт с теми же 4 метриками на уровне аккаунта; вся карточка ведёт в его экраны, мелкие quick-links — в Stats / Replies (с счётчиком).
  • Переиспользует importing-state. Свежеподключённый аккаунт показывает в своей карточке тот же Phase-0 «Importing your history» баннер (import-banner.css), а метрики — плейсхолдеры, пока данные не подъедут.
  • Грациозная деградация на 1 аккаунт. С одним аккаунтом сетка — одна карточка + тёплый nudge «подключите ещё, чтобы видеть рядом». Никакого пустого «портфеля из одного».

1Идентификация экрана

Маршрут, назначение, ширина, раскладка сверху вниз: sidebar | main(topbar + scroll(top-strip + account-grid)). Read-only — карточки только ведут в per-account экраны.

Маршрут/app/overview. Достаётся из account switcher → «All accounts» (пин сверху меню) или как top-level Overview. Не привязан к одному аккаунту.
ТипПолный app-shell с особым контекстом: account-control = «All accounts», ни один пункт sidebar не active. Каркас 1:1 из Studio.
НазначениеВся картина по портфелю за один взгляд: суммарные метрики сверху + карточка на аккаунт с ключевыми числами и статусом синка. Вход в любой аккаунт — в один клик.
Ширина контентаwide = --content-wide 960. Топбар выровнен по той же ширине.
ТопбарЗаголовок «Overview» + .status-pill «4 accounts · updated daily» (глиф <IcOverview 13>) + тема + Settings.
Секции (top→bottom).ov-totals (combined top strip, 4 тайла) → .ov-grid (карточка на аккаунт). В single-account — карточка + .ov-nudge. В empty — .ov-empty.
Фазыloading (скелет сетки) · ready · empty (нет аккаунтов) · error (.ov-error + Retry). На уровне карточки: synced / importing / sync-error.
ЛокализацияEnd-user копи в 8 языках (en/ru/uk/de/es/fr/it/pt): заголовок, лейблы тоталов/метрик, статусы синка, nudge, empty/error копи, quick-links. Числа — формат локали; время «updated Nh ago» — относительный форматтер в TZ зрителя.

3.4 — Статусы синка синк-индикатор

Карточка несёт состояние своего аккаунта: synced (тихий «● Updated Nh ago»), importing (Phase-0 баннер вместо метрик), sync-error (danger «Sync failed» + Retry).

СтатусКлассЧто в карточке

sync-error.ov-sync--error«● Sync failed» (danger) + кнопка Retry. Остальные карточки не затронуты.

4Все состояния по очереди

single + nudgemany ●importingloadingemptyerror

4.1 — Один аккаунт (грациозная деградация + nudge)

С одним подключённым аккаунтом портфель не имеет смысла как сетка: top strip = метрики этого аккаунта, сетка = одна карточка, плюс тёплый .ov-nudge «ведёте больше одного? подключите ещё». Никакого пустого «портфеля из одного».

4.2 — Аккаунт ещё импортируется

Свежеподключённый аккаунт в сетке держит Phase-0 importing-карточку; тоталы помечают «+1 still importing» и не включают его числа, пока импорт не разрешится. Остальные карточки работают как обычно.

4.3 — Loading / Empty / Error

Loading — скелет, повторяющий раскладку (strip + сетка карточек). Empty — нет подключённых аккаунтов (edge): .ov-empty «Connect your first account». Error — .ov-error (danger-rail) «Couldn’t load your accounts» + Retry; это про загрузку списка аккаунтов, а сбой синка одного аккаунта живёт в его карточке.

СостояниеЧто рендерится
loadingСкелет strip (4 тайла) + 2–4 скелет-карточки, повторяющие финальную раскладку (без reflow).
empty.ov-empty: mark IcOverview + «No accounts connected yet» + sub + кнопка «Connect a Threads account».
error.ov-error: danger-mark + «Couldn’t load your accounts» + «Retry». Список не загрузился целиком.

5Данные · контракт

Один запрос на весь портфель. GET /api/portfolio?tz_offset= → массив аккаунтов + предрассчитанные тоталы.

КлючПоляКуда идёт
totalsfollowers (+delta), views_7d, posts_week, replies_to_answer, accounts_count, importing_countCombined top strip
accounts[]id, name, handle, avatar, followers (+delta), views_7d, posts_week, replies_to_answer, sync_status, synced_atКарточка на аккаунт
sync_statussynced · importing (+ import progress: posts/comments/total) · errorСтатус-строка / Phase-0 баннер
  • Тоталы суммируют только synced-аккаунты; importing считается в importing_count («+N still importing»), его числа не вмешиваются.
  • Δ followers — за тот же период, что и в Stats (месяц); time-метки «updated Nh ago» — относительный форматтер в TZ зрителя.
  • Карточка → аккаунт: клик переключает активный аккаунт и открывает его Stats; quick-links deep-link'ают в конкретный экран (Replies с ?filter=needs-reply).
  • Read-only: Overview ничего не мутирует — только навигация + Retry синка.

6Раскладка · Web ↔ Mobile

Брейкпоинты: 880px (сайдбар → icon-rail) · 760px (.ov-totals и .ov-grid → 2-up / 1-up) · 600px (телефонный shell). Полный телефонный проход — в Overview-Mobile-SPEC.html.

Десктоп ( > 880 )

  • Фикс. сайдбар; колонка 960; account-control = «All accounts».
  • Top strip — 4 тайла в ряд; сетка карточек — 2-up.
  • Карточка: 4 метрики в ряд; статус-строка с quick-links справа.

Телефон ( ≤ 600 )

  • Нет сайдбара/таб-бара; гамбургер → drawer; «All accounts» — пин сверху drawer-аккаунта/sheet.
  • Top strip — 2×2 тайла; сетка — карточки в столбик.
  • Карточка: метрики 2×2; статус-строка переносит quick-links под sync.

360px. Без нового брейкпоинта: гаттеры 14px; top strip держит 2×2; карточка — метрики 2×2; имя/handle усекаются ellipsis'ом; quick-links переносятся под sync. Importing-баннер внутри карточки складывает ETA под бар (как в Phase-0).
Числа и время — живой текст. Тоталы и метрики — tabular; «updated Nh ago» пересчитывается клиентом в TZ зрителя; имена аккаунтов локали не меняют, но @handle всегда LTR.

8Чек-лист реализации

  • Точка входа: пин «All accounts» сверху account switcher (.acct-row--all, IcOverview, «N connected · Overview») → /app/overview.
  • Полный app-shell; контекст = «All accounts» (account-control), ни один пункт sidebar не активен; топбар «Overview» + pill «N accounts · updated daily».
  • Combined top strip: 4 тотала (Followers +Δ · 7-day views · Posts this week · Replies to answer [attention]); «Across N accounts» + «+M still importing».
  • Карточка на аккаунт: аватар + name + @handle + .ov-go; 4 метрики (Followers +Δ · 7-day views · Posts this week · Replies to answer [accent при >0]); вся карточка ведёт в аккаунт.
  • Статус синка в карточке: synced («● Updated Nh ago») / importing (Phase-0 import-banner--syncing вместо метрик) / sync-error («Sync failed» + Retry).
  • Quick-links: «Stats» + «Replies N» (deep-link, --attention при >0).
  • Тоталы суммируют только synced-аккаунты; importing считается отдельно и не вмешивается.
  • Состояние single-account: одна карточка + .ov-nudge «подключите ещё» (Connect CTA) — грациозно, без пустого портфеля.
  • Loading = скелет, повторяющий раскладку; empty = «No accounts connected yet» + Connect; error = .ov-error + Retry (про загрузку списка, не синк одного).
  • Корректно в светлой и тёмной теме; ни одного hardcoded-цвета.
  • Копи в 8 локалях без клиппинга; проверено на 360px; числа tabular, «updated Nh ago» в TZ зрителя.
