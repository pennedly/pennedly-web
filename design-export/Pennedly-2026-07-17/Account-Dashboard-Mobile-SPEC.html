Дашборд аккаунта — телефон ~390, до 320 · тот же V3

Телефонный проход концепта V3 «Советник». Тот же порядок — Личность → Вердикт → Доказательства — в мобильном хроме: верхний бар (марка + аккаунт) и нижний бар Дашборд · [Бренды / Профили] · Настройки. Пункта «Советник» нет и здесь (решение C): строка вопроса и «Открыть советника» уводят в чат-экран. Всё — реальный вывод кита account/v3.js в режиме device:"mobile", свет + тьма. Ширина ревью ~390, раскладка доказана до 320 по правилам 1–2.

V3 · телефон − таб «Советник» device:"mobile" @container vbody 390 → 320
Критерий — правило 1 на телефоне. Однострочники — значения тоталов, чипы, @никнеймы, имена брендов, счётчики, метки кнопок — не переносятся на 390 / 360 / 320 (см. §10). Перенос сделан невозможным (white-space:nowrap, tabular-nums, усечение многоточием). Единственное исключение — заголовок-вердикт (text-wrap:balance), он не ломает соседей.

1Идентификация

Телефонный дашборд аккаунта. Сверху вниз: верхний бар (марка + тема + аккаунт) → личность → герой-вердикт → «Доказательства» (тоталы 2×2 + каналы столбиком) → нижний бар. Тот же компонент, что десктоп; переставляют контейнерные запросы @container vbody.

Маршрут/app/account · tester-gated. Профиль ≥ 1 (иначе онбординг).
ХромВерхний бар (марка + тема + кнопка аккаунта → лист) + нижний бар: Дашборд · [Бренды при 2+ / иначе Профили] · Настройки. Без «Советника».
ШиринаРевью 390. @container vbody: ≤560 → тоталы 2×2, каналы 1-стб, «Открыть советника» → иконка; ≤400 → вердикт мельче. Предел — 320.
СостоянияСоветник вердикт / тонкий (204) / загрузка; профиль synced / importing / error / disconnected. «Все отключены» → Empty-Mobile.

3390Полный экран

Весь телефон на 390: верхний бар → личность → герой-вердикт (вердикт → чипы → «На основе:» → рекомендации столбиком → ask-строка) → «Доказательства» → нижний бар. Свет + тьма.

4без «Советника»Мобильный хром

Нижний бар — Дашборд · [Бренды при 2+ / иначе Профили] · Настройки. Таба «Советник» нет (решение C): дашборд и есть его дом, а чат открывается со строки вопроса / кнопки героя. Верхний бар — марка + тема + кнопка аккаунта (→ лист с настройками и выходом).

5204Тонкое состояние

Советник вернул 204: честное приглашение + 3 вопроса-стартера + ask-строка. Без чипов и цифр.

62×2«Доказательства»

Тоталы схлопываются в сетку 2×2 (@container vbody ≤560); каналы идут столбиком (1 колонка ≤560). Значения tabular, nowrap — не переносятся.

7Карточки профиля + статусы

Полноширинные карточки. Состояния синка: голос настроен / «Настроить голос» (synced + has_voice=false) / importing (спиннер + %) / sync-error + «Повторить» / disconnected + «Переподключить».

8Бренды + раскрытие

В режиме 2+ карточка = бренд (агрегат + стек аватаров + строка состояния). Кнопка «Профили» раскрывает профили строками — статусы (sync-error, disconnected) видны внутри.

10правило 1Раскладка · 390 · 360 · 320

Доказательство. Тот же экран (2+ брендов, Field развёрнут) на трёх ширинах. Ни один однострочник не переносится: тоталы (2×2), чипы, @никнеймы, имена брендов, «Повторить» / «Переподключить», счётчики — держатся, при нехватке усекаются многоточием. Вердикт балансируется, но соседей не ломает.

11правило 2Немецкая длина

Стресс самой длинной локали (~1.3–1.5× к ru) на 390 и 320. «Synchronisierung fehlgeschlagen», «Erneut verbinden», «Weiteres Konto verbinden» — усекаются на своей строке, сетка держит.

12решение CСоветник: маршрут

Как на десктопе. Таба «Советник» в нижнем баре нет. Строка «Спросите совет по портфелю…» и кнопка «Открыть советника» в шапке героя — оба data-nav="advisor-chat": уводят в чат-экран, засеяв первый вопрос. Многоходовой чат не встраивается в дашборд.

Нижний барДашборд · [Бренды при 2+ / Профили] · Настройки. Без «Советника».
ask-строкаУводит в чат /app/account/advisor, засеяв вопрос.
«Открыть советника»Кнопка в шапке героя (на узком — иконка). Туда же.
ЧатОтдельный «глубокий» экран с возвратом «← к дашборду». Спека: Account-Advisor-Mobile-SPEC.html.

13Чек-лист

  • Правило 1: однострочники не переносятся на 390 / 360 / 320 (§10); не влезает → усечение, не разрыв. Вердикт — единственное балансируемое исключение.
  • Правило 2: немецкая длина держит правило 1 на 390 и 320 (§11).
  • Хром: верхний бар + нижний бар без таба «Советник» (§4); кнопка аккаунта → лист.
  • Порядок V3: Личность → Герой-вердикт → «Доказательства» (тоталы 2×2 + каналы столбиком).
  • Советник (C): ask-строка и «Открыть советника» уводят в чат, засевая вопрос; чат — отдельный экран.
  • Статусы importing / sync-error / disconnected — на карточке и внутри развёрнутого бренда; «Повторить» / «Переподключить» на месте.
  • Тонкое (204): приглашение + стартеры, без выдуманных цифр; тоталы «—» при отсутствии числа.
  • Светлая + тёмная на токенах; реальные логотипы сетей; аватар с монограммой. ?demo=1 Tweaks (§2).
