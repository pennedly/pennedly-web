Explore patterns — every state, rendered

Full-fidelity render of the Explore patterns screen (/app/patterns/explore) for the engineer to build pixel-for-pixel. The user pastes the text of posts they admire; Pennedly reads the words, names the reusable writing move, shows the exact line it was spotted in, and rewrites a fresh example in the user's own voice, then offers to fold the good rules into the role-book. Pennedly never opens links and never reads other accounts: the user brings the words, not a URL. Every frame below uses the real PennedlyDesign tokens, the shared app shell, and the real copy from explore-data.jsx. Reading width is 720px. Each state is shown for web + mobile in light + dark.
