Pennedly · Моб. спецификация · Сетевой «Connect»

Пикер сетей + первый вход network-aware · телефон

Телефонный парный документ к десктопному пикеру. Один общий компонент: Threads — живая, первичное «Подключить аккаунт Threads» (→ OAuth); LinkedIn — приглушённая заглушка «Скоро». Три точки входа: полноэкранный первый вход (новый пользователь), «Подключить другой» и «Переподключить» — на телефоне лист открывается нижним sheet под большой палец. Третья сеть встаёт ещё одной строкой без сюрпризов. Текст русский, 8 локалей (эталон — немецкий), проверено до 320px.

account-empty-mobile.css + picker + pickerSheet + phoneFirst
Марки сетей. Нейтральные буквенные марки ДС («@» / «in»), тонированные по сети (Threads = ink, LinkedIn = accent) — узнаются по марке + подписи, не воспроизводят товарные знаки; реальные ассеты подставляются в слот позже.

1Идентификация

Точки входаПолноэкранный первый вход (§2) · «Подключить другой» (нижний sheet, §4) · «Переподключить» (sheet, известный @handle).
ThreadsLive. Марка (ink) + «Threads» + «Живая сеть» + «Подключить». → OAuth Threads.
LinkedInСкоро. Приглушена, некликабельна, бейдж «Скоро».
РасширяемостьPICKER_NETS[] → третья сеть = ещё строка.

2состояние 1Полноэкранный первый вход

Новый пользователь (0 профилей когда-либо) — заметный приветственный полный экран: пикер-герой + «Подключите первый аккаунт» + подкопия + «что дальше». Не в дашборде.

3Пикер — анатомия

Строка сети: марка + имя + подпись + «Подключить» (live) / бейдж «Скоро» (soon). Live — кнопка; soon приглушена и некликабельна.

4Лист «Подключить другой» + «Переподключить»

Тот же пикер — нижний sheet. «Подключить другой» открывается с дашборда «все отключены». «Переподключить» — Threads-строка первична и помечена @handle, LinkedIn остаётся coming-soon; данные целы.

5N сетейРасширяемость

Список тянется вниз: третья сеть = ещё строка, без переливов. Ниже — пикер с гипотетической третьей сетью.

6правила 1–2Раскладка · 390 · 320 + de

Первый вход при 390 (реф), 320px и на немецкой длине. «Coming soon» → «Bald», «Threads-Konto verbinden» держат ширину; строки не переносятся.

7Чек-лист

  • Один пикер: полноэкранный первый вход · «Подключить другой» (sheet) · «Переподключить» (sheet).
  • Threads live первичен → OAuth; LinkedIn coming-soon приглушён + «Скоро».
  • Первый вход — полный экран (0 профилей когда-либо); остальное — в дашборде.
  • Третья сеть = ещё строка; Rule 1 + немецкая длина на 390/320.
  • Нейтральные марки; светлая + тёмная.
