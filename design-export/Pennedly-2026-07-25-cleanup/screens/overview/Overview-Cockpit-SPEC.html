Pennedly · Спецификация · Мульти-сетевой кокпит

Главная /app/overview · кокпит

Pennedly становится мульти-сетевым портфельным продуктом — Аккаунт (логин) → Бренды (единица голоса) → Профили (один соц-аккаунт в одной сети). Старый read-only Overview вырастает в настоящую Главную-кокпит, которая при открытии сразу отвечает «что от меня сейчас требуется?». Три добавления + один мобильный контрол: очередь «Требует тебя» (герой — черновики, ответы, сбои синка и аудиты по всему портфелю, каждая строка ведёт в нужный экран/профиль), компактная строка growth-аудита (сигнал недели по профилю, read-only, в «Аудит роста») и Главная как стартовый экран (пункт сайдбара, первый/активный; ≥2 профилей → сюда, 1 → Студия). Полоса итогов портфеля и сетка карточек профилей остаются под очередью. Всё — живой слой ДС (светлая + тёмная) на ширине --content-wide 960; текст русский, раскладка держит все 8 локалей (эталон длины — немецкий) по правилам 1–2.

+ TriageQueue + GrowthAuditRow + NetworkBadge overview-app.jsx overview.css import-banner.css ds/tokens.css
Критерий приёмки — раскладка (правила 1–2).
  • Правило 1. Однострочные элементы — значения метрик и итогов, счётчики в очереди, бейджи, чипы @никнейм, метки кнопок, вердикт аудита, короткие подписи — никогда не переносятся на вторую строку и не толкают соседа вниз. Не влезает → осознанное усечение многоточием (число/начало строки остаётся), не разрыв строки. Доказано в §9 на узком окне десктопа, обычном и совсем узком (320px) мобильном.
  • Правило 2. Текст русский, но контейнеры рассчитаны на самую длинную локаль (немецкий, ~1.3–1.5× к ru). Немецкая длина показана и держит правило 1 (§9, переключатель локали в Tweaks §11).
Достраивает Overview, не начинает с нуля. Полоса итогов, карточка профиля AccountCard, состояния importing/sync-error/empty/skeleton/error и пин «Все аккаунты» — перенесены 1:1 из Overview-SPEC.html. Новое: очередь «Требует тебя», строка growth-аудита, пункт Главная + правило старта, и небольшой значок сети на аватаре каждого профиля (продукт теперь мульти-сетевой).

1Идентификация экрана

Маршрут, назначение, ширина и порядок сверху вниз: sidebar | main(topbar + scroll(очередь → итоги → строка аудита → сетка профилей)). Read-only, кроме Retry на сбое синка.

Маршрут/app/overview. Вход — пункт Главная (первый) и пин «Все аккаунты» в переключателе. Контекст — «Все аккаунты», не один профиль.
ТипПолный app-shell с контекстом «Все аккаунты»: пункт Главная в навигации active; account-control читает «Все аккаунты». Каркас 1:1 из Студии.
НазначениеОтветить «что от меня сейчас требуется?» по всему портфелю, затем дать цифры одним взглядом и вход в любой профиль в один клик.
Ширинаwide = --content-wide 960. Топбар по той же ширине.
Секции (сверху вниз).ov-tri (очередь — герой) → .ov-totals (итоги) → .ov-ausec (строка аудита) → .ov-grid (карточки). Пустая очередь → .ov-tri--zero.
Фазыloading (скелет) · ready · empty (нет профилей) · error (сбой загрузки списка + Retry). По профилю: synced / importing / error.

2new«Главная» + сайдбар

Overview становится Главной: пункт сайдбара, первый и активный. При открытии приложение ведёт сюда, когда профилей два и больше; ровно с одним профилем кокпит не нужен — главной остаётся Студия. Пин «Все аккаунты» в переключателе тоже ведёт сюда.

Правило / элементПоведение
Маршрут старта/app → /app/overview при профилей ≥ 2; → /app/studio при профилей == 1. (Нет профилей → первый запуск, подключение.)
.sb-row--active (Главная)Первый пункт навигации, иконка IcOverview, метка «Главная», active на этом экране. Выше Студии / Ленты / Статистики / Аудитов.
Account-controlВнизу сайдбара; здесь читает «Все аккаунты · N профилей», открывает меню вверх (email + тариф в шапке, сменить профиль, Все аккаунты, подключить, Настройки, выйти).

3Анатомия + живой кокпит

Весь кокпит в контексте — светлая и тёмная, на ширине экрана, пять профилей (один импортируется, у одного Threads-сбой синка). Очередь → итоги → строка аудита → карточки.

shell3.1 — Топбар

App-shell 1:1 из Студии. На Главной: заголовок «Главная», пилюля «N профилей · обновлено ежедневно».

4new · heroОчередь «Требует тебя»

Приоритизированный, легко-сканируемый список всего, что требует действия, над карточками. Четыре сигнала (всё уже считается): сбои синка, ответы, черновики, аудиты на разбор. Порядок: ответы и сбои синка — первыми, затем черновики, аудиты — последними. Каждая строка показывает свой профиль (аватар + значок сети + @никнейм) и ведёт в нужный экран этого профиля.

4.1 — Заполненная очередь + анатомия строки

Ответы .ov-tr--accentПрофиль · «N ответов к разбору» · «старшему N ч».Ответы · ?filter=needs-reply

Анатомия (правило 1). .ov-tr = аватар профиля (со значком сети) · тело (плитка-иконка типа + строка-заголовок, затем @никнейм + мета) · действие справа (.ov-tr-go шеврон или .ov-tr-btn Retry). Заголовок и мета — min-width:0 + усечение многоточием (число/начало остаётся); строка-аватар и действие фиксированы — соседи не съезжают.

4.2 — Спокойное «всё разобрано» (нулевое состояние)

Когда ничего не ждёт, очередь — спокойное, заслуженное состояние покоя: мягкая галочка, «Всё разобрано», тихая строка «проверено только что». Никогда не выглядит как пустота/ошибка; итоги, строка аудита и карточки остаются ниже.

5newСтрока growth-аудита

Компактная read-only секция с последним сигналом аудита по профилю: вердикт (сигнал вверх / ровно / вниз + Δ), уверенность (по числу постов) и «разобрать N предложений». Каждая карточка ведёт в полный «Аудит роста» этого профиля. Показываются только профили с недавним аудитом; без них секция мягко скрывается.

Элемент / классОткуда (данные аудита)
.ov-au-sig--{up|flat|down}Знак wowDelta (неделя к неделе). Вверх = success, вниз = danger, ровно = subtle. Δ — tabular («+12%»).
.ov-au-confУверенность по postsAnalyzed (≥16 Высокая · 11–15 Средняя · ≤10 Низкая) + «N постов».
.ov-au-cta / .ov-au-doneЧисло undecided-изменений → «Разобрать N предложений»; ноль → тихое «Всё разобрано».
ВырождениеПрофили без недавнего аудита (importing / новые) опускаются; если ни у кого нет аудита — секция скрыта.

6Итоги + карточки профилей перенесено

Без изменений из Overview. Полоса итогов суммирует синхронизированные профили (Подписчики +Δ · Просмотры · Посты · Ответы [accent]); карточка профиля несёт те же метрики, строку синка и quick-links, теперь со значком сети на аватаре и названием сети в подписи. Метка = одно слово, деталь — в подпись (правило 1).

7Статусы синка перенесено

Каждая карточка несёт состояние профиля: synced («● Обновлено N ч назад»), importing (Phase-0 баннер вместо метрик), error («● Сбой синка» + Retry). Сбой синка также поднимает строку очереди с высшим приоритетом.

8Все состояния

заполнено ●нулевой триажодин → Студияimporting + errorзагрузкапервый запускошибка

8.1 — Один профиль → Главная = Студия

С одним профилем кокпит — не стартовый экран, им остаётся Студия. При прямом заходе вырождается в заметку + одну карточку + nudge «подключить ещё» (без героя-очереди, без пустого портфеля).

8.2 — Загрузка / первый запуск / ошибка

Загрузка повторяет раскладку кокпита (скелет очереди + итоги + карточки). Первый запуск/пусто — CTA «Подключить аккаунт» из Overview. Ошибка — баннер сбоя загрузки списка + Retry (сбой синка одного профиля живёт в его карточке и строке очереди).

9правила 1–2Проверка раскладки

Доказательство критерия приёмки. Тот же кокпит в жёстких условиях: узкое окно браузера (контейнер сжат до 720 и 600px — на 640 итоги переходят в 2-в-ряд), и немецкая длина (самая длинная локаль). Ни один однострочный элемент не переносится и не сбивает выравнивание — длинные метки усекаются многоточием, число/начало остаётся, аватар и действие фиксированы. 320px проверен в мобильной спецификации (там ширина — телефонная).

9.1 — Узкое окно браузера (контейнер 720 · 600)

9.2 — Немецкая длина (стресс самой длинной локали)

«Synchronisierung fehlgeschlagen», «Erneut versuchen», «Wachstums-Audit» — самые длинные подписи. Усекаются, не ломая сетку. Это же состояние доступно в Tweaks (локаль = de).

Один запрос на весь портфель. GET /api/me/overview?tz_offset= → профили + предрассчитанные итоги. Счётчики триажа и сигналы аудита приходят по профилю.

12Web ↔ Mobile

Брейкпоинты: 880 (сайдбар → рейл) · 760 (итоги/сетка/строка аудита → 1-в-ряд) · 600 (телефон). Полный телефонный проход: Overview-Cockpit-Mobile-SPEC.html.

Десктоп ( > 880 )

  • Фикс. сайдбар, Главная активна/первая; колонка 960.
  • Строки очереди на всю ширину; итоги 4-в-ряд; строка аудита 3-в-ряд; карточки 2-в-ряд.
  • Account-control = меню-вверх в подвале сайдбара.

Телефон ( ≤ 600 )

  • Без сайдбара; гамбургер-drawer; кнопка аккаунта внизу → нижний лист (единственный контрол аккаунта).
  • Строки очереди в столбик; итоги 2×2; строка аудита скроллится; карточки в столбик.
  • Retry остаётся в своей строке очереди и карточке; свободный нижний край.

13Локализация · i18n

Весь текст ключевой (triage.*, audit.*, account.*) в 8 локалях: en · ru · uk · de · es · fr · it · pt. ru — ревью, de — эталон длины. Контейнеры рассчитаны на самую длинную локаль (правило 2); числа tabular, формат локали; «N ч назад» — относительный форматтер в TZ зрителя; @никнейм всегда LTR.

Ключenru (ревью)de (длиннее)
Плюрализация + интерполяция. «N ответов / черновиков / предложений» и «+N импортируется» идут через ICU-плюрали локали; «{сеть}: сбой синка» интерполирует название сети. Длинные подписи усекаются на своей строке многоточием — выравнивание соседей не сбивается (правило 1).

14Чек-лист

  • Правило 1: ни один однострочный элемент (метрики, итоги, счётчики, бейджи, @никнейм, метки кнопок, вердикт) не переносится и не толкает соседа вниз — на узком десктопе, мобильном и 320px. Не влезает → усечение, не разрыв строки.
  • Правило 2: текст русский; контейнеры держат немецкую длину (§9, локаль de в Tweaks) без нарушения правила 1.
  • Главная первая + активная; /app → кокпит при профилей ≥ 2, → Студия при == 1.
  • Очередь — герой (над итогами): сбои синка и ответы, затем черновики, затем аудиты; каждая строка показывает профиль (аватар + сеть + @никнейм) и ведёт в нужный экран; сбой синка → Retry на месте.
  • Нулевой триаж = спокойное «всё разобрано» (заслуженное), не пустота/ошибка; итоги + строка аудита + карточки остаются.
  • Строка аудита: сигнал вверх/ровно/вниз + Δ + уверенность + «разобрать N предложений»; только профили с недавним аудитом; скрыта без них.
  • Значок сети на аватаре каждого профиля (Threads / Bluesky / Mastodon…).
  • Итоги + карточки 1:1; итоги суммируют только synced; «+N импортируется».
  • Синк по карточке: synced / importing (Phase-0 баннер) / error (Retry).
  • Загрузка повторяет раскладку; первый запуск/пусто = CTA подключения; ошибка = баннер загрузки списка + Retry.
  • Корректно в светлой + тёмной; токены, не хардкод. Tweaks (?demo=1): dark · state · locale.
