Упоминания /app/mentions — телефон

Телефонный слой редизайна Упоминаний. Тот же смысл, что на десктопе: командный центр по входящим, три зоны («Требуют вас», лента, свёрнутое «Отфильтровано»), интент-чипы, медиа и черновики. Меняется только раскладка ниже 600px: общий app-shell (гамбургер + левый drawer, freshness-пилюля, без таб-бара, свободный нижний край), карточка сворачивается в одну колонку, футер уходит в два яруса с крупными (44px) целями. Обе темы, только токены ds/tokens.css, один акцент. Тексты РУ, без длинных тире.

mentions-queue.css · .mq-mob mentions-queue-build.js ds/tokens.css ds/components.css
Что не меняется. Классификация по интенту, три зоны, медиа-превью, честное «видео я не вижу», перевод, статусы и состояния — идентичны десктопу. Threads даёт только @автора (без имени/аватара) — карточка их не выдумывает. Мобайл это раскладочный проход: единственное структурное изменение — общий app-shell (таб-бар → drawer).

1Идентификация экрана

Маршрут/app/mentions — tester-gated (строка drawer скрыта у не-тестеров).
Ширина (телефон)100% − 14px поля; одна колонка карточек.
Сверху внизСтатус-бар → топбар (гамбургер · «Упоминания» · freshness-пилюля · тема) → интро → зона «Требуют вас» → лента → «Отфильтровано» → свободный нижний край.
Только read + generateНикаких действий вне бэкенда; жаловаться нельзя. Единственный внешний переход — «Открыть в Threads».

2Экран целиком (три зоны)

Весь экран в контексте, светлая и тёмная: интро, «Требуют вас», лента и свёрнутое «Отфильтровано (N)». Зоны отделены заголовками; карточки идут в одну колонку до свободного нижнего края.

3shellShell: топбар + drawer

Shell общий. Мобильные значения для Упоминаний:

СлотЗначение
ГамбургерСлева, открывает .m-drawer (активная строка = Упоминания, tester-gated).
Заголовок«Упоминания»; обрезается перед пилюлей на длинных локалях.
Freshness-пилюляClock «Раз в час» — отражает ежечасный сбор. Уходит под заголовок только на очень длинной локали.
Действие топбараТолько тема; аккаунт — в подвале drawer.
StickyНет — фильтров/свитчера нет, список скроллится прямо под топбаром.

4fixКарточка на телефоне

Шапка — аватар-монограмма + @автор + время, чип интента и статус переносятся на свою строку. Текст с @-хэндлами. Футер уходит в два яруса: мета сверху, действия — крупные (44px) кнопки снизу, главное действие тянется на всю ширину.

Правила. Текст переносится с text-wrap:pretty; @-хэндлы — .at-mention (акцент, 500). Длинное упоминание просто растит карточку — без клампа. Чип интента и статус-бейдж не клипаются, переносятся. Медиа занимает всю ширину колонки.

5Медиа-превью

Фото и видео растягиваются на ширину колонки; постер видео несёт бейдж «Видео»; подозрительное медиа — размытое, с «Показать». В черновике к видео — «видео я не вижу».

6Карточка по статусам

Новое (AUTO), черновик (с текстом), отвечено, пропущено — те же действия, что на десктопе, в двухъярусном футере.

7«Отфильтровано» + опасное

«Отфильтровано» свёрнуто по умолчанию; разворот — компактный список с причинами. Опасная карточка (скам/фишинг) несёт предупреждение и размытое медиа.

8Лимит + рутины

Отдельный дневной лимит ответов на упоминания (в «Правилах дома») и вход в рутины упоминаний — те же контролы, на ширину телефона.

11Чек-лист

  • Ниже 600px нет сайдбара и таб-бара — один топбар с гамбургером слева и freshness-пилюлей «Раз в час».
  • Три зоны в одну колонку: «Требуют вас» → лента → свёрнутое «Отфильтровано (N)»; свободный нижний край.
  • Карточка: аватар-монограмма + @автор + время; чип интента + статус переносятся под шапку.
  • Один акцент, не светофор; warning только у скам/фишинг/инъекция.
  • Медиа на всю ширину; видео с бейджем; скрытое размытое с «Показать»; «видео я не вижу» в черновике.
  • Футер в два яруса; действия ≥44px; главное действие — grow.
  • «Отфильтровано» разворачивается со списком, причинами и «это развод» у скам/фишинг.
  • Отдельный дневной лимит ответов на упоминания; вход в рутины (только место).
  • Состояния: пусто, reconnect (сохранён), ошибка.
  • Обе темы на токенах; тексты РУ без длинных тире; проверено на 360px.
