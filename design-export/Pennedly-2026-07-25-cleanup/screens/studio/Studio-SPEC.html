Studio /app — пиксель-в-пиксель

Дотошная спецификация самого большого экрана приложения — Studio — и общего app-shell, который Studio задаёт ПЕРВЫМ и который потом переиспользуют все остальные экраны (<window.Sidebar> + топбар + переключатель аккаунтов). Брифуешь тему → Pennedly пишет N черновиков в твоём голосе → ты ревьюишь, твикаешь, апрувишь и публикуешь в Threads. Ниже задокументированы АБСОЛЮТНО все состояния по очереди: shell (аккаунт-меню откр/закр), composer «Строка» (collapsed/open/seeded/ideas: loading·results·empty·error/busy), табы, лента (normal/loading/empty/error/generating), карточка во всех статусах и под-режимах (draft/ready/published/rejected + editing/tweaking/revising/translated/reply), ⋯-меню (root/translate), диалог публикации, тосты с Undo, first-run hero, density, тема и адаптив web↔mobile. Все значения взяты из реального дизайна, без «примерно».

App-shell — общий, задаётся здесь. Studio первым собирает каркас: .app = display:flex; height:100% с двумя колонками — <window.Sidebar active="studio"/> слева (фикс. 248px) и .main справа (топбар + скролл-область). Sidebar, AccountMenu, Avatar и ErrorBanner живут в shell-parts.jsx / shell.css / shell-data.jsx и рендерятся ОДИНАКОВО на всех экранах. Поэтому §2 и §4 документируют shell так же дотошно, как и сам Studio.
Состояния одним взглядом. Экран управляется шестью твиками (studio-app.jsx → TWEAK_DEFAULTS): account (Active / First-run), state (Normal / Loading / Empty / Error), drafts (1–4, для generate), ideas (Results / Empty / Error — исход палитры идей), dark, density (Comfortable / Compact). account="First-run" заменяет весь composer+feed на приветственный hero и переводит voice-пилюлю в warning. Сгенерированные черновики падают сразу в ленту (таб «Черновики») — НИКАКОЙ отдельной preview-карточки «last generated». Публикация — только через confirm-диалог.

1Идентификация экрана

Маршрут, назначение, ширина wide-колонки, условие first-run, раскладка сверху вниз: sidebar | main(topbar + scroll(content)).

Маршрут/app (Studio.html) — главный рабочий экран после онбординга. Dev-вход из Login ведёт прямо сюда.
ТипПолный app-shell: рендерится <window.Sidebar active="studio"/>. Это первый экран, который СОБИРАЕТ shell; все остальные экраны переиспользуют его 1:1.
НазначениеБриф (тема / хот-тейк / ссылка) → Pennedly пишет N черновиков постов и ответов в голосе пользователя → ревью, твик, апрув, публикация в Threads. Лимит текста 500 символов.
Корневой контейнер.app → display:flex; height:100%; overflow:hidden; background:var(--color-bg). Атрибут data-density="comfortable|compact".
Ширина контентаwide = --content-wide 960px. Колонка .content--wide центрируется; топбар выровнен по той же ширине через .topbar-inner.topbar--wide (§3.1/3.2 системного слоя).
ТопбарЗаголовок «Studio» + voice-пилюля .status-pill (success «Voice active» / warning «Voice not set up») + действия (тема, Settings).
Условие first-runt.account === "First-run" (= голос не настроен). Тогда вместо composer+ленты показывается hero <FirstRun>, а voice-пилюля = warning. account="Active" → обычный режим, пилюля success.
Секции (top→bottom)First-run hero ИЛИ [Composer → FilterTabs → Feed]. Внутри Feed по твику state: normal / loading (3 скелетона) / empty (per-tab) / error (ErrorBanner). Generate добавляет N скелетонов сверху в табе Drafts.
ЛокализацияВесь end-user текст локализуется. 8 UI-локалей (UI_LANGS, shell-data): EN (original) · ES · DE · FR · IT · PT · RU · UK. Перевод тела карточки — инлайн, через ⋯ → Translate.

Раскладка сверху вниз

  1. .app — горизонтальный flex во всю высоту. Два прямых ребёнка: <Sidebar> и .main.
  2. .sidebar (shell) — flex:0 0 248px, колонка: бренд → nav-группы → .sidebar-foot (AccountMenu, прижат вниз через margin-top:auto).
  3. .main — flex:1 1 auto; min-width:0; flex-direction:column. Внутри: <Topbar> (sticky, 60px) и .scroll (flex:1; overflow-y:auto).
  4. .scroll > .content.content--wide — max-width:960; margin:0 auto; padding:28px 24px 96px; flex-column; gap:20px. Здесь живут Composer / FilterTabs / Feed (или FirstRun).
  5. Оверлеи поверх .app — <PublishDialog> (по требованию), <Toasts> (фикс. снизу-центр), <TweaksPanel>.

7Чек-лист

«Убедись, что X = ровно Y». Пройди по каждому состоянию и по сквозным проверкам.

Shell

  • Sidebar = flex 0 0 248px; на ≤880px схлопывается в 72px icon-rail (лейблы/беджи/who+chev скрыты).
  • AccountMenu открывается ВВЕРХ (bottom:calc(100%+8px)); при открытии есть .acct-scrim; chev = rotate 180°.
  • В меню: активный аккаунт с IcCheck (success); «Connect another account»; разделитель; mara@pennedly.com · «Creator plan»; «Settings»; «Log out» (danger).
  • Топбар-заголовок и левый край контента выровнены по wide-ширине 960.
  • Voice-пилюля = success «Voice active» (Active) / warning «Voice not set up» (First-run).
  • Подпись под логотипом — «Пиши в своём голосе» (старый слоган «Партнёр по черновикам» ретирован).
  • Меню — три группы (Рабочая область / Аналитика / Бренд) + отдельный вход в зону аккаунта вне групп; «Черновики» ведёт на /app; бейдж только у черновиков/ответов/аудитов.
  • Экраны зоны аккаунта показывают свою строку крошек под топбаром — Студия её не показывает.

Composer / табы

  • «Строка»: свёрнутый бар (аватар · инпут · ⌘↵ · ✨) раскрывает полку по фокусу; ✨ → палитра идей (не отдельный экран).
  • Полка: чипы — скролл-ряд с фейдом; ряд tools = DRAFTS · сегмент 1·2·3·4 · Generate; b.on = primary.
  • Палитра идей: loading (3 скелетона) → results (Use по hover/тач) + empty (без фейк-карточек) и error (тон danger, не схлопывается), у обоих «Try again».
  • Мобайл ≤560: полка не переполняется (DRAFTS·1·2·3·4 ряд 1, Generate во всю ширину, seeded свой ряд); ⌘↵ скрыт на тач; ✨/сегмент/idea-карточки ≥44px; инпут ≥16px.
  • Generate disabled при пустом брифе; активна при непробельном тексте.
  • Busy = каноничный nib-write 1.5s + «Drafting {N} posts…» + 3 dot-pulse; НИКАКОЙ preview-карточки.
  • Generate переключает на таб Drafts и кладёт N скелетонов сверху; через 1600ms — N карточек в начале ленты.
  • Лимит = ровно 500; CharMeter warn при >440, over при >500.
  • Табы по порядку: Черновики · Готово к публикации (default) · Запланированные (новое) · Опубликовано · Отклонено, каждый со счётчиком; активный = bg surface + shadow-sm.

Лента / карточка

  • Loading = ровно 3 скелетона; Empty = per-tab title/sub (+ CTA у draft); Error = ErrorBanner + Retry.
  • Черновик — исключение: Одобрить + Редактировать + Удалить черновик видимы сразу; у ready/scheduled/published/rejected по-прежнему одна primary (или ни одной) + всё вторичное в ⋯.
  • draft → Одобрить/Редактировать/Удалить; ready → Publish to Threads; scheduled → нет primary (Отменить в ⋯); published → Open in Threads ↗; rejected → нет primary; editing → Cancel+Save.
  • У черновика — кнопки «Добавить картинку» / «Добавить видео»; у прикреплённой картинки — ALT-подпись (добавить/изменить/удалить).
  • Черновик ответа (kind=reply) — read-only: футер = «Черновик ответа · управление в Ответах» + «Открыть Ответы», без Edit/Approve/Delete.
  • Запланированный пост несёт бейдж «Запланировано» у статуса.
  • Reply-карточка показывает .reply-ctx с автором и текстом исходника + «replying to {who}».
  • Translate инлайн: тело меняется, появляется .translate-bar «Translated to {native} · Show original».
  • Save disabled при пустом тексте или >500; «Revised just now» появляется после твика.
  • Status-переход = leave-анимация 250ms, затем коммит; rejected карточка opacity 0.72; published bg surface-2.

⋯-меню / диалог / тосты

  • Тосты Approve/Reject содержат Undo; авто-скрытие 4800ms; стек снизу-центр.

Сквозные

  • Все цвета = токены (нет хардкод-hex в studio.css/shell.css); тёмная тема флипает бесплатно через .dark.
  • Density Comfortable/Compact меняет padding/размер тела/gap карточек.
  • Адаптив корректен на каждой точке: 880 (rail), 720 (voice-tag), 560 (контент/табы/footer/topbar).
  • Анимации каноничные (nib-write / dot-pulse / shimmer / card-in / dialog-in / toast-in); resting opacity = 1.
  • FirstRun (account=First-run) заменяет composer+feed на hero; voice-пилюля = warning.
