«Отвечать на комментарии» — три направления настройки на выбор

Один экран, три отчётливо разных подхода — основателю выбрать. Все три настраивают одну встроенную рутину: вкл/выкл + кому отвечать + коротко как отвечать. «Кому» — 4 опции с максимальной гибкостью: «Только фанатам» · «Все, кроме троллей» · «Только вопросы» · «Свой вариант» (поле, где креатор своими словами описывает аудиторию, а Pennedly решает по каждому комменту — отвечать или пропустить). Частота, тихие часы и потолок — глобальные, из «Правил дома» (показываем чипом из Правил дома, не дублируем). Различаются подходом к компоновке и логике, не косметикой.

0Что общего у всех трёх

Меняется подача, не бэкенд. Во всех вариантах действует одна реальность:

ПравилоКак отражено
Тумблер = режим ответовВкл → «на все», выкл → «выкл». «На выбранные посты» — в Ленте, не здесь.
Кому — 4 опциифанатам / все кроме троллей / вопросы / свой вариант (текст). «Свой вариант» = reply_audience=custom + audience_prompt.
Свип отвечает самБез подтверждения, опрос раз в ~15 минут (не мгновенно). Не «Спроси меня»-черновик.
Частота / тихо / потолокГлобальные, из «Правил дома». Чип из Правил дома, не редактируются здесь.
Встроенную нельзя удалитьБейдж встроенная, нет «Удалить».
Кастомный reply-сценарийПеребивает дефолтный свип → встроенная карточка уходит «на паузу» с пометкой «заменена сценарием …».

AВсё на карточке · инлайн, 0 кликов вглубь

Идея: карточка в списке рутин и есть настройка. Тумблер, сегмент «кому» с раскрытием «Свой вариант», поле «как отвечать» — всё прямо на .sc-card, ничего не открывается. Для соло-креатора — один экран, ноль навигации.

A · включена · «Свой вариант» раскрыт — Light / Dark

A · выключена · сосуществование с reply-сценарием

Плюс: мгновенно, всё видно. Минус: карточка тяжелеет — на узком телефоне это длинная стопка; «как отвечать» конкурирует за внимание с другими рутинами в списке.

BКарточка → редактор · ведёт по шагам

Идея: в списке — лёгкая карточка-сводка (тумблер + строка «кому» + «Настроить»). Редактирование — в reply-варианте гибрид-редактора: слева шаги (Когда read-only «раз в ~15 мин» · Кому отвечать · Как отвечать), справа — крупное живое превью ветки авто-ответа. Список остаётся чистым.

B · редактор · шаг «Кому» · «Свой вариант» раскрыт — Light / Dark

B · карточка-сводка в списке · включена / выключена

Плюс: список чистый, редактор просторный, превью убеждает. Минус: «кому» — один клик вглубь; для «поменять на быстро» это лишний экран.

CЖивой триаж · видно последствия

Идея: «кому отвечать» — это всегда живой фильтр, а не радио-кнопка. Слева — поле-описание (4 пресета его заполняют, «Свой вариант» — это и есть редактирование текста). Справа — лента последних настоящих комментов с вердиктом ответим / пропустим. Меняешь описание — вердикты пересчитываются. Делает «Свой вариант» героем и сразу показывает, кого свип тронет.

C · панель · «Свой вариант» (своими словами) — Light / Dark

C · карточка в списке (вкл/выкл) · сосуществование

Плюс: снимает страх «а кому он напишет?» — видно до включения. Идеален для «Свой вариант». Минус: самый «тяжёлый» по площади; триаж-лента требует выборки последних комментов.

Десктоп

  • A — карточка в строку, сегмент и поля во всю ширину карточки.
  • B — список 1 колонка; редактор 2 колонки (шаги + липкое превью).
  • C — панель 2 колонки (описание | триаж-лента).

Телефон ( ≤ 600 ) — стопкой

  • A — карточка стопкой: шапка → сегмент (4 опции в ряд, ≥44px) → своё поле → «как».
  • B — карточка-сводка full-width; редактор → 1 колонка (превью под шагами).
  • C — описание сверху, триаж-лента под ним (одна колонка); вердикты — справа в строке коммента.
Все вердикты/сегменты держат ≥44px тапа; длинные RU/DE-лейблы оборачиваются. Тёмная — те же семантические токены (показана для главных фреймов каждого направления).
