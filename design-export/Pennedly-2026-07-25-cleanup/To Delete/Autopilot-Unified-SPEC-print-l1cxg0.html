Pennedly · Спецификация · Объединение режимов

Автопилот — объединённый хаб (Автопилот + Сценарии в одном)

Два режима — «Автопилот» и «Сценарии» — сливаются в один, под названием «Автопилот». Раньше они пересекались и путали: постинг по расписанию делали два механизма параллельно, глобальный гейт постинга по факту был мёртв, ответы настраивались в двух местах. Теперь это один понятный хаб автоматизации: сверху — «Правила дома» (глобальная шапка с единственным реальным рубильником), под ними — список рутин (это нынешние сценарии). Спеки Сценариев и Редактора — это и есть будущие поверхности рутин: мы их переиспользуем, а не переделываем. Ниже — только дельты к существующему дизайну. Живые фреймы — реальные DS-компоненты, светлая И тёмная.

A · шапкаПравила домаМастер-выключатель + глобальные правила (кап постов, частота/тихие часы/потолок ответов), действуют на ВСЕ рутины сразу.
B · списокРутины АвтопилотаКарточки контроль-центра как есть: живое предложение + статус. Каждая рутина = триггер + действие + режим.
C · постовыеВремя + разбросПостовые рутины теперь несут точное ВРЕМЯ и «разброс минут» (джиттер) в шаге «Когда» — влилось из старого Автопилота.
D · ответныеРутина «на все»Дефолтная рутина «Отвечать на комментарии» заменяет прежний глобальный «режим ответов». «На выбранные посты» остаётся в Ленте.
+ Правила дома + рутина «на все» + время/джиттер в «Когда» scenarios-redesign.css scenario-editor.css autopilot.css \u2212 отдельный экран Автопилота \u2212 двойной постинг \u2212 мёртвый гейт

1Зачем объединяем

Старая развилка «Автопилот vs Сценарии» создавала три пересечения, которые путали даже основателя. Объединение убивает каждое.

1
Двойной постинг по расписанию. Расписания жили и в Автопилоте (объекты-расписания), и в Сценариях (постовые сценарии) — два механизма постили параллельно. \u2192 Один список рутин. Постовая рутина — единственный носитель расписания; время и джиттер из Автопилота вливаются в её шаг «Когда».
2
Глобальный гейт постинга мёртв. «Автопостинг вкл/выкл» в Автопилоте по факту ни на что не влиял — сценарии постили в обход. \u2192 Мастер-выключатель «Правил дома» — единственный реальный рубильник. Выключен \u2192 ничего не постит и не отвечает, точка.
3
Ответы настраивались дважды. Политика авто-ответов жила и в Автопилоте, и в сценарии-дежурстве «Отвечать на комментарии». \u2192 Частота, тихие часы и потолок ответов \u2014 глобальные, в «Правилах дома». Дефолтная рутина «Отвечать на комментарии» держит только «кому отвечать».
Заголовок режима — «Автопилот». Элементы списка по-прежнему называются «сценарии» (рутины Автопилота). Старый отдельный экран «Автопилот» исчезает \u2014 его настройки переехали в «Правила дома». Мастер по умолчанию ВКЛ для существующих аккаунтов: нельзя молча остановить уже работающий постинг.

2Модель объединённого «Автопилота»

Один экран = (A) «Правила дома» сверху + (B) список рутин. Сверху вниз: topbar(«Автопилот» + master-pill) \u2192 Правила дома (свёрнуты) \u2192 список рутин.

ЧастьЧто это
(A) Правила домаГлобальная шапка. Крупный мастер-выключатель «Автопилот вкл/выкл» + раскрытие «Настройки»: «не больше N постов в день»; ответы \u2014 как часто (от «сразу» до «раз в день») + тихие часы + потолок ответов в день; ссылка на «Голос». Это правила, действующие на ВСЕ рутины разом.
(B) Список рутинКарточки контроль-центра (.sc-card) как есть: живое предложение + статус. Рутина = триггер (расписание ИЛИ реактив) + действие (пост / ответ / Акция) + режим «Спроси меня / Автоматически».
Постовые рутиныПо расписанию. Несут точное время + «разброс минут» (джиттер) в шаге «Когда» редактора \u2014 влилось из старого Автопилота.
Ответные рутиныДефолтная «Отвечать на комментарии» заменяет прежний глобальный «режим ответов». Своё \u2014 только «кому отвечать» (фанатам / все кроме троллей / вопросы). Частоту, тихие часы и потолок берёт из «Правил дома».
Реактивные + Акция«Раскрутить залетевший», «Спасибо за подписчиков» и «Акция» (gated) \u2014 как в текущем дизайне Сценариев.
Лента, не хабРежим «отвечать только на выбранные посты» остаётся в Ленте (кнопка «отвечать на этот пост» у конкретного поста). В Автопилоте \u2014 только дефолтная ответная рутина «на все».

3Дельта 1 · Экран «Автопилот» \u2014 дом Правила дома + рутины

«Правила дома» свёрнуты над списком рутин. Свёрнутое состояние = мастер-выключатель (крупный) + одна строка-сводка глобальных правил + «Настройки». Ниже \u2014 список рутин (переиспользуем карточки контроль-центра). Светлая и тёмная:

3.1 \u2014 Первый запуск (пусто)

Пустой список = первый запуск (как §4 Сценариев): «Правила дома» уже на месте (мастер ВКЛ), под ними \u2014 объяснение «что такое рутина» + готовые примеры-предложения, каждый создаётся выключенным. Учим на примере, потом включаем поштучно.

4Дельта 2 · «Правила дома» раскрытые сюда переехал Автопилот

Раскрытие «Настройки» показывает глобальные правила, которые действуют на все рутины: кап постов (степпер, дефолт 1) + блок ответов (как часто / тихие часы / потолок) + ссылка на «Голос». Это и есть бывший отдельный экран Автопилота, ужатый в шапку. Светлая и тёмная:

4.1 \u2014 Что внутри

Элемент / классОписание
.hr + .ap-masterКарта «Правил дома». Сверху \u2014 крупный мастер-выключатель (Switch--lg): вкл «постит и отвечает по твоим правилам» / выкл «ничего не публикуется и не отвечает». Единственный реальный рубильник.
.hr-toggle / .hr-summaryСтрока-сводка + «Настройки» (шеврон). Свёрнуто читается как «Не больше 1 поста в день · ответы раз в час · тихо 23:00\u201308:00».
.hr-group «Постинг»«Не больше N постов в день» \u2014 степпер .hr-stepper (1\u201310, дефолт 1), общий на все постовые рутины аккаунта.
.hr-group «Ответы»3 строки .policy-row: как часто (select: сразу ~15 мин / раз в час / несколько раз в день / раз в день) · тихие часы (switch + From/to, локально + UTC±N) · потолок в день (select 10/25/50).
.hr-voiceСсылка на «Голос»: «Все рутины пишут в твоём Голосе». Это не правило-тумблер, а навигация к настройке голоса.
.inheritЧип «из Правил дома» \u2014 показывается у ответной рутины напротив частоты/тихих часов/потолка, чтобы было видно, что значение глобальное.
Выключенный мастер \u2014 честно мёртвый. Когда мастер off, тело «Правил дома» и список рутин показываются приглушённо: правила можно настроить, но ничего не публикуется и не отвечает, пока не включишь. Это убивает «мёртвый гейт» из старого Автопилота.

5Дельта 3 · Шаг «Когда» для ПОСТОВОЙ рутины время + джиттер

Редактор рутины \u2014 это гибрид-редактор (шаги слева + крупное превью справа), он остаётся как есть. Дельта только в шаге «Когда» постовой рутины: к выбору расписания добавлены точное время (час) и «разброс минут» (джиттер) \u2014 раньше они жили только в Автопилоте. Светлая и тёмная:

5.1 \u2014 Время + «разброс минут»

ПолеОписание
Сегмент расписания .seg5 режимов: ежедневно / раз в N дней / еженедельно / период дат / по событию. В узкой колонке шагов \u2014 переносится, не обрезается.
Время (NEW)Select целых часов в локальной TZ; хинт «UTC±N · отправит HH:00 UTC». Канон \u2014 UTC post_hour, конверсия через браузерную TZ. Влилось из Автопилота (раньше время жило только там).
Разброс минут (NEW)Джиттер: «Точно (без разброса)» или «± N мин». Хинт «опубликует в пределах ±N мин». Случайный сдвиг вокруг времени поста, чтобы лента не выглядела роботом.
Превью справаКрупное липкое превью поста (.stage-frame) \u2014 как в Editor-SPEC. Меняется живо. «Прогнать сейчас» \u2014 только черновик.
Режим «Спроси / Авто» здесь не дублируется. Выбор режима \u2014 в момент включения (отдельное окно), по умолчанию «Спроси меня». В редакторе его нет. «Прогнать»/превью \u2014 только черновик, никогда не публикует.

6Что куда переехало

Старый отдельный экран «Автопилот» исчезает. Карта переезда каждой его части:

Было (старый Автопилот)Стало (объединённый Автопилот)
Мастер-выключатель «Автопилот»Мастер в «Правилах дома» \u2014 единственный реальный рубильник (раньше дублировал «Автопостинг»).
Глобальный «Автопостинг вкл/выкл» (мёртвый гейт)Удалён. Его роль выполняет мастер «Правил дома».
«Не больше N постов в день»«Правила дома» \u2192 группа «Постинг», степпер 1\u201310 (дефолт 1).
Объекты-расписания (Scheduled posts) с временем и джиттеромПостовые рутины. Время + джиттер переехали в шаг «Когда» редактора.
Политика авто-ответов (5 строк)Частота / тихие часы / потолок \u2192 «Правила дома», группа «Ответы». «Кому отвечать» \u2192 на рутину «Отвечать на комментарии».
Глобальный «режим ответов» (off / все / выбранные)«Все» \u2192 дефолтная рутина «Отвечать на комментарии». «Выбранные» \u2192 кнопка «отвечать на этот пост» в Ленте. «Off» \u2192 рутина выключена.
Activity (журнал)Остаётся как «Активность» рутины (см. §10 Сценариев) \u2014 человеческий журнал на рутину.

7Раскладка · Web ↔ Mobile

Ширина --content-wide 960. Мобайл \u2014 стопкой: «Правила дома» сворачиваются в одну карту, список рутин под ними. Редактор \u2192 1 колонка (превью под шагами).

Десктоп ( > 880 )

  • Фикс. сайдбар; колонка 960; master-pill в топбаре.
  • «Правила дома»: мастер в строку, раскрытие \u2014 группы «Постинг»/«Ответы» с контролами справа.
  • Список рутин: живое предложение + статус в строке.
  • Редактор: 2 колонки \u2014 шаги + липкое превью; шаг «Когда» с временем/джиттером.

Телефон ( \u2264 600 )

  • Нет сайдбара; гамбургер \u2192 drawer.
  • «Правила дома» сворачиваются (мастер + сводка); раскрытые группы \u2014 контрол full-width под лейблом; quiet From/to переносится.
  • Список рутин \u2014 под «Правилами дома», карточки full-width.
  • Редактор: шаги, затем превью крупным блоком; сегмент/время/джиттер full-width.
Степпер капа, селекты ответов и время/джиттер держат \u2265 44px / 16px на телефоне. Длинные RU/DE-лейблы оборачиваются. Полные телефонные проходы \u2014 в парных mobile-спеках.

8Жёсткие ограничения бэкенда

ОграничениеКак отражено в UI

Ответы \u2014 опрос раз в 15 минут«Сразу» в частоте = «по мере поступления (~15 мин)», не мгновенно.
«Прогнать» / превьюТолько черновик, tester-only \u2014 никогда не публикует.
Режим «Спроси / Авто»В момент включения, не в редакторе. По умолчанию «Спроси меня».
Мастер по умолчаниюВКЛ для существующих аккаунтов \u2014 нельзя молча остановить работающий постинг. Новые рутины \u2014 OFF по умолчанию.
Время / джиттерЧас в локальной TZ, канон UTC post_hour; джиттер «Точно» (0) или «± N мин».

9Чек-лист реализации

  • Один режим «Автопилот» = (A) Правила дома сверху + (B) список рутин; старый отдельный экран Автопилота удалён.
  • Правила дома: крупный мастер (единственный рубильник, выкл \u2192 ничего не постит/не отвечает) + сводка + «Настройки»: кап постов (степпер 1\u201310, дефолт 1) + ответы (как часто / тихие часы / потолок) + ссылка «Голос».
  • Мастер по умолчанию ВКЛ для существующих аккаунтов; новые рутины OFF.
  • Постовые рутины несут время + джиттер в шаге «Когда» (влилось из Автопилота); двойной постинг убран.
  • Дефолтная ответная рутина «Отвечать на комментарии» заменяет глобальный «режим ответов»; держит только «кому отвечать»; частоту/тихие/потолок берёт из Правил дома (чип «из Правил дома»).
  • «Отвечать только на выбранные посты» \u2014 в Ленте, не в хабе.
  • Реактивные («раскрутить залетевший» / «спасибо за подписчиков») и «Акция» (gated) \u2014 как в текущем дизайне.
  • Режим «Спроси / Авто» \u2014 в момент включения, не дублируется в редакторе; по умолчанию «Спроси меня»; «Прогнать» = только черновик.
  • Мобайл стопкой: Правила дома сворачиваются, список рутин под ними; редактор \u2192 1 колонка.
  • Светлая и тёмная; только семантические токены; Geist; 960px; копи через i18n (8 локалей).
