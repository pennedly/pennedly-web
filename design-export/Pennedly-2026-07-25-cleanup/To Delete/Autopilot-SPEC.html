Autopilot /app/autopilot — пиксель-в-пиксель

Полная спецификация обновлённого экрана Autopilot — opt-in автоматизации, которую автор собирает из нескольких ясных контролов. Выключено по умолчанию; тон — «вы остаётесь у руля», никогда не «Threads на автопилоте». С прошлой версии экран заметно вырос: добавлены scheduled posts (объекты-расписания), политика авто-реплаев расширена до пяти строк (с заголовочным контролом «отвечать, только когда это уместно»), а Activity переработана — теперь есть общий all-time-заголовок и пер-объектные карточки только по постам (авто-реплаи считаются на уровне аккаунта). Документ покрывает десктоп и телефон одним проходом: живые фреймы (реальные DS-компоненты, светлая И тёмная темы, на ширине экрана), пронумерованная анатомия, все состояния, маппинг Web↔Mobile, локализация в 8 языков и чек-лист. Иконография — спокойные часы / расписание; авто-реплаи — чат-бабл; молнии нет нигде.

autopilot-app.jsx autopilot-parts.jsx autopilot-data.jsx autopilot.css shell-parts.jsx ds/tokens.css ds/components.css + 5-row policy + reworked Activity
Специфицируется ОБНОВЛЁННЫЙ экран — он разошёлся со старым кодом. Живой экран (/app/autopilot?demo=1) ушёл вперёд от старого autopilot-app.jsx; autopilot-app.jsx — лишь стартовый референс. Реконсиляции к новому дизайну:
  • Иконография — часы/расписание. Старый код использовал IcBolt в master-карте, диалоге и тегах активности — заменено на часы; авто-реплаи помечаются чат-баблом. Молнии нет нигде (master, теги, confirm, sidebar nav).
  • Ширина — wide 960 (не reading 720): колонка .content.content--wide, топбар .topbar-inner.topbar--wide.
  • Политика авто-реплаев расширена до 5 строк в фикс. порядке (было 2). Добавлены: «only reply when it adds value» (headline, default on), «how often to reply», «quiet hours» (с From/to сабстрокой). Audience-опции переформулированы (fans/positive · except trolls · questions); cap = 10/25/50.
  • Activity переработана: all-time-заголовок «N posts · M auto-replies» (account-wide) + пер-объектные карточки только по постам (posts_total + «last …»). Пер-объектный счётчик реплаев (всегда читавший 0) удалён — реплаи живут на уровне аккаунта.
  • Delete объекта — inline-confirm «Delete this object?» (а не undo-тост).
Состояния одним взглядом. Два твика (?demo=1): dark и state. state = On (master on, полный) · Off (master off → reassurance, конфиг приглушён) · Edit (карточка в редактировании) · PolicyOff (reply-master off → тело политики dimmed 50%) · Replies (Activity на вкладке Replies) · Empty (нет объектов / нет активности) · Loading (skeleton, повторяющий раскладку). Включение master открывает confirm-диалог; выключение — мгновенно. OFF — дефолт для всех.

4Раскладка · Web ↔ Mobile

Брейкпоинты: 880px (shell → icon-rail) · 640px (autopilot.css — obj-grid 1 кол., act-counters 1 кол., policy-row → label-сверху-контрол-снизу) · 600px (телефонный слой pennedly-mobile.css). Полный телефонный проход — Autopilot-Mobile-SPEC.html.

Десктоп ( > 880 )

  • Фикс. сайдбар; колонка 960; master-pill в топбаре.
  • Объект: 3-up поля (time/spread/topic) в ряд; действия в head.
  • PolicyRow: label слева, контрол справа.
  • Activity: all-time-строка + 3-up пер-объектные карточки; список full-width.
  • Confirm — центрированный modal-диалог.

Телефон ( ≤ 600 )

  • Нет сайдбара/таб-бара; гамбургер → drawer; свободный нижний край.
  • Объект: поля в 1 колонку; действия стопкой; inputs 16px / ≥44px.
  • PolicyRow: контрол падает full-width под лейбл; quiet From/to переносится.
  • Activity: all-time-заголовок в 2 стат-строки; пер-объектные карточки стопкой; list-карточки full-width.
  • Confirm — bottom sheet (primary-кнопка сверху).

Local ↔ UTC · jitter

  • Все часы — UTC server-side, показываются/выбираются в локальной TZ зрителя. Hour-picker (whole-hour, HH:00) + hint «UTC±N · sends HH:00 UTC». Канон = post_hour (UTC); конверсия через браузерную TZ, ничего не персистится на конверсии.
  • Jitter: «Exact (no spread)» (0) или «± N min» — случайный разброс вокруг времени поста.
  • Quiet hours хранятся как UTC reply_quiet_start_hour/reply_quiet_end_hour (nullable); включение по умолчанию = 23:00–08:00 local; выключение → оба null.
  • OFF для всех по умолчанию. Worker honors account reply policy + enabled schedule objects.

7Чек-лист реализации

  • Полный app-shell; активный пункт = Autopilot (Voice & automation, tester-gated); топбар «Autopilot» + master-pill (success «Active» + живая точка / нейтральный «Off»); ширина --content-wide 960.

  • Master switch (большой); саб «On · posting and replying on your schedule» / «Off · you approve everything yourself»; OFF по умолчанию; off → reassurance-блок.
  • Включение открывает confirm «Turn on Autopilot?» (Cancel / Turn on autopilot); выключение мгновенно; тосты на флипе.
  • Scheduled posts: «Add»; объект = имя (#id фолбэк) · Topic (any round-robin / saved) · Post time (local hour + UTC±N + sends HH:00 UTC) · Random spread (Exact / ±N min) · enabled/Paused · seed «start with auto-reply on» · delete (inline-confirm «Delete this object?»); кол-во = posts/day; empty «No scheduled posts yet».

  • Footer: «follows your Voice and Style rules» + safety-строка.
  • Local↔UTC конверсия + offset-label; jitter Exact/±N; quiet UTC nullable.
  • Состояния On/Off/Edit/PolicyOff/Replies/Empty/Loading; loading-скелет повторяет раскладку.
  • Корректно в светлой и тёмной теме; только семантические токены; копи выживает в 8 локалях; проверено на 360px.
