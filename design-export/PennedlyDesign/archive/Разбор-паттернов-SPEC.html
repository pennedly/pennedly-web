Разбор паттернов — every state, rendered

Full-fidelity render of the redesigned Explore patterns screen (/app/patterns/explore), rebuilt around a one-post-at-a-time flow. The old single textarea (paste many posts at once, separated by blank lines) is gone. Now the user pastes one post they admire, hits Break it down, and gets a single result — the name of the move plus that post rewritten in their own voice. An Add another post control reopens the composer; each breakdown stacks into a running list. Pennedly never opens links and never reads other accounts — it only reads the words the user pastes. Every frame uses the real PennedlyDesign tokens, the shared app shell, and authored copy. Reading width is 720px. Each state is shown for web + mobile in light + dark; copy ships in 8 locales (EN/RU authored).
