Все профили отключены дашборд V3 · портфель жив

Крайнее состояние дашборда аккаунта V3 «Агент»: у аккаунта есть профили, но все они отключены (истёк токен сети, отозван доступ). Это анти-«меня разлогинило»: аккаунт, данные, голоса и история — на месте, экран не выбрасывает в мастер и не выглядит как выход из системы. Полный хром V3 сохранён: личность, герой-Агент (честное приглашение без выдуманного вердикта), «Доказательства» с тоталами «—» и каждым бывшим профилем карточкой с «Переподключить», плюс плитка «Подключить ещё аккаунт». Всё — реальный вывод кита (сценарий all_off), свет + тьма.

V3 · all_off портфель жив Переподключить Подключить ещё аккаунт honesty: «—»
Портфель жив — это не выход из системы. Аккаунт, бренды, голоса и вся история сохранены. Экран показывает полный хром и приглашает переподключить хотя бы один профиль. Никакого выброса в онбординг-мастер, никакого «пустого» вида.
Граница: 0 профилей за всю жизнь — это НЕ этот экран. «Совсем пустой аккаунт» (ни одного профиля никогда) сюда не попадает — гейт ведёт в онбординг. «Все отключены» отличается тем, что профили существуют (просто без активного коннекта) — поэтому мы показываем их карточками, а не мастер создания.

1Идентификация состояния

Тот же дашборд /app/account, фаза «все профили отключены». Определяется данными: scope.disconnected_count === profiles_count и profiles_count > 0. Порядок V3 не меняется: личность → герой → «Доказательства».

Когдаprofiles_count > 0 и все профили sync_status = "disconnected". Тоталы приходят null (нет живых источников).
ХромПолный. Сайдбар (Дашборд активен; «Бренды» при 2+; без «Агента»), топбар с переключателем, кнопка аккаунта. Ничего не прячется.
АгентНе вердикт (нечего анализировать) → честное приглашение «Все профили отключены» + кнопка «Переподключить» + ask-строка (уводит в чат). Без выдуманных цифр.
«Доказательства»Тоталы «—» (ответы могут быть 0). Каждый бывший профиль — карточка с «Отключён» + «Переподключить». Плитка «Подключить ещё аккаунт».
Не путать0 профилей за всю жизнь → онбординг, не этот экран.

3Полный экран

Весь экран: сайдбар (без «Агента»), личность «3 профиля · Threads», честный герой, тоталы «—», три карточки отключённых профилей + плитка «Подключить ещё аккаунт».

4без вердиктаЧестный герой Агента

Агент не выдумывает вывод. Заголовок «Все профили отключены», честное пояснение «аккаунт и данные на месте — это не выход из системы», первичное действие «Переподключить» и ask-строка (уводит в чат). Никаких чипов и цифр — привязывать нечего.

5честностьТоталы «—»

Правило честности: нет живого числа → «—», а не ноль-заглушка и не фейковая метрика. «Ответы» может быть реальным 0. Так пользователь видит: данные не потеряны, просто нет активного коннекта.

6Переподключить + подключить ещё аккаунт

Каждый бывший профиль — карточка (приглушённый аватар + @никнейм + сеть + «Отключён» + «Переподключить»). Профиль вне тоталов, но виден и восстановим в один клик. Плитка «Подключить ещё аккаунт» (та же addTile, лейбл connectMore) — добавить новый профиль, не трогая существующие.

7правила 1–2Раскладка

Тот же экран на узком контейнере (560) и в немецкой длине. «Переподключить» / «Erneut verbinden» и «Подключить ещё аккаунт» / «Weiteres Konto verbinden» не переносятся; @никнеймы держатся; карточки схлопываются в 1 колонку. 320px — в мобильной спецификации.

8границыЧто это НЕ

НЕ это
Выход из системы

Пользователь не разлогинен. Аккаунт, тариф, настройки — на месте; кнопка аккаунта работает.

НЕ это
Онбординг-мастер

Профили существуют — мы не гоним в «создай первый профиль». 0 профилей за всю жизнь → онбординг, отдельно.

ЭТО
Живой портфель на паузе

Полный хром + честный Агент + карточки с «Переподключить». Один клик — и данные снова текут.

9Чек-лист

  • Портфель жив: полный хром V3 (сайдбар без «Агента», топбар, кнопка аккаунта); никакого выброса в мастер и вида «разлогинило».
  • Честный Агент: «Все профили отключены» + «Переподключить» + ask-строка (в чат). Без выдуманного вердикта и цифр.
  • Тоталы «—»: нет живого числа → прочерк, не фейк; «Ответы» может быть реальным 0.
  • Каждый профиль — карточка с приглушённым аватаром, @никнеймом, «Отключён» и «Переподключить»; профиль вне тоталов, но восстановим.
  • «Подключить ещё аккаунт» — плитка в решётке (та же addTile).
  • Границы: 0 профилей за всю жизнь → онбординг, не этот экран.
  • Правила 1–2: «Переподключить» / «Подключить ещё аккаунт» и @никнеймы не переносятся (§7); немецкая длина держит; 320px — в моб. спецификации.
  • Светлая + тёмная на токенах; ?demo=1 Tweaks (§2).
