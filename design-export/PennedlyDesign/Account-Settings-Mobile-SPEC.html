Настройки аккаунта /app/account/settings · телефон

Телефонный парный документ к десктопным настройкам аккаунта. Те же карточки (они container-query адаптивны — сетка языка в один столбец, строки-действия переносятся), в телефонном хроме: топ-бар «Настройки» + гамбургер → drawer навигации аккаунта (пункт Настройки активен). Секция аккаунта: имя, email, язык, тариф/PRO; работа с данными — экспорт (GET /api/me/export) и удаление (DELETE /api/me) с теми же inline-состояниями. Один логин — без мульти-логина. Текст русский; раскладка держит немецкую длину и 320px.

account-screens-mobile.css + AccountCard + LanguageGrid + DataExport + DeleteAccount pennedly-mobile.css
Один продукт, другой форм-фактор. Те же токены и компоненты, что на десктопе — карточки .acc-card2 адаптируются под телефон без отдельной вёрстки. Хром — drawer аккаунта (Дашборд / [Бренды] / Агент / Настройки) + логин-переключатель в подвале. Профильные настройки живут на уровне профиля, не здесь.

1Идентификация

Маршрут/app/account/settings. Вход: drawer аккаунта (пункт «Настройки») или логин-меню. Не тестер-гейтед.
Сверху внизСтатус-бар → топ-бар (гамбургер · «Настройки» · тема) → карточка аккаунта → язык → данные/экспорт → опасная зона/удаление.
ДействияЭкспорт → GET /api/me/export (idle/preparing/ready); удаление → DELETE /api/me (idle/confirm/deleting).
Один логинСекция аккаунта = имя/email/язык/тариф + экспорт + удаление. Мульти-логина нет.

2Полный экран

Весь экран в контексте: топ-бар «Настройки», четыре карточки в столбик. Светлая и тёмная.

3Карточка аккаунта

Марка-квадрат (Аккаунт) + имя + email + бейдж PRO; редактируемое Имя и строки Email / Тариф.

4Язык интерфейса · 8 локалей

Сетка языка на телефоне — один столбец (container-query). Моно-код-бейджи (не флаги); активная (RU) с чернильной рамкой + галочкой.

5Экспорт · GET /api/me/export

Строка-действие переносит кнопку под текст на узком. Состояния: idle → preparing (спиннер) → ready (скачать .zip).

6Удаление · DELETE /api/me

Danger-карточка. idle → confirm (ввод слова «УДАЛИТЬ» + кнопки) → deleting (спиннер). Те же шаги, что на десктопе.

7Навигация · drawer аккаунта

Гамбургер открывает навигацию аккаунта: Настройки активны; Дашборд / [Бренды] / Агент рядом; логин-переключатель в подвале. Полная навигация Аккаунт↔Профиль — Navigation-SPEC.html.

8Раскладка · 390 · 360 · 320 · немецкий

390 реф360320немецкий

Один экран при 390 (реф), 360, 320px и на немецкой длине. Однострочные усекаются/переносятся по правилам, карточки держатся.

9Чек-лист

  • Топ-бар «Настройки» + гамбургер-drawer (Настройки активны) + логин-переключатель.
  • Секция аккаунта = имя/email/язык/тариф; один логин.
  • Язык — 8 локалей в один столбец, моно-код-бейджи; активная с рамкой + галочкой.
  • Экспорт → GET /api/me/export (idle/preparing/ready); удаление → DELETE /api/me (confirm/deleting).
  • Светлая + тёмная; 390/360/320px и немецкая длина без слома.
Конец мобильной спецификации. Десктоп — Account-Settings-SPEC.html. Навигация — Navigation-SPEC.html.
