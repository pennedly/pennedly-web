Stats /app/stats — пиксель-в-пиксель

Полная, дотошная спецификация обновлённого экрана Stats — агрегатной аналитики аккаунта за выбранный период. С прошлой версии экран сильно вырос: появились панели Top posts и Best times to post, а тренд-график перестроен в непрерывную ось с заполнением пропусков (gap-fill), пунктирной линией среднего и разреженными подписями. Документ покрывает и десктоп, и телефон как один проход. Ниже — живые фреймы (реальные DS-компоненты, светлая И тёмная темы, на ширине экрана), пронумерованная анатомия с таблицами значений, перечень всех состояний (Live / Loading / Empty), все шесть периодов, правила графика, маппинг Web↔Mobile, локализация в 8 языков и финальный чек-лист. Числа — сэмплы; формы — реальные.

stats-app.jsx stats-parts.jsx stats-data.jsx stats.css shell-parts.jsx studio.css ds/tokens.css ds/components.css + Follower growth + Top posts + Best times
Живые фреймы — это реальный системный слой. Документ подключает ds/tokens.css + ds/components.css + stats.css и рендерит компоненты как в продукте на ширине --content-wide 960. Каждый фрейм пинит свои токены: светлый — из :root, тёмный — через класс dark (как .device-screen.dark в mobile-фреймах), поэтому темы живут рядом, не затрагивая саму страницу-документ. App-shell (.sidebar/.topbar/.account) — общий из Studio, активный пункт = Stats в группе Insight; ниже он показан мини-демо топбара, полная анатомия каркаса — в Studio-SPEC.
Что изменилось в этой переработке.
  • Тренд-график перестроен. Теперь это непрерывная ось с gap-fill: в окне присутствует каждый бакет, пустые рисуются крошечным нулевым «пеньком» — тихий отрезок читается как тихий, а не как «два столбика». Пунктирная линия среднего считается только по непустым бакетам (нули исключены). Подписи разрежены (~8) и могут выходить за свою ячейку в пустых соседей, чтобы «Jun 3» не обрезалось в «Ju…».
  • Гранулярность — по периоду: hourly для Today/Yesterday · daily для 7 days/Month · weekly для 3 months/All time. Бакеты — в локальной TZ зрителя.
  • НОВОЕ: Top posts — топ-5 постов окна по просмотрам, у каждого вердикт «N× your average» с цветовой градацией (success ≥ 1.5× · plain ≥ 0.7× · muted ниже), вся строка ведёт в Threads.
  • НОВОЕ: Best times to post — два мини-графика (By hour и By day of week); лучший слот тинтован accent и назван в чипе «Best · …». Скрыт целиком для Today/Yesterday (окно слишком короткое).
  • Состояния — Live / Loading / Empty. Error-состояния нет по дизайну. Loading — скелет, повторяющий итоговую раскладку, чтобы ничего не «прыгало».
Состояния одним взглядом. Экран управляется тремя твиками (?demo=1): dark (false), period («7d»), state («Live»). Смена периода или state="Loading" уводит фазу в loading ~700ms → ready; state="Empty" рисует EmptyState и скрывает селектор периода. Колонка контента — --content-wide 960; топбар выровнен по той же ширине (.topbar-inner.topbar--wide). Форматирование чисел — sfmt() (K/M).

1Идентификация экрана

Маршрут, назначение, ширина, раскладка сверху вниз: sidebar | main(topbar + scroll(content: head(intro + period) + summary + trend + top-posts + best-times + spread)). Read-only — никаких мутаций контента.

Маршрут/app/stats. Пункт навигации Stats в группе Insight (без badge, не tester-gated). Демо-режим: /app/stats?demo=1 с панелью Tweaks.
ТипПолный app-shell: рендерится <window.Sidebar active="stats"/>. Каркас 1:1 переиспользован из Studio.
НазначениеКак аккаунт выступает в агрегате за период: headline-числа, что сработало (Top posts), когда постить (Best times) и насколько вирально (Performance spread). Только просмотр.
Ширина контентаwide = --content-wide 960px. Колонка .content.content--wide центрируется; топбар выровнен по той же ширине (.topbar-inner.topbar--wide).
ТопбарЗаголовок «Stats» + .status-pill «Updated daily» (чарт-глиф <IcChart 13>, всегда) + действия: тема + Settings.
Секции (top→bottom).stats-head (h1 + подзаголовок + .range-seg) → .stats-grid (4 SummaryCard) → trend «Average views per post» → Top posts → Best times to post → Performance spread. В empty селектор и панели скрыты.
Фазы (state)loading (скелет, повторяющий раскладку) · ready · empty («Not enough data yet»). Error-фазы нет.
Период6 фиксированных опций = backend-enum 1:1: Today · Yesterday · 7 days · Month · 3 months · All time. По умолчанию 7 days.
ЛокализацияEnd-user копи локализуется (8 языков: en/ru/uk/de/es/fr/it/pt): заголовок, лейблы периода/карточек, текст дельт, подписи графика, «× your average», «Best · …», названия тиров, empty-копи. Числа — сэмплы из insights, формат локали.
Backend-правдаОпции периода — РОВНО backend-enum (без кастом-диапазонов). Дельты — против предыдущего равного периода; у All time предшественника нет (prev=null → «no prior period»). Бакеты/гранулярность — от backend; время — в локальной TZ зрителя. Графики нарисованы вручную на CSS (без библиотек).

NEW2.6 — Follower growth .spanel / .fchart FollowerChart

Панель роста подписчиков. Шапка: слева caption «FOLLOWERS» (+ тихий саб «Since you connected»), справа — текущее число (крупное, tabular) + прирост за всё окно (+N success / −N danger). Ниже — линия (accent 2.2px, скруглённая) с лёгкой accent-заливкой и точкой на последнем значении. Важно: ось min–max, а НЕ от нуля — счётчики подписчиков большие, а суточный прирост мал; нулевая база схлопнула бы линию в плоскую. Блок независим от селектора периода — всегда показывает всю историю с момента подключения. Collecting (меньше 2 дней данных): пунктирная плитка с чарт-глифом + «Collecting your follower data» + саб про то, что Threads отдаёт только сегодняшнее число.

NEW2.8 — Best times to post .spanel / .besttimes BestTimes

3.3 — График: few vs many · gap-fill

few (≤ 8 бакетов)

  • Бары flex:1 — заполняют ширину панели.
  • Подписи = дни недели (7 days) — все видны.
  • Пунктирная средняя по всем непустым бакетам; выше = accent, на/ниже = muted.

many (> 8 бакетов)

  • Десктоп: бары всё ещё flex — просто плотнее (Month ≈ 30 дневных).
  • Телефон: фикс. ~40px бары + горизонтальный скролл; средняя едет с ними.
  • Пустые дни — нулевые пеньки (.colbar--zero); подписи разрежены до ~8 и выходят за ячейку.
Пустого графика как состояния нет. При нехватке данных весь экран уходит в EmptyState — отдельный «пустой график» не рисуется.

7Чек-лист реализации

  • Полный app-shell; активный пункт = Stats (Insight, без badge); топбар «Stats» + status-pill «Updated daily» (чарт-глиф) + тема + Settings.
  • Колонка контента — --content-wide 960; топбар выровнен через .topbar-inner.topbar--wide.
  • Период — сегмент из 6 фиксированных опций 1:1 с backend (Today / Yesterday / 7 days / Month / 3 months / All time); дефолт 7 days; скрыт в empty.
  • Сводка — 4 карточки (Posts / Views / Likes / Comments), каждое число text-h1, sub + дельта vs предыдущего периода; All time → «no prior period».
  • Тренд: непрерывная ось с gap-fill (каждый бакет; пустые — пеньки); пунктирная средняя по непустым; выше = accent, на/ниже = muted; подписи разрежены до ~8 и выходят за ячейку.
  • Гранулярность по периоду (hour / day / week); бакеты в локальной TZ; ≤8 заполняют ширину, >8 — fill на десктопе / фикс. 40px + скролл на телефоне.
  • Top posts: топ-5 по просмотрам, ранг + сниппет (2 строки) + мета (date · views/likes/comments) + вердикт «N× your average» (success ≥1.5× / plain ≥0.7× / muted ниже); строка ведёт в Threads.
  • Best times: By hour + By day of week (полная неделя, пустые дни — пеньки); лучший слот (≥2 поста) accent + чип «Best · …»; скрыт для Today/Yesterday; десктоп 2-col, телефон стопкой.
  • Performance spread: 4 тира (Viral/Good/Average/Weak) с цветами viral=success, good=accent, average/weak = ink-микс; count + % + бар.
  • Состояния Live / Loading / Empty; error-состояния нет; loading-скелет повторяет итоговую раскладку (без reflow).
  • Корректно в светлой и тёмной теме; ни одного hardcoded-цвета (только семантические токены).
  • Копи расширяется в 8 локалях без клиппинга; проверено на 360px; подписи графика — живой текст.
Конец спецификации. Источник: stats-app.jsx, stats-parts.jsx, stats-data.jsx, stats.css + общий shell. Парный телефонный документ — Stats-Mobile-SPEC.html.
