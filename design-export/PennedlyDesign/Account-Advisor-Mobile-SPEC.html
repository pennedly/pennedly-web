Агент по портфелю — чат /app/account/advisor · телефон

Телефонный парный документ к десктопному чату-агенту. По решению C дашборд стал домом агента — таба/пункта «Агент» в мобильной навигации больше нет. В этот чат попадают только с дашборда: со строки «Спросите совет по портфелю…», с вопроса-стартера или с кнопки «Открыть агента». Экран открывается «глубоким», с засеянным первым вопросом, и даёт возврат «← дашборд» стрелкой в топ-баре. Сам чат не переделан — тот же вокабуляр (.adv-*): закреплённый вердикт, реплики, чипы, «На основе:», карточки-подсказки, докнутый композер. Реф 390, проверено до 320.

+ шапка «← дашборд» + засев вопроса − таб «Агент» чат без редизайна
Тот же чат — только вход и возврат другие. Тело диалога (закреплённый вердикт, реплики, .adv-chip--*, «На основе:», карточки-подсказки, докнутый композер) — без изменений. Изменились две вещи: (1) убрана «Агент»-навигация — экран открывается «глубоким» с шапкой-возвратом и без нижнего таба; (2) он открывается засеянным первым вопросом с дашборда.
Никакого пустого first-run «из меню». Входа из меню нет — попасть сюда можно только с дашборда, значит первый вопрос всегда засеян. Экран открывается уже в диалоге (вопрос + генерация/ответ), а не с чистого листа.

1Идентификация

Маршрут/app/account/advisor. Вход только с дашборда: ask-строка · вопрос-стартер · «Открыть агента». Пункта/таба «Агент» нет (решение C). Tester-gated.
Сверху внизСтатус-бар → топ-бар («←» возврат на дашборд · «Агент аккаунта» · тема) → закреплённый вердикт → лента реплик → докнутый композер. Без гамбургера и нижних табов.
ВозвратСтрелка «←» в топ-баре ведёт на дашборд. Дашборд = взгляд, чат = разговор.
ОткрытиеС засеянным первым вопросом. Экран открывается уже в диалоге.
Состоянияready (засеяно → ответ) · thinking (генерация) · thin (тонкие данные) · error (inline + Retry).

2seedПолный экран

Весь телефон: топ-бар с возвратом «←», закреплённый вердикт, диалог, открытый засеянным вопросом (помечен «Засеяно с дашборда»), докнутый композер. Светлая и тёмная. Нижнего таба «Агент» нет.

3без табаШапка-возврат «← дашборд»

Единственное изменение хрома: топ-бар несёт стрелку возврата на дашборд и заголовок «Агент аккаунта». Ни гамбургера, ни нижнего таба «Агент» — это «глубокий» экран, а не пункт навигации. Вход — только с дашборда (см. §1).

4Открывается засеянным вопросом

Момент входа с дашборда: первый вопрос уже в ленте, агент генерирует ответ. Три входа — ask-строка, вопрос-стартер, кнопка «Открыть агента» — засевают вопрос.

5heroЗакреплённый вердикт

Компактная sticky-карточка: caption «Сводка портфеля» + scope, вердикт и чипы (скролл вбок). Тот же компонент и источник, что герой дашборда (в проде — один ответ /advisor).

6Реплика + ответ

Реплика пользователя (правый accent-пузырь ≤85%) → ответ ассистента: mark + проза + чипы + «На основе:» + карточка-подсказка «Открыть в Студии». Вокабуляр 1:1 с профильным чатом — не переделан.

7Состояния

засеяно → ответгенерациятонкие данныеerror

Вердикт закреплён во всех; первый вопрос всегда засеян. ready — засеянный вопрос + ответ; генерация — «Читаю статистику портфеля…»; тонкие данные — «пока мало данных» без чипов; error — inline + Retry. Пустого «first-run из меню» больше нет.

9Чек-лист

  • Вход только с дашборда: ask-строка · стартер · «Открыть агента». Таба/пункта «Агент» в мобильной навигации нет (решение C).
  • Шапка-возврат «←» на дашборд; без гамбургера и нижних табов — «глубокий» экран.
  • Открывается засеянным первым вопросом — экран уже в диалоге, без пустого «first-run из меню».
  • Чат не переделан: закреплённый вердикт (sticky) + реплики + .adv-chip--* + «На основе:» + карточки-подсказки «Открыть в Студии»; докнутый композер (safe-area).
  • Чипы привязаны к сигналам портфеля; тонкие данные — честно, без выдуманных чисел.
  • Состояния: засеяно→ответ · генерация · тонкие-данные · error; светлая + тёмная; 390 / 360 / 320 и немецкий.
