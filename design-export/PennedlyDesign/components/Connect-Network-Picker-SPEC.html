Pennedly · Спецификация · Сетевой «Connect»

Пикер сетей + первый вход network-aware connect

Pennedly — мульти-сетевой портфель: канал = аккаунт × сеть (network уже поле модели). Везде, где начинается подключение, вместо одной кнопки Threads показывается маленький пикер сетей: Threads — живая, первичное действие «Подключить аккаунт Threads» (→ существующий OAuth-флоу); LinkedIn — «скоро», приглушённая, некликабельная, с локализованным бейджем — рекламирует направление, но ничего не делает. Один общий компонент для трёх точек входа: полноэкранный первый вход (новый пользователь), «Подключить другой» и «Переподключить». Спроектировано так, что третья сеть встаёт ещё одной строкой без сюрпризов раскладки. Токены ДС (светлая + тёмная); текст русский, 8 локалей (эталон — немецкий).

+ picker + networkRow + pickerSheet + firstConnect account-empty.css ds/tokens.css
Марки сетей. ДС осознанно использует нейтральные буквенные марки («@» / «in») — «no third-party logos» — тонированные по сети через семантический токен (tone): Threads = ink, LinkedIn = accent. Это узнаётся по марке + подписи и не воспроизводит товарные знаки; реальные бренд-ассеты команда сети сможет подставить в слот .acc-net-tile позже.

3состояние 1Полноэкранный первый вход

Брэнд-нью пользователь, 0 профилей когда-либо: у него ещё ничего нет, поэтому уместен заметный приветственный полноэкранный экран «выберите сеть» — не в дашборде. Пикер-герой + заголовок «Подключите первый аккаунт» + строка подкопии + компактное «что дальше» (только чтение · вы одобряете каждый пост · отключить в любой момент). Это единственное исключение из «дашборд поверх профилей».

4Пикер — анатомия

Строка сети: марка (tone) + имя + подпись + действие (live) / бейдж «Скоро» (coming-soon). Live-строка — кнопка (hover, primary в героях); coming-soon приглушена и некликабельна.

5Лист «Подключить другой» + «Переподключить»

Тот же пикер как поповер/лист. «Подключить другой» — выбор сети. «Переподключить» — сеть уже известна (@handle), поэтому Threads-строка первична и помечена ником, LinkedIn остаётся coming-soon; действие ведёт в тот же OAuth-флоу, нацеленный на этот хэндл. Копия подчёркивает: данные и настройки на месте.

6N сетейРасширяемость

Пикер рендерит PICKER_NETS — массив. Третья сеть = ещё один объект: строка встаёт следом, вертикальный список тянется вниз без переливов и переносов. Ни одна ширина не «прибита» к двум сетям. Ниже — тот же пикер с гипотетической третьей строкой (доказательство раскладки).

Zero layout surprises. Вертикальный список строк во всю ширину; марка flex:0 0 auto, тело min-width:0 с усечением, действие/бейдж flex:0 0 auto. Добавление сети не двигает соседей и не ломает Rule 1.

10Чек-лист

  • Один общий пикер в трёх точках: полноэкранный первый вход, «Подключить другой», «Переподключить».
  • Threads — live, первичное «Подключить аккаунт Threads» → OAuth. LinkedIn — coming-soon: приглушён, некликабелен, бейдж «Скоро» (локализован).
  • Первый вход (0 профилей когда-либо) — полноэкранный; всё остальное — дашборд поверх профилей (empty-states).
  • «Переподключить» = connect-флоу на известный @handle; сеть предвыбрана, данные целы.
  • Третья сеть = ещё одна строка, zero layout surprises (§6).
  • Нейтральные марки (no third-party logos), тон по токену; светлая + тёмная; Rule 1 + немецкая длина.
