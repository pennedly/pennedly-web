Pennedly · Автопилот · бустер «Комментарий при росте» — расширение

Цель + три точки входа — один бустер, привязанный к разной области постов

Бустер делает то же, что и раньше: когда пост набирает порог (N комментариев / лайков / просмотров), Pennedly один раз добавляет к нему заранее написанный комментарий (обычно ссылку или призыв). Новое — ЦЕЛЬ: за какими постами бустер следит. Под капотом это одна сущность (правило-бустер с целью); три точки входа просто задают цель по-разному — в одной явным пикером, в двух других неявно из контекста.

одна сущность · правило-бустер с целью конфиг идентичен: метрика · порог · текст · режим меняется только ЦЕЛЬ цель: все / сценарий / пост / условие web-desktop · ~960px · двухколоночник

Прицеп в Студии · «Бустер для этого поста»

При публикации/планировании поста под композером — секция бустера. Цель задана неявно (этот пост) и показана локнутой плашкой «Цель: этот пост». Свёрнуто — переключатель + строка-сводка; развёрнуто — тот же общий конфиг.

Секция развёрнута · локнутая цель + общий конфиг

Прицеп в редакторе сценария · «Бустер»

В редакторе сценария-поста бустер — отдельный раздел после шагов. Цель задана неявно (посты этого сценария): «для постов этого сценария: когда наберут [N] → добавь [текст]». Свёрнуто/развёрнуто, тот же общий конфиг.
