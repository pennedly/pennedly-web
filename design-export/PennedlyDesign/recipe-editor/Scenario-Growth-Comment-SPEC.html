Pennedly · Автопилот · новый тип сценария

Комментарий-добавка при росте поста — реактивный сценарий в редакторе-рецепте

Когда один из твоих постов переходит порог активности — N комментариев / лайков / просмотров (на выбор) — Pennedly один раз добавляет к этому же посту заранее заготовленный комментарий: рекламную ссылку, призыв или дополнение. Это реактивный сценарий (как «По событию», без расписания). Отличие от «много просмотров → новый ПОСТ»: здесь действие — комментарий к тому же посту, с заранее написанным текстом, который Pennedly не генерирует.

двухколоночник · ~960px · web-desktop метрика: комментарии · лайки · просмотры действие = комментарий к своему посту текст заготовлен, не генерится реактивно · проверка раз в ~15 мин один раз на пост · посты за ~48 ч

Фраза-рецепт

Когда мой пост наберёт [N] [комментариев / лайков / просмотров] → Pennedly добавит к нему комментарий: [текст] (один раз на пост)

01

Ключевой экран · слот «метрика и порог» раскрыт

«Ссылка под залетевшим постом». Слот «Когда сработает» раскрыт прямо в карточке: выбор метрики (просмотры / лайки / комментарии или «любая из»), числовой порог со степпером и быстрыми пресетами. Снизу — честные подписи: реактивно, один раз на пост, окно ~48 ч. Справа — живое превью: пост + добавленный комментарий веткой.

Light · метрика «Просмотры», порог 5 000 · правка существующего
Метрика

Все режимы триггера

Одна метрика на сценарий — так предсказуемее. У каждой свой порог по умолчанию и быстрые пресеты. Для тех, кому нужно несколько порогов разом — режим «Любая из метрик»: сработает, как только пройдён любой из включённых порогов.

Просмотры · порог 5 000
Лайки · порог 200
Комментарии · порог 50
Любая из метрик · порог на каждую
02

Слот «текст комментария» + окно длинного текста

Текст заготовлен заранее и публикуется как есть — Pennedly его не переписывает и не «озвучивает голосом». Ввод — через ту же модель, что и инструкция в других сценариях: компактный триггер показывает текущий текст и кнопку «Открыть в отдельном окне»; тап разворачивает полноразмерное окно ввода.

Триггер в редакторе · слот «текст комментария» раскрыт
Окно длинного текста открыто · полноразмерное поле
03

Раскадровка · слот → драйвер → готово

Петля «увидел → поменял → проверил» на слоте порога. Свёрнутый слот показывает значение человеческими словами; тап разворачивает драйвер прямо в карточке; «Готово» сворачивает обратно — и фраза сразу читается по-новому.

1Свёрнуто— слот показывает текущий порог словами.
2Тап по слоту— драйвер раскрылся на месте: метрика + порог.
3«Готово»— свернулось, метрика сменена на комментарии.
04

Слот «как добавлять» · Спроси меня / Автоматически

Как у всех сценариев: «Спроси меня» по умолчанию — комментарий-черновик ждёт в «Активности», пока не подтвердишь. «Автоматически» — осознанный опт-ин: комментарий появляется под постом сам. Всё решается внутри редактора.

«Спроси меня» (по умолчанию) · превью = черновик ждёт тебя
«Автоматически» выбран · превью = комментарий уже под постом
05

Слой 2 · «Настроить точнее» раскрыт

Конструктор условий «только если» (только оригинальные посты, лимит добавлений в день, кулдаун, наличие ссылки в посте) и окно наблюдения — за какой срок смотреть посты (24 / 48 / 72 ч). Частота проверки наследуется из «Правил дома» и подписана честно.

Light · слой 2 раскрыт
06

Состояния

Создание нового (черновик, не сохранён) · заход из шаблона (фраза предзаполнена пресетом «лид-магнит») · условие «только если» уже задано (тихая строка под фразой раскрыта в драйвер).
