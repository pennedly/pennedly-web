Дизайн Слоя 3 — в этом файле

Открой его в браузере. Это спека Слоя 3 во всех состояниях: рецепт-карточка с раскрытым аккордеоном «Слой 3 · для продвинутых» и готовыми контролами переопределения «Правил дома». Light и dark. Рендерится из layer3-override.js + layer3-override.css.

Что именно смотреть в коде

Дизайн построен на той же модели «карточка-рецепт», что и весь редактор. Слой 3 — это тело аккордеона, которое раньше было заглушкой, а теперь рендерит реальный список переопределений.

ГдеЧто там
layer3-override.js → layer3Body(cfg)Главная функция. Раньше отдавала .rce-stub, теперь — блок .ovr: лид с счётчиком переопределений + список из 4 пунктов.
layer3-override.js → l3Row(key, cfg)Одна строка пункта: бейдж «наследуется ↔ переопределено здесь», «Сейчас действует», кнопка Переопределить / ссылка Вернуть к наследованию, раскрытый контрол + «В Правилах дома: …».
layer3-override.js → l3Ctl(key, cfg)Контрол для каждого пункта: who — галерея .aud-grid (переиспользована из редактора); limit — слайдер .rc-range; freq — сегмент .seg; quiet — два input[type=time] + чекбокс.
layer3-override.js → L3_ITEMSМетаданные 4 пунктов: иконка, заголовок, описание и наследуемое значение (inh) из «Правил дома».
layer3-override.cssВсе классы .ovr-*: строка, бейджи, кнопки, раскрытый контрол, слайдер лимита, тихие часы. Только семантические токены — dark из коробки.
buildLayer3(cfg) / buildEditor(cfg)Аккордеон Слоя 3 отдельно (для раскадровки) и Слой 3 в контексте полного редактора. Монтируются на [data-l3card] и [data-l3recipe].
i
Интеграция в основной редактор. Чтобы поднять это в боевом recipe-editor.js, достаточно заменить там тело-заглушку layer3Body() на версию из layer3-override.js и подключить layer3-override.css рядом с recipe-editor.css. Структура cfg и классы совпадают один-в-один.

Reply-сценарий («Дежурство», «Ответ на упоминания»). По умолчанию каждый пункт наследуется из «Правил дома»; переопределяется точечно, только для этого сценария.

Как отрендерить нужный кадр

Хосты в HTML монтируются автоматически из data-*-атрибута с JSON-конфигом.

  • Слой 3 в контексте редактора: <div data-l3recipe='{"kind":"reply","l3over":["limit"],"l3limit":40}'></div>
  • Только аккордеон Слоя 3 (компактно, для раскадровки): <div data-l3card='{"kind":"reply","l3over":["freq"],"l3freq":"30"}'></div>
  • Ключи cfg: l3over (массив: who·limit·freq·quiet), l3who (fans·q·custom), l3limit (число), l3freq (5·15·30·60), l3quietOff (bool), dark (bool).
